## 一、问题

连续工具调用（连查 3 个文件 / 搜 2 次网页）在界面是**逐条折叠卡**，屏幕被切碎。目标：连续批合并为一个大块，块内小计「查看×3 · 搜索×2」。

🔴 **反直觉点（决定判据取舍）**：「连续 3 次 `read_file`」有两种成因——①一次 LLM 调用**并发**吐 3 个 tool_call（同 step）②**分 3 次**各吐一个（跨 3 个 step；mimo 中转属此类）→ **按 step 合并盖不住 ②**。故不采用「按 step 分组」（方案 A），改按**事件相邻性**切段（方案 B）。

## 二、目标与约束

**目标**

1. 过程条目流中相邻连续的工具条目合并为一批（`toolBatch`），块内按工具名小计。
2. 单工具批视觉等价现状（零回归）。

**约束**

- **内核生产代码零改动**：判据只读宿主已可见的 `ProcessEvent` 全序（`seq`）/ 类型 / `toolCallId` / `stepIndex`。
- **不改落盘结构**（纯渲染投影）→ 旧数据天然兼容。
- 运行时流式 / finalize 重放 / pending 行升级**三渲染上下文共用一个** `groupToolBatches()`，禁内联三份（SKILL-S2 血训：同一清单两个消费通道只改一个）。

## 三、设计

### 3.1 切段判据（口径①定案）

批 = 过程条目流中**前后相邻、中间无打断物**的最大工具序列。

| 条目 | 角色 |
| ---- | ---- |
| `narrate` / 正文（text）/ `plan_item_boundary`（任务项边界） | **打断物** → 一切断段 |
| `thought` | 穿插**不断段**（思考是 step 内伴随物，不打断工具连续性） |
| `tool_start` / `tool_result` | 段内容（按 `toolCallId` 配对） |

段 id = 段内首个 `tool_start` 的 `seq`（稳定、可复现，不新造标识）。

### 3.2 失败工具（口径②定案）

失败 / 被拒工具**留段内**，块级标红提示；不单独成块（拆块 = 视觉随错误率抖动）。

### 3.3 pending 行（口径③定案）

工具意图预告行（pending，结果未回）升级为工具行后**并入所在批**；DOM key 由 `toolCallId` 改为**段 id**，旧 key 消费点随实现一并清干净（不留僵尸 key）。

### 3.4 文案与命名契约（挂 STEP-ID-1）

- 块标题用「**第 N 批**」或纯计数（如「工具×4（查看 2 · 搜索 1 · 写入 1）」）；🔴 **不得**出现「第 N 步」（屏上唯一「步」= 思考折叠，STEP-ID-1 防复发约定）。
- 概念命名：`toolBatch`（批）/ `data-tool-batch` / `groupToolBatches()`；**禁** `toolStep`（step 词根表任务表语义 = 术语红线）、**禁** `toolRun`（与内核 `ToolRunner` 同词根两义，2026-09-25 撤销原登记名）。

### 3.5 与思考分桶的边界

`groupThoughtBuckets`（`chatView.ts`）是同构先例（纯 webview、两调用点），批分组与其同层并列。**STEP-BUCKET-1 根治（桶 key 加容器前缀）不混批**（未触发不做）；若实现中批分组必须触碰桶 key，再连带并回写台账。

## 四、不带伤五类预检

| 类 | 判定 | 措施 |
| --- | --- | --- |
| 双轨镜像 | 批 = 呈现分组（跨 step 成立），step = 执行语义，互不为影子 | 命名避 step 词根（§3.4） |
| 降级兜底 | 旧数据无批概念 → 回落逐条渲染 | 单工具批 = 现状形态 |
| 类型 hack | 段 id = `seq`（number），无 `as` | — |
| 重复实现 | 三上下文共用 `groupToolBatches()` | 测试断言同源，禁内联 |
| 僵尸声明 | pending 旧 `toolCallId` key 消费点清干净 | 口径③随行 |

## 五、测试与验收

- **宿主（主）**：切段矩阵（三种打断物各一例 / `thought` 穿插不断段 / 跨任务项边界切段）+ 三上下文一致 + 小计文案 + 失败留段标红 + pending 升级归段。
- **内核（辅，1 例）**：**发射形态不变量**——同 step 工具事件区间内无 `narrate` / `plan_item_boundary`（STEP-BUCKET-1 范式：测试固化前提，不加防御分支）。
- **变异捕红**：①打断规则回退（`thought` 也打断）→ 切段矩阵红；②三上下文之一内联独立分组 → 一致性用例红。恢复后残留 0。
- **总验收**：`npm run ci:local -- --preset=full` 12 步全绿 + 术语门禁零漂移（`toolBatch` / `toolBatches` 等新载体词按流程注册基线后复跑）。
