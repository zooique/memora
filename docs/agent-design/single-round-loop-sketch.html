关于套娃合理性的说明
子 Agent = 本 Agent 自身，因此真理源只有一个（单轮闭环），这符合 SSOT 原则。
三种拉起的区别仅在调用上下文：①② 是 同步主线程调用，复用同一工作记忆；③ 是 异步 fork 副本，持独立工作记忆，完成后仅结果汇合——避免并行写冲突。
当前阶段：③ 不实施，保持架构简洁。
