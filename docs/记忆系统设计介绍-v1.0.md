# 接入 Memora · 记忆系统设计介绍

> 面向接入 Memora 的宿主程序开发者。5 分钟理解记忆系统的全流程。

---

## 一句话

**Memora 把"角色、规则、技能、对话历史、用户画像"全部统一为"记忆"，通过「类型 + 永久性」两个维度区分，用同一套索引存储和召回。**

---

## 记忆的四个层级

```
┌──────────────────────────────────────────┐
│  Layer 0  作品层                          │
│  用户自己的产出（小说/代码），Memora 不存  │
│  只存投影（摘要），通过宿主工具访问原文     │
├──────────────────────────────────────────┤
│  Layer 1  用户画像  (permanence: always)  │
│  "我叫张三" "我喜欢简洁的代码"             │
│  自动提取，身份覆写，偏好累积              │
├──────────────────────────────────────────┤
│  Layer 2  话题存档  (permanence: topic)   │
│  每段对话结束后自动总结为结构化摘要        │
│  下次相关话题自动召回                      │
├──────────────────────────────────────────┤
│  Layer 3  引导记忆  (permanence: always)  │
│  角色人格、项目规则、技能定义              │
│  启动时加载，每次对话都注入 system prompt  │
└──────────────────────────────────────────┘
```

## 记忆类型与永久性

### 五种记忆类型

| 类型          | 含义     | 真理源                                      | 运行时索引                       | 例子                               |
| ------------- | -------- | ------------------------------------------- | -------------------------------- | ---------------------------------- |
| `personality` | 用户画像 | UserProfile 自动提取 + persona 目录         | SQLite                           | "我叫张三"、"我喜欢简洁的代码"     |
| `rule`        | 行为规则 | `agent-config/rules/` 或 `.memora/rules/`   | SQLite                           | 安全基线、写代码风格、写作规范     |
| `skill`       | 技能定义 | `agent-config/skills/` 或 `.memora/skills/` | SQLite + SkillManager 关键词索引 | 章节创作、代码审查、魔法体系       |
| `topic`       | 话题摘要 | 话题文件 + TopicSummarizer 自动生成         | SQLite + 文件                    | 章节记录、讨论总结                 |
| `projection`  | 作品投影 | WorkProjectionManager 自动生成              | SQLite                           | 小说的角色关系图、代码的模块依赖图 |

> **核心理念**：rule、skill、personality 的真理源是配置文件（Markdown），启动时由 MemoryLoader 扫描并写入 SQLite 索引。`addRule()`/`addSkill()`
> 支持运行时注入到 SQLite，但持久化仍依赖 AutoConfigRefiner 写回配置文件。**SQLite 是运行时索引，不是持久化存储。**

### 永久性分级

| 级别        | 含义 | 召回时机           | 例子                         |
| ----------- | ---- | ------------------ | ---------------------------- |
| `always`    | 永驻 | 每次对话           | 角色人格、核心规则、用户画像 |
| `domain`    | 领域 | 本项目内始终召回   | 项目规则、项目技能           |
| `topic`     | 话题 | 话题匹配时自动召回 | 章节摘要、讨论记录           |
| `on-demand` | 按需 | 主动搜索时         | 脱敏临时信息                 |

## 记忆归档：什么时候写入

```
full 模式（默认）
  ├── 用户说"记住…" → 信号检测 → 立即归档
  ├── 每 3 轮对话 → 周期性归档检查
  └── 每 30 轮 → 中途归档（长对话防丢失）

insights-only 模式（草稿/审核工作流）
  ├── 用户画像始终自动归档 ✅
  └── 话题归档暂停，宿主手动调 archiveApprovedContent()

manual 模式
  └── 完全不自动归档，宿主完全控制
```

**关键设计**：用户画像归档不受 `archiveMode`
影响。因为"我叫张三"是确定事实，和"AI 写的第 2 版草稿"性质不同。

---

## 记忆召回：什么时候读取

```
每次 chat() 调用
  │
  ├── 1. TopicMount.focus()   ← 根据输入关键词，召回相关话题记忆
  ├── 2. 构建 system prompt   ← 永驻记忆 + 领域记忆 + 角色 + 技能
  ├── 3. 注入 messages        ← 当前对话的工作记忆
  └── 4. 发送 LLM             ← 上下文中包含所有召回的记忆
```

## 宿主程序的最小接入

```typescript
import { Agent } from 'memora';

// 1. 构造
const agent = new Agent({
  projectPath: '/path/to/project',
  configDir: '/path/to/agent-config', // 规则/角色/技能放这里
  archiveMode: 'insights-only', // 可选：草稿模式
  maxContextTokens: 16000, // 可选：上下文窗口大小
  config: {
    /* LLM 配置 */
  },
});

// 2. 初始化
await agent.init();

// 3. 对话
for await (const chunk of agent.chat('你好')) {
  console.log(chunk.content); // 流式输出
}

// 4. 审核通过后归档（insights-only 模式）
await agent.archiveApprovedContent('定稿内容...');

// 5. 切换话题
await agent.switchTopic('下一章');

// 6. 查看记忆
const snap = agent.inspect();
// snap.working    → 当前对话状态
// snap.bootstrap  → 引导记忆（角色/规则/技能）
// snap.archive    → 话题归档统计
// snap.mounted    → 当前挂载的话题记忆

// 7. 关闭
await agent.close();
```

## 长运行场景的关键配置

| 配置                      | 默认值   | 作用                                              |
| ------------------------- | -------- | ------------------------------------------------- |
| `archiveMode`             | `'full'` | 桌面精灵用 `'full'`，小说写作用 `'insights-only'` |
| `maxContextTokens`        | `8000`   | 自动截断超长对话，防止爆 LLM 上下文窗口           |
| `agent.lastInteractionAt` | `null`   | 判断用户离线时长，决定是否主动问候                |

---

## 核心理念

> **配置文件是真理源，SQLite 是运行时索引。**
>
> 你编辑 `agent-config/rules/`、`personas/`、`skills/`
> 下的 Markdown 文件，Memora 启动时自动扫描加载到 SQLite。记忆归档也走 SQLite，但源头永远是配置文件。
