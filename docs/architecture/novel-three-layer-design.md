# 共鸣小说家：三层结构创作方法论设计（探索中）

> **状态**：探索中（2026-09-13）。未定案、未占 ADR 编号、未改 README 索引。经真实场景复现消费后按 S2 触发固化。
>
> **一句话**：小说创作 = **需求层（当下社会缺什么）→ 内核层（不变的人性故事）→ 形式层（内核与读者的纽带）**，三层自洽后逐层落为可写方案。
>
> **土壤来源**：本文设计前的行业搜索养分（网络为土壤）：2026 网文市场趋势（光明日报 / 中国作协网 / 平台数据分析）与经典故事理论（麦基《故事》等），详见 [§四 行业印证](#四-行业印证搜索养分)。

## 一、核心主张（用户理念沉淀）

小说不是"讲一个好听的虚构故事"，而是**用故事回应当下人的精神需求**。三层结构：

| 层 | 回答的问题 | 变化性 | 来源 |
| --- | --- | --- | --- |
| **① 需求层** | 为什么写：当下社会普罗大众的痛点痒点是什么、缺什么精神供给 | 随时代变 | 上网搜索当前社会热门事件/现象 → 分析 → 反推精神需求缺口 |
| **② 内核层** | 写什么：故事的精神内核（人性和人的故事） | 不随时代变 | 经典故事之所以经典，因内核底层是人性——社会形态变、人不变，社会关系/亲子关系/人际关系不变，只是表现形式变 |
| **③ 形式层** | 怎么表达：题材、文笔、故事设定、表达形式 | 服务内核 | 形式是搭建"精神内核 ↔ 读者"的纽带；**不同内核需配不同题材与设定** |

**创作顺序**：先需求 → 再内核 → 最后形式。需求是种子发芽的土壤，内核是种子本身，形式是长出来的枝叶。

## 二、发散：三层之外的完整创作地图

写小说远不止三层。三层解决"写什么方向"，其下还有决定"能不能写出来、写得好不好"的横向维度：

### A. 需求层的细化缺口

1. **读者群体画像**：痛点属于"谁"？Z 世代 / 中老年 / 女性 / 男性 / 下沉市场，不同群体的痛点与阅读习惯完全不同。例：2026 中老年情感题材搜索量上涨 280%，付费主力是 45 岁以上中老年 + 新就业体力群体——"沉默的大多数"被重新发现。
2. **需求验证**："热门事件 → 需求缺口"是**推测**，如何验证？搜索什么（社会事件、平台榜单、读者评论）、看什么数据（完读率/留存/标签热度）、如何避免"想当然的痛点"。
3. **情绪价值类型学**：2026 读者需求已从"单纯爽感"转向"情绪代偿/解压/共鸣"——反内卷、职场反击、中年救赎、精神内耗治愈、反抗规训。需求层要能区分**解压型 / 治愈型 / 共鸣型 / 代偿型 / 爽感型**，不同型对应不同内核与形式。
4. **时效性分级**：社会热点有保鲜期（3-6 个月），内核没有。需求层输出必须区分"**当下红利**"与"**长期底色**"。

### B. 内核层的细化缺口

1. **内核元库（原型库）**：经典内核能否类型化？麦基《故事》的"原型 vs 陈规俗套"——原型 = 挖掘普遍人性体验，以独特文化细节呈现。可沉淀的母题候选：身份认同、规则与自由、爱与牺牲、代际冲突、阶层跃升、自我救赎、亲密关系、孤独与连接……
2. **内核提取方法论**：如何从一部经典里"提炼内核"（去掉时代外壳，留下人性骨架）？需要一个可复用的提取步骤。
3. **内核 ↔ 需求适配规则**：不是任意内核都能承接任意痛点。需要规则判断"这个需求缺口该配哪类内核"——如"被规训的疲惫"配"规则与自由"、"孤独感"配"孤独与连接"。

### C. 形式层的细化缺口

1. **题材与内核匹配**：同一内核可配多种题材，但题材有限制力——"规则与自由"可配规则怪谈（制度异化）、职场文（体制牢笼）、仙侠（修行体系），不可配无冲突的日常流水。需要匹配规则。
2. **世界观四维**（麦基）：时代 / 期限 / 地点 / 冲突层面——世界越小、钻研越深，越自由，越能避免陈词滥调。
3. **叙事结构**：三幕式（1:2:1）、《救猫咪》15 拍、节拍-场景-序列-幕-故事弧光的最小单位体系（每场景必须有价值转变，无转变即删）。
4. **人物弧光**：欲望 → 障碍 → 代价 → 转变（现有 persona 的"故事三要素"雏形，需成体系）。
5. **节奏与钩子**：2026 网文短剧化、一章一个反转/钩子、前 10 页立人物。平台（阅文 vs 番茄）算法分发逻辑影响节奏设计。
6. **类型常规**：每种类型有读者期待的元素，满足常规是底线、超越常规才是原创。

### D. 横向全流程缺口

1. **流水线编排**：需求分析 → 内核锁定 → 题材匹配 → 世界观 → 人物 → 结构 → 章节 → 成文 → 打磨 → **验证**。现状角色包无此编排，作者从"帮我写小说"到成文缺少引导。
2. **连续性管理**：长篇连载的人物状态、伏笔、时间线一致性（现有 foreshadow 技能覆盖部分）。
3. **验证与反馈闭环**：写完如何自检？读者视角重读、留存思维（开头 3 章留人）、价值转变检查（每场景）、情绪价值是否达成（对照需求层）。
4. **AI 协作边界**：代笔 vs 辅助。现有 rules 已有"不代笔关键选择"，需扩展到：创作主权（内核/命运由作者拍板）、一致性义务（不擅自改设定）、场景感保留。

## 六、已知风险（对抗式自查）

| 风险 | 说明 |
| --- | --- |
| 需求层变"追热点" | 热点是土壤不是答案：三层结构要求内核不变，防止"什么火写什么"的短视——需要规则约束（形式可追热点，内核不可） |
| 内核层变"抄经典" | 提取内核是借鉴人性骨架，不是复制故事：需规则防抄袭式借鉴（换时代、换人物、换冲突具象） |
| 三层自洽的复杂度 | 三层各自能跑通不难，难在互相匹配：G5 一致性检查是质量闸门 |
| AI 边界 | 需求分析/内核建议可 AI，创作主权（内核拍板、命运选择）归作者：沿用现有"不代笔关键选择"并扩展 |
