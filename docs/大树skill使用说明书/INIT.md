# 匠码 — 代码项目 Skill

> 匠码是代码项目的完整大树 Skill 体系。播种机负责扎根（技术栈选型 + 架构设计），生长器负责养树（日常开发 + 测试 + 部署）。
>
> **架构**：匠码采用"基础树模板 + 分支注入 → 编译"架构。源文件在 `src/`，运行
> `python scripts/generate-branch-skills.py` 编译到 `dist/codecraft/`。

---

## 编译产物文件清单

| 组件         | 位置（dist/codecraft/）       | 作用                                                     |
| ------------ | ----------------------------- | -------------------------------------------------------- |
| **播种机**   | `big-tree-seeder/SKILL.md`    | 矛盾分析 → 技术栈选型 → Rules 生成 → 样板验证            |
| **生长器**   | `big-tree-grower/SKILL.md`    | 日常开发、测试、数据库迁移、安全审计、依赖管理、版本发布 |
| **参考文档** | `big-tree-seeder/references/` | 技术栈决策矩阵、样板验证指南                             |
| **参考文档** | `big-tree-grower/references/` | 测试生成指南、前端审美指南、依赖审计指南、发布指南       |

---

## 如何使用

### 1. 编译

```bash
cd big-tree-skills
python scripts/generate-branch-skills.py
```

### 2. 安装到目标项目

将 `dist/codecraft/` 下的 `big-tree-seeder/` 和 `big-tree-grower/`
复制到目标项目的 `.trae/skills/` 目录。

### 新项目

在 AI 对话中说：`我要开发一个系统`

### 已有项目接入

在 AI 对话中说：`已有代码项目需要大树管理`

## 播种后

seeder 扎根完成后，grower 接管：

```
种木成林（建骨架）→ 方案更新（日常开发）→ 补测试 → 提交前审查
                                          → 数据库迁移
                                          → 安全审计 → 依赖审计
                                          → 发布版本
```

详细触发词和串联链路见 [匠码体系触发词速查.md](匠码体系触发词速查.md)。
