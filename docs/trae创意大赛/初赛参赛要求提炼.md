## 一、参赛前提

- 初赛作品有效的前提是**报名审核已通过**
- 如果只在初赛专区发了 Demo，但报名最终没通过，该 Demo 不会进入评审
- 建议先确保报名帖通过，再提交 Demo（报名审核期间可以提前打磨）

## 二、初赛全流程

```
报名通过 → 用 TRAE 做出可体验 Demo → 按模板发布初赛 Demo 帖（附体验链接 + 关键步骤截图 + Session ID）
→ 走专业评审通道（可叠加抖音人气通道）→ 7 月 21–23 日公示结果 → 晋级复赛
```

## 三、Demo 作品帖模板（必须包含以下 4 个部分）

### 【标签】
按所选赛道选择话题标签：生活娱乐 / 学习工作 / 社会服务 / 硬件交互，**必须四选一**；
参加附加赛题的还可加选「社会公益」标签。（需要跟报名通过的赛道保持一致）

### 【标题】
报名赛道 + Demo 名称

### 【正文】至少包含以下 4 个部分：

#### 1. Demo 简介
- **是什么**：一句话说清你的产品形态（App / 小程序 / 网站 / 系统 / 硬件等）
- **面向谁**：核心用户是哪些人
- **主要功能**：列出 2–3 个核心功能，建议配产品截图或界面展示

#### 2. Demo 创作思路
- **灵感来源**：你为什么想到做这个
- **想解决的问题**：用户真实存在的痛点
- **为什么做这个方向**：你的判断和取舍

#### 3. Demo 体验地址（三选一）
- 部署随时可公开访问的体验链接
- **交互式可体验的 HTML 格式文件，请使用 Zip 格式打包上传到社区**
- 硬件交互赛道可用演示视频替代在线体验（视频请上传第三方平台后附公开链接）

#### 4. TRAE 实践过程
- 清晰展示用 TRAE 完成 Demo 开发的完整流程
- **附开发关键步骤截图（不少于 3 张）**
- **附关键任务对话的 Session ID（不少于 3 个）**，用于证明作品由 TRAE 开发完成
- 最后再附上通过的社区报名帖链接

> Session ID 获取方式：双击 TRAE 的对话复制出来即可

## 四、评审维度（专业评审通道，4 个维度打分）

专业评审团按以下 4 个维度给每个作品打分，综合得分 **TOP 300 晋级复赛**：

| 维度 | 说明 |
|------|------|
| **创新性** | 创意是否新颖、是否有独特视角 |
| **实用性** | 是否解决真实痛点、是否有实际使用价值 |
| **完成度** | 核心功能是否能跑通、体验是否流畅 |
| **技术实现** | 技术方案是否合理、是否充分利用 TRAE 能力 |

### 专业评审通道基本要求：
- 初赛 Demo 应与报名创意方向一致
- **必须基于 TRAE IDE 或 TRAE Work 完成**
- 需提供可体验地址（或上传 HTML 格式文件，硬件赛道可用演示视频）
- 能清晰展示核心功能与目标场景，而非停留在概念
- 参赛帖结构完整、便于评审

## 五、晋级通道（两条独立通道，合计最多 350 个复赛名额）

| 通道 | 名额 | 说明 |
|------|------|------|
| **专业评审通道** | 300 席 | 按 4 维度打分，TOP 300 晋级 |
| **抖音人气通道** | 50 席 | 与专业评审独立，互不影响 |

### 抖音人气通道规则：
- **参与前提**：必须已通过大赛报名并在初赛专区提交了符合要求的 Demo 帖
- **参与方式**：在抖音发布作品图文/视频，带话题 `#vibecoding大赏 #traeai创造力大赛` 并 `@TRAE @抖音科技`
- **人气分公式**：人气分 = 点赞数 + 评论数 × 2 + 收藏数 + 转发数
- **最低门槛**：单条内容点赞数 ≥ 500 才能进入人气榜计分
- **数据口径**：同一作品可发多条，仅取数据最高的一条计分（不累加），统计截止 7 月 15 日 23:59:59
- **流量扶持**：符合要求的优质作品，单条可获得 **5 万+ 曝光流量扶持**

## 七、提高入围概率的实战建议

1. **写真实场景**：别空泛，把你真正想解决的问题讲具体
2. **展示过程，而非只放结果**：把任务怎么拆解、用了 TRAE 哪些能力、关键 Prompt / 操作、踩过的坑都讲出来——**这是评审最看重的**
3. **多用截图**：开发关键步骤截图非常加分（记得不少于 3 张）
4. **保留并附上 Session ID**：不少于 3 个，证明作品由 TRAE 完成
5. **保证体验链接可用**：提交前自己点一遍，确认能正常打开、能体验到核心功能
6. **内容原创、版权清晰**
7. **不用追求「完美作品」**，把真实创作过程分享出来就很好
8. 补充开发中的踩坑经历、解决方案和心得，会更容易获得关注

## 八、关键 FAQ

- **Q：多个创意都通过了报名，初赛能都提交吗？**
  A：可以提交多个；但晋级复赛评选时，只取同账号下得分最高的 1 个作品。

- **Q：作品必须从 0 到 1 创建吗？**
  A：不一定。可以全新创作，也可以是已有作品在参赛期间完成**实质性版本迭代**（如新增核心功能、重构关键流程、显著优化体验），但开发都必须用 TRAE IDE 或 TRAE Work 完成，并能提供可证明过程真实的材料。

- **Q：视频太大传不上社区怎么办？**
  A：TRAE 社区发帖仅支持文字、图片、GIF、链接、20M 以内文件。视频、代码库、大体积压缩包等，请先上传到第三方平台（如 Bilibili、GitHub、飞书云文档等），再在帖子里附上可公开访问的分享链接。
