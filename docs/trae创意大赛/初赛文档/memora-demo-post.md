> **一句话介绍**：Memora 是一款真正会记忆的桌面 AI 助手。每轮对话自动提取关键信息为结构化记忆，下一轮自动召回最相关的记忆注入上下文。AI 终于能记住你了——而且越用越懂你。

---

### 1. Demo 简介

**是什么**：Memora Sprite 是一款运行在你桌面上的、**真正会记忆**的本地 AI 助手。

它不是"接了 API 的聊天窗口"，也不是"套了壳的网页版 ChatGPT"。Memora 从内核层面重新设计了 AI 的记忆机制——每轮对话结束后，关键信息被结构化提取为记忆；下一轮对话开始时，最相关的记忆被动态召回注入上下文。记忆不是聊天记录的堆叠，而是有生命周期、有置信度、有关系网络的结构化知识。

**面向谁**：
- 长期在 IDE 中连续编码数小时、不希望被窗口切换打断心流的开发者
- 需要跨天持续深度对话、希望 AI 记住项目背景和创作风格的创作者
- 受够了"每次都要重新介绍一遍自己"的 AI 用户
- 重视隐私、希望 AI 数据完全本地存储的用户

**核心功能**：

**① 每轮记忆闭环（核心创新）**
对话结束自动提取关键信息（身份画像 / 偏好洞察 / 作品投影），下一轮通过「关键词匹配 + 语义向量」双通道召回最相关的记忆。每条记忆有置信度评分，不常用的记忆随时间自然衰减。这不是简单的历史记录持久化——这是一个有生命周期的记忆引擎。

【截图：04-memory-list-view.png + 05-memory-graph-view.png】

**② 三态自然交互**
不打断工作流的桌面精灵设计：完整窗口深度对话 / 浮动图标热键召唤 / 系统托盘后台静默。会话历史按天自动管理，微信/QQ 式时间流向上滚动加载，跨天无缝衔接。

【截图：07-float-bubble-state.png + 06-memory-timeline-view.png】

**③ 从"工具"到"伙伴"的进化**
精灵不止于问答工具——它真实感知你的状态并持续成长：
- **默契度**：初识 → 熟悉 → 默契 → 知己，基于真实记忆积累
- **情感基调**：温暖度 / 直接度 / 主动度 / 稳定度四维实时推导
- **行为模式**：自动发现你的工作习惯和偏好模式

【截图：03-chat-with-memories.png 左侧侧边栏默契度 + 情感基调面板】

**④ 流式对话与透明召回**
- 真正的流式输出，带思考阶段指示器（recalling → processing → archiving）
- 召回透明度：回复前展示"想起 X 条记忆"，点击可跳转详情
- 同角色连续消息自动分组，减少视觉噪音

【截图：03-chat-with-memories.png 对话区域展示召回标签和闭环提示】

**⑤ 隐私本地优先**
- 不监听键盘、不读剪贴板、不截屏、不监听网络
- 剪贴板三重保护：被动检测（仅哈希）→ 主动触发（用户确认）→ 敏感过滤
- 两级权限 + 路径白名单，所有记忆 100% 本地存储

【截图：11-sprite-config-panel.png 精灵配置面板展示隐私相关设置】

### 2. Demo 创作思路

**灵感：一个被所有人忽略的痛点**

在用 Trae IDE 编程的过程中，我发现了一个反直觉的问题：**对话越长，AI 越傻**。

连续聊 2 小时以上，AI 开始记混之前说过的话、开始重复回答、开始遗漏关键上下文。要么你忍受质量下降，要么手动清空窗口重新介绍背景——这打断了心流。

所有人都在解决"怎么让上下文窗口更大"，但没人解决"怎么让上下文永远精简而相关"。

**核心理念：应无所住，而生其心**

这句话来自《金刚经》，也是 Memora 的设计哲学：
- **无所住**：启动时上下文为空，不携带冗余历史，Token 消耗固定
- **生其心**：开口时相关记忆自然浮现，AI 永远知道你在说什么、你是谁

记忆系统的四步闭环：
1. **存储**：对话结束自动提取结构化记忆（profile / insight / work-projection 等）
2. **衰减**：不常用记忆 score 逐渐降低，遗忘也是记忆的一部分
3. **召回**：下轮对话通过关键词 + 语义向量双通道召回相关记忆
4. **组装**：召回的记忆注入系统提示，上下文永远保持精简相关

**从"工具"到"伙伴"的进化（新增）**：

初赛期间，我们不止完善了记忆引擎，还完成了三个重大 Phase 的迭代：
- **Phase 2**：从"工具"到"伙伴"——情感基调推导、默契度成长、行为模式检测
- **Phase 3**：桌面壁垒——全局快捷键、在场状态检测、剪贴板三重保护、浮动窗口
- **Phase 4**：生态准备——配置建议闭环、用户画像闭环、作品投影、技能拖入安装、审计日志

**我们选择做什么、不做什么**：
- 做：让 AI 真正记住你，而且不打扰你
- 不做：通用 Agent 平台、无限长上下文、云端服务、多 Agent 协作
- 专注一件事，做到极致

### 3. Demo 体验地址

**交互式 HTML Demo 已作为附件上传**（`memora-demo.zip`），下载解压后打开 `index.html` 即可完整体验。

**推荐体验路径（3 分钟看懂核心价值，两种方式任选）**：

**方式一：观看自动演示（推荐，约45秒）**
1. 打开首页，点击「开始交互式体验」
2. 关闭欢迎引导层后，点击底部引导栏的「观看演示」按钮
3. 自动演示将完整展示：自我介绍→偏好设置→项目信息→记忆列表→记忆图谱→记忆时间线→三态切换→日期导航→记忆召回全流程

**方式二：手动体验（3分钟）**
1. 打开首页，点击「开始交互式体验」
2. 点击空状态建议按钮或发送「我叫小明，是一名前端开发者」→ 观察记忆自动提取
3. 发送「我喜欢简洁直接的回答」→ 观察 insight 类型记忆入库
4. 发送「我最近在做一个 Vue 项目」→ 观察作品投影记忆 + 召回标签
5. 点击顶部「🧠 记忆」标签 → 切换「📋列表 / 🕐时间线 / 🕸️图谱」三种视图观察记忆网络和衰减条
6. 使用顶部三态切换器 → 体验「🪟完整窗口 / 💫浮动图标 / 🔽系统托盘」三种形态
7. 点击工具栏「📅 今天」日历按钮 → 选择「昨天」查看历史对话，体验按天自动会话管理
8. 发送「你还记得我是谁吗？」→ 观察记忆召回效果
9. 观察左侧「💕默契度」和「🎭情感基调」面板随对话真实成长

**Demo 特点**：
- 对话是实时的（模拟 LLM 回复逻辑，带思考阶段指示器）
- 记忆提取是即时的（发送身份/偏好/项目类消息立即看到记忆入库和衰减条）
- 记忆每8秒自动衰减一轮（可在列表视图观察score变化）
- Canvas 2D 动态绘制记忆关系图谱（节点大小=score，颜色=来源，连线=关系类型）
- 召回透明度：回复前展示"📎 召回 X 条记忆"标签
- 所有面板都可点击探索，设置面板展示完整配置项
- 支持浅色/深色主题切换
- 无后端依赖，纯 HTML/CSS/JS 即可运行

**阶段四：Demo 迭代与质量收敛——踩坑与修复**

这一阶段在 Trae 中进行了多轮自我审查和迭代，踩过的坑：

1. **首页只罗列功能，没有差异化定位** → 增加"对比表格"，让评审一眼看到 Memora 和传统方案的区别
2. **记忆计数显示 3 但实际只有 1 条** → 修复数据一致性，增加系统内置记忆（角色/护栏/规则）
3. **记忆识别只能识别"我是XX"** → 扩展为支持身份/偏好/项目三类信息提取
4. **用户看不到记忆如何工作** → 增加召回标签、新记忆保存提示等视觉反馈
5. **空状态没有引导** → 增加 5 个体验建议按钮，引导用户完整体验记忆闭环
6. **流式输出在高频 chunk 下卡顿** → 引入 RAF 节流渲染，合并高频更新
7. **用户停止流式后状态锁死** → 修复 streaming state machine，确保所有终止路径清理状态
8. **IPC 时序导致消息顺序错乱** → 使用 try/catch/finally 自然执行顺序保证错误先于 END 事件
9. **Canvas 图谱主题切换后颜色错误** → 统一使用 getComputedStyle 解析 CSS 变量，移除硬编码颜色
10. **会话历史下拉切换导致对话流断裂** → 改为微信/QQ 式时间流，按天向上滚动加载

### 5. 技术实现亮点

**工程严谨性**：
- 22 份 ADR 决策记录，每个架构选择都有理由和约束
- 992 个自动化测试，核心逻辑覆盖率高
- 零 native 依赖内核，纯 TypeScript 编写，可被任何宿主项目集成
- 分层架构清晰：agent / memory / persona / skill / llm / security / config / logging / utils 职责分明
- 精灵宿主 8 个专职控制器，单一职责明确

**产品差异化**：
- 记忆不是聊天记录：结构化提取、置信度评分、自然衰减、双通道召回
- 记忆关系网络：支持 contradicts / supports / follows / refines 等多种关系类型，Canvas 2D 力导向图谱可视化
- 三态交互设计：完整窗口 / 浮动图标 / 系统托盘，真正融入桌面工作流
- 默契度真实成长：基于记忆积累而非虚假数值
- 情感基调实时推导：温暖度 / 直接度 / 主动度 / 稳定度四维感知
- 对话上下文感知：节奏 / 话题集中度 / 对话深度三列指标

**隐私设计**：
- 上下文感知而非内容感知：只通过文件变化、窗口标题等元数据感知状态
- 四不原则：不监听键盘、不读剪贴板、不截屏、不监听网络
- 剪贴板三重保护：被动检测（仅哈希比较）→ 主动触发（用户确认才读取）→ 敏感过滤（密码/Token/密钥自动忽略）
- 纯本地存储，数据不出本机

**桌面级集成**：
- 两阶段初始化：阶段 1 创建窗口 + 托盘（始终成功），阶段 2 初始化 Agent（可能失败但不影响 UI）
- 全局快捷键热更新，无需重启应用
- 浮动气泡窗口：80×80 悬浮球 + 未读角标 + 位置持久化 + 多显示器边界校验
- 系统托盘脉冲动画：idle / active / sleeping 三种状态
