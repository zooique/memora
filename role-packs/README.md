# role-packs 示例库

> **声明**：本目录下的角色包是 **示例 / 参考实现**，用于展示角色包目录结构、字段用法和内核支持能力。**不进入任何运行时分发**，不作生产使用。

## 身份

本示例库归属 memora 内核仓库，随内核版本演进，**不随宿主产物分发**：

| 项 | 说明 |
|----|------|
| 身份 | 示例 / 参考 |
| 归属 | memora 内核示例库 |
| 分发 | 不进入 VSIX、npm 包或任何运行时产物 |
| 生命周期 | 随内核能力演进，独立于宿主角色包 |

## 接入者指引

- 宿主（如 VS Code 插件）应使用**宿主内置角色包**作为生产配置，参阅 [role-pack-spec.md](../docs/architecture/role-pack-spec.md) §9.1 示例库 vs 宿主生产库。
- 本目录仅作**结构参考**和**字段 / 能力用法示例**，修改本目录内容不影响任何宿主运行时行为。
- 新增宿主时，可复制本目录角色包到宿主内置目录，复制后即"分叉"——各自独立演进，不回写本目录。
