# core-extractor：内核提取与适配

## 用途

三层结构的第二层。内核 = 人性与人的故事，跨时代稳定。从经典提炼内核、用内核承接需求层找到的缺口。

## 内核提取步骤（去掉时代外壳，留下人性骨架）

1. 选一部经典（或经典片段）；
2. 问"这个故事在讲哪种人的困境"——不是情节，是困境类别；
3. 剥掉时代外壳：科技/制度/服饰变了，剩下什么不变？（关系、欲望、恐惧、代价）；
4. 一句话说内核：如"规则与自由"、"爱与牺牲"、"代际冲突"、"自我救赎"。

## 母题库（供适配检索）

身份认同 / 规则与自由 / 爱与牺牲 / 代际冲突 / 阶层跃升 / 自我救赎 / 亲密关系 / 孤独与连接 / 真相与谎言 / 成长代价……

## 内核 ↔ 需求适配规则

| 需求缺口 | 适配内核 |
| --- | --- |
| 被规训的疲惫 | 规则与自由 |
| 孤独与疏离 | 孤独与连接 |
| 奋斗无回报的怀疑 | 阶层跃升 / 代价与意义 |
| 关系信任崩塌 | 真相与谎言 / 亲密关系 |

## 校验清单

- [ ] 内核是"人性的困境"而非"情节梗概"？
- [ ] 内核能跨时代成立？
- [ ] 适配的需求缺口有实证依据？
- [ ] 借鉴的是内核不是故事？
