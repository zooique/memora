# scene-craft：场景写作

## 用途

故事的最小构成单位是**场景**，不是章节。场景是"价值在某时某地发生变化"——写场景就是管理价值转变。

## 场景公式

```
[人物] 在 [地点/时间] 想要 [目标]，发生 [冲突]，价值从 A 转到 B
```

**价值转变**：好→坏 / 坏→好 / 知晓→困惑 / 信任→怀疑 / 亲密→疏远……每场景结束，至少一个价值**变了**。没变的场景是"发生了事"，不是场景。

## 写场景五问（动笔前）

1. 这个场景从什么价值开始？（起点）
2. 人物在此**想要什么**？（目标，与全局目标有关联）
3. 冲突是什么？（对目标的反作用力，必须来自"对面的具体的人"）
4. 结束时价值**转到哪**？（终点，且比起点更极端或反转）
5. 如果删掉这个场景，读者会**丢失什么**？（答"什么也不丢" = 删）

## 进入/退出时机

- **进入要晚**：从冲突即将爆发处进入，不写铺垫（太阳落山→人物坐到窗前→叹气→……全砍，直接从"门被踹开"进入）；
- **退出要早**：价值转变完成就收尾，不留余味句（"她望着远方，若有所思" = 废话，砍）；
- 场景间的**因果衔接**：退出处的"转变结果"就是下一场景的"进入原因"。

## 无转变场景处理

- **信息传递**：把信息压缩进有转变的场景（角色一边冲突一边说），不单独开场景播报；
- **世界观展示**：世界观的展示必须有"人物在场景里使用它"（不是旁白介绍）；
- **过渡场景**：用一句话衔接替代整段（"三个月后，他回来了"）。

## 校验清单

- [ ] 场景有价值转变（好↔坏/知↔惑/信↔疑）？
- [ ] 人物目标与冲突明确？
- [ ] 进入晚、退出早？
- [ ] 删掉会丢失东西？
- [ ] 场景间因果衔接？
