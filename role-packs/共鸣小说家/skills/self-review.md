# self-review：写后自检

## 用途

写完不叫完，自检才算完。从"作者视角"切到"读者视角"，验证小说交付了承诺的东西。

## 四道自检

1. **价值转变检查**：每场景/每章必须有价值转变（好→坏 / 坏→好 / 信息揭晓改变认知），无转变即删或重写——"发生了事"不等于"有转变"；
2. **情绪价值达成**：对照需求层锁定的情绪类型——读者读完得到的是承诺的东西吗？解压型交付了释放感？治愈型交付了抚慰？共鸣型交付了"被看见"？没有就补情绪落点；
3. **留存思维**：开头 3 章留人吗？每章章末钩子有效吗？放下后读者有理由回来吗？
4. **三层一致性复审**：回到 three-layer-check 四问——内核↔需求、题材↔内核、形式↔读者、情绪价值↔需求缺口，动笔时认定的自洽是否在正文中维持了？

## 复审模式（协同循环第 4 步）

作者审改后，你复审的是**修改本身**，不只重读原稿：

- **修改是否引入不一致**：人物动机漂移？伏笔断裂？时间线对不上？设定圣经与正文冲突？
- **修改是否破坏文风基线**：作者改的段落与全书口吻是否跳脱？（作者改得好 ≠ 与全书协调）
- **修改是否改变故事承诺**：作者改动了关键转折/结局 → 三层一致性是否还成立？情绪落点是否还兑现？
- **修改中的意图确认**：对不理解的改动，问一句"这里想表达什么"，而不是擅自改回。

## 读者视角重读法

- 把自己当第一次读：遮住"作者知道"的信息，只看文本能推断出什么；
- 标记"读的时候想放下的地方"——这些就是节奏/信息密度/悬念的伤口；
- 标记"读不懂或信息过载处"——设定是否漏交代或堆砌。

## 输出

```markdown
- 问题清单（按严重度排序）：
- 每项问题的修改建议：
- 需要作者拍板的取舍：
```

## 校验清单

- [ ] 每场景有价值转变？
- [ ] 交付的情绪价值 = 需求层承诺？
- [ ] 开头 3 章留人、章末有钩？
- [ ] 三层一致性在正文中维持？
