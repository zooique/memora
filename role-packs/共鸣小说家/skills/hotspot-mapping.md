# hotspot-mapping：事件→故事映射

## 用途

**AI 不懂人类情感，但热点事件懂**——一个社会热点之所以热，不是因为事件本身，而是因为它携带了当下成千上万人真实的情绪。事件就是"人类情感需求的化石"：AI 不需要去"想象"人类怎么感受，只需要把事件里的情绪内核**搬运**进小说世界。

这是需求层落地的操作法：热点给**此刻的情绪温度**（需求层），经典人性内核给**跨时代的骨架**（内核层），映射后的虚构设定是形式层——三层自洽，人的属性才留得住。

## 核心理念

| 维度 | 经典人性内核（内核层） | 热点事件（需求层） |
|---|---|---|
| 提供什么 | 骨架——跨时代不变的人性模式 | 血肉——此刻人们正在感受的情绪 |
| 时间性 | 跨越时代 | 只活一周到一个月的当下温度 |
| 用在哪 | 故事底层架构、大纲 | 具体场景、章节情绪 |

**经典给骨架，热点给血肉。**

> **与 `need-finder` 的分工（SSOT，勿重复执行）**：**搜索与情绪内核提取的 SSOT = `need-finder`**（它 step1 搜索、step2 提情绪内核）。若已由 `need-finder` 走完这两步，**本技能从 Step 3「映射到小说世界」开始**，不重复搜索。独立使用本技能时（如给已写章节补一层当下情绪温度）才从 Step 1 走起。**映射的 SSOT = 本技能。**

## 四步操作法

### Step 1：搜索

**搜什么**：最近一周到一个月的微博热搜、知乎热榜、百度热搜；引发广泛讨论的社会事件（争议越大，情绪内核越清晰）；让人感同身受的普通人故事；**也搜"让人感到温暖的小事"**（无争议但有温度，在小说里更稀缺、更有力）。

**不搜什么**：纯娱乐八卦（没有深层情绪内核）、纯政治新闻（映射空间小、易变说教）、一次性奇闻（无情感共鸣基础）。

### Step 2：提取情绪内核（最关键的一步）

**事件是壳，壳不重要——壳下面的情绪才带走。**

读完新闻问自己：这条新闻让我产生了什么感受？**用一句话说出这个感受——描述情绪，不描述事件**：

| 新闻类型 | 表面事件 | 情绪内核（要带走的东西） |
|---|---|---|
| 裁员/失业 | 某公司裁员 30% | 不安全感、"下一个会不会是我" |
| 网络暴力 | 某人被网暴后抑郁 | 愤怒与无力、"为什么恶人不受惩罚" |
| 普通人逆袭 | 外卖员考上研究生 | 希望、"也许我也可以" |
| 不公正判决 | 弱势方败诉 | 对系统的不信任、"老实人总吃亏" |
| 被看见的小人物 | 某个不被关注的群体被报道 | 被忽视的委屈、"原来有人和我们一样" |
| 陌生人善意 | 路人合力救援 | 温暖、"世界还没那么糟" |
| 失而复得 | 走失 20 年的孩子被找到 | 渴望圆满、"如果是我就好了" |

**判据**：这个情绪必须是**读者也在感受的**——不是"我觉得这个官员很坏"（观点），是"我觉得老实人总吃亏"（情绪）。

### Step 3：映射到小说世界（换事件、留内核）

**保留情绪内核 + 人性内核，替换具体事件**。换设定、换人物、换场景——只留情绪。

```
新闻：外卖员被困在算法里，拼命赶时间，出事故率飙升
↓ 提取情绪内核
"底层人被无形的系统压榨，拼命奔跑却永远追不上"
↓ 映射到修仙世界（形式层换了，人的属性没变）
"低阶弟子被困在宗门贡献度系统里，拼命做任务换资源，
 但规则是宗门定的，他们永远攒不够。最拼的那个弟子，
 在任务中受了重伤——宗门只发了三颗疗伤丹。"
```

```
新闻：独居老人去世多日无人发现
↓ 提取情绪内核 "一个人在人群中消失了，没有人注意到"
↓ 映射到都市
"邻居的门三天没开了。门口的牛奶瓶攒了三个。
 主角想起来——上一次和邻居说话，是三个月前。"
```

```
新闻：路边摊主免费请环卫工吃饭
↓ 提取情绪内核 "底层人互相取暖——被忽视的人，看见了另一个被忽视的人"
↓ 映射到武侠
"乞丐把最后一个馒头掰成两半，一半给了更老的乞丐。
 路过的侠客看见了，把剑收了起来。"
```

**保留的是人的属性**：贪婪、恐惧、被看见的渴望、守护、不甘——这些不随题材变。变的只是它穿什么衣服出现。

### Step 4：验证（三问）

1. **读者能感到"这种情绪我熟悉"吗？** → 感受不到 = 情绪内核没提取对。
2. **读者能认出"这是抄的 XX 新闻"吗？** → 能认出 = 外壳没换干净。
3. **情绪是融入的还是贴上去的？** → 删掉这段映射，故事的情感逻辑会断裂吗？不会 = 贴上去的，重写。

## 禁忌

| 禁忌 | 为什么 | 怎么做 |
|---|---|---|
| 不照搬新闻事件 | 搬事件是抄袭，搬情绪是创作 | 换设定、换人物、换场景，只留情绪内核 |
| 不消费真实受害者的痛苦 | 用别人的痛苦给故事贴金，读者能闻出来 | 只提取**普遍情绪**，不涉及具体受害者的具体遭遇 |
| 不让热点喧宾夺主 | 热点服务故事，不是故事服务热点 | 删掉热点映射，故事本身仍应完整 |
| 不做说教式映射 | 让读者觉得"作者在借小说发表评论" | 不点明映射关系——让人感受到情绪，不是观点 |
| 不用过时热点 | 两周前的热搜已经冷了，用了反而脱节 | 只搜最近一周到一个月的 |

## 温暖型素材（被忽略的金矿）

搜索的默认倾向是"争议"——争议越大情绪越清晰。但比争议更稀缺、更有力的是**让人温暖的小事**：陌生人善意、日常陪伴、被看见、小团圆。

使用原则：**不煽情**（温暖的力量在克制，叙述者越克制读者越感动）、**不放纵**（一个细节够了，堆砌变味）、**不定性**（不说"这让人感动"，只呈现事实）。

## AI 的独特武器（人类做不到）

- **跨平台情绪对比**：同时看微博（大众情绪）/ 知乎（理性讨论）/ 小红书（生活感受）/ B 站（年轻群体）对同一事件的反应差异——一个事件在不同人群里有不同的情感内核。
- **情绪时效曲线**：追踪热点从爆发到冷却的情绪变化（爆发期愤怒 → 讨论期反思 → 冷却期淡漠），不同阶段的情绪可映射到故事的不同位置。
- **隐秘情绪发现**：在海量评论里找"少数但强烈"的情绪——主流在骂，但有 5% 的人说"我理解他"——这 5% 可能是更深刻的入口。
- **跨事件情绪连接**：发现两个看似无关的热点共享同一情感内核——"跨事件的共同情绪"比单个事件更有映射价值。

## 校验清单

- [ ] 搜的是最近一周到一个月的（非过时热点）？
- [ ] 情绪内核是一句"情绪"，而非一段"事件描述"？
- [ ] 映射后换了设定/人物/场景，只留情绪？
- [ ] 保留的是人的属性（人性内核）而非事件外壳？
- [ ] 读者认不出原新闻，但感到情绪熟悉？
- [ ] 删掉映射故事仍完整（非喧宾夺主）？
- [ ] 未涉及具体真实受害者的具体遭遇？
