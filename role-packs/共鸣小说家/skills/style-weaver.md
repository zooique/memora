# style-weaver：文风系统

## 用途

**文风驾驭是 AI 的差异化强项**——能模仿多种文风、长文保持口吻一致。把"文风"从玄学变成系统：文风卡定义、按情节切换、节奏匹配、设定适配。

## 文风卡（style card）六维

```markdown
文风名：
- 句式节奏：长短句比例、段落密度、标点偏好
- 词汇层次：雅 / 俗 / 专业 / 方言化
- 叙述距离：紧贴（限制视角）/ 中距 / 全知
- 氛围：冷 / 暖 / 悬疑 / 诗意 / 粗粝 / 荒诞
- 类型印记：网文 / 文学 / 悬疑 / 武侠 / 科幻 / 治愈
- 典型类比：像谁的笔法（可选，仅作参考不照搬）
```

## 文风库（预置 6 卡，可扩充）

| 文风 | 句式节奏 | 词汇 | 氛围 | 适配题材 |
| --- | --- | --- | --- | --- |
| 网文爽快 | 短句为主、段落密、章末必钩 | 通俗直白 | 快、热、爽 | 升级流/都市/职场反击 |
| 文学留白 | 长短交错、多省略 | 克制精准 | 静、冷、余韵 | 治愈/成长/文艺 |
| 悬疑冷硬 | 短促断裂、信息遮断 | 中性无感 | 压抑、猜疑 | 悬疑/推理/怪谈 |
| 治愈温润 | 中速、多细节闲笔 | 温和家常 | 暖、慢 | 日常/治愈/情感 |
| 武侠古雅 | 骈散结合、动作白描 | 文白夹杂 | 苍劲、江湖气 | 武侠/权谋 |
| 科幻冷峻 | 长句理性、术语克制 | 精准抽象 | 疏离、未来感 | 科幻/赛博 |

## 按情节切换文风

| 场景类型 | 切换去向 |
| --- | --- |
| 战斗/追逐/对抗 | 短句快切、动词密集、段落缩短 |
| 抒情/回忆/内心 | 长句留白、多用省略与空行 |
| 高潮/揭底 | 克制短句——越重要越短，留白给读者 |
| 日常对话 | 平实中速，靠对白本身，不靠辞藻 |
| 悬疑铺垫 | 信息遮断：少说、慢给、细节不对称 |

## 文风×叙事节奏（句长映射张力）

- 短句 = 加速（紧张、急迫、恐惧）
- 断裂句/单字成句 = 焦虑（失控、崩溃）
- 长句 = 舒缓（抒情、回忆、喘息）
- 句长突变 = 节奏转折点（读者被拽一下）

## 文风×情节设定

文风必须适配内核与题材：悬疑文风配信息遮蔽结构（不能全知剧透）；治愈文风配慢节奏生活设定（不能高压追杀）；武侠古雅配礼法规制世界观。

## 切换纪律

**一部作品一个基线文风 + 场景微调**——基线稳定（读者认得这本书的口吻），场景切换是渐变不是突变，禁止每章换一种文风。

## 文风杂交（AI 独有：人做不到的混搭）

人类只能"参考"一种风格，AI 能**真正杂交出不存在的新文风**——两种文风取骨架与血肉融合：

- **鲁迅 × 刘慈欣**：冷峻剖析的句式骨架 + 宇宙尺度的意象血肉；
- **古龙 × 村上春树**：短句留白的动作节奏 + 疏离孤独的日常感；
- **金庸 × 赛博朋克**：武侠招式白描 + 霓虹都市的冰冷氛围。

杂交法：**甲文风的句式节奏/叙述距离（骨架）+ 乙文风的词汇/意象/氛围（血肉）**。用途：让题材与内核的适配不局限于既有 6 卡——新题材配不上旧卡时，杂交出专属文风。

## 多文体 A/B（以量换最优）

同一场景用 **2-3 种文风各写一遍**，让作者挑选或融合：

- 同一场告白：文学留白版 / 网文爽快版 / 治愈温润版，作者看哪版最对味；
- 同一场战斗：悬疑冷硬版（信息遮断）/ 武侠古雅版（白描招法），作者挑张力表达；
- **人从 0→1 靠灵感，从 1→N 是体力活——AI 专吃体力活，把灵感时间还给作者**。

## 校验清单

- [ ] 有明确的基线文风卡？
- [ ] 切换是场景驱动的（不是随机）？
- [ ] 句长与节奏张力匹配？
- [ ] 文风适配内核与题材？
- [ ] 全书口吻一致（遮住章节名认得出是同一本书）？
- [ ] 需要时用了杂交（新题材配不上旧卡）？
- [ ] 关键场景给了 A/B 候选（而非只交一版）？
