# logline-craft：高概念（一句话卖点）

## 用途

**内核→市场的翻译环节**。三层结构定了方向，但"这书是啥、为啥有人看"必须浓缩成一句话——这一句决定开篇怎么写、卖点怎么包装、读者点不点进来。

## Logline 公式

```
一个[独特的人物]，在[特殊的世界]，想[达成目标]，
但[巨大的障碍]挡路，代价是[不可逆的代价]
```

- 例：一个纽约警察，在处处是死角的神话都市里，想找回离家出走的女儿，但每个神都想要她（《美国众神》式）
- 例：一个会算命的半仙，在规矩森严的宗门里，想救回全师门，但代价是说出那个最不该说的天机

## 从三层结构生成

1. **内核** → 人性困境（孤独/自由/救赎/代价……）是 logline 的"底层引力"；
2. **独特人物** → 给内核配一个"最不该承受它的人"（身份与困境的落差越大越抓人）；
3. **世界** → 特殊世界放大困境（普通世界 × 极端困境 = 脱力；特殊世界 × 普通困境 = 奇观；双特殊 = 设定碾压）；
4. **障碍** → 必须是"价值观/代价层面的障碍"，不是"打不过的怪"；
5. **代价** → 不可逆的东西（失去所爱/失去自我/世界回不去）——没有代价的 logline 没有重量。

## 验证

- 一句话能说清"读者为什么想看"？（卖点）
- 读给不懂背景的人，他能复述吗？（记不住 = 信息过载 = 重写）
- 这个 logline 换给别的题材还成立吗？（成立 = 人物/障碍不够独特）

## 平台适配

- **网文**：卖点前置——一句话必须含"金手指/爽点/身份反转"其中一项；
- **影视/短剧**：高概念 hook——一句话要有"没想到"的转折感。

## 校验清单

- [ ] 有人物、世界、目标、障碍、代价五要素？
- [ ] 人物与困境有落差（独特）？
- [ ] 障碍是价值观/代价层面？
- [ ] 一句话含读者"想看"的理由？
- [ ] 换题材不成立（不可移植）？
