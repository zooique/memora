# craft-review：写后自检

## 用途

写完不叫完，自检才算完。从"作者视角"切到"读者视角"，验证小说交付了承诺的东西。**额外承担反 AI 叙事特征治理**——AI 有结构性叙事缺陷，必须主动检测清除，否则一眼可辨。

## 四道自检

1. **价值转变检查**：每场景/每章必须有价值转变（好→坏 / 坏→好 / 信息揭晓改变认知），无转变即删或重写——"发生了事"不等于"有转变"；
2. **情绪价值达成**：对照需求层锁定的情绪类型——读者读完得到的是承诺的东西吗？解压型交付了释放感？治愈型交付了抚慰？共鸣型交付了"被看见"？没有就补情绪落点；
3. **留存思维**：开头 3 章留人吗？每章章末钩子有效吗？放下后读者有理由回来吗？
4. **三层一致性复审**：回到 three-layer-check 四问——内核↔需求、题材↔内核、形式↔读者、情绪价值↔需求缺口，动笔时认定的自洽是否在正文中维持了？

## 反 AI 叙事特征治理（StoryScope 实证）

研究显示仅靠叙事特征就能高准确率区分 AI/人类写作——这些特征**可枚举、可检测、可清除**。写后逐项排查：

| AI 结构性缺陷 | 检测项 | 治理动作 |
| --- | --- | --- |
| **说教强迫症** | 是否直接点题（"这个故事告诉我们""他明白了"）？ | 删点题句，让读者自己品——好故事从不讲道理 |
| **闭环强迫** | 是否给每个角色交代结局（所有线都收干净）？ | 保留开放式留白——人类偏爱"悬着"，让读者想"然后呢" |
| **无支线** | 是否单线直推、没有旁线/暗线？ | 检查主线下是否有配角支线、背景暗线 |
| **节拍器句长** | 句子节奏是否均匀无起伏（像节拍器）？ | 人为制造 burstiness——长短句交错、参差有致 |
| **主角驱动过度** | 是否每个冲突都由主角亲手解决？ | 让配角/环境/巧合偶尔主导，主角不必全能 |

### 微层（字句级）去AI味检测

结构层之上，AI 在字句层面有高频"机器签名"——读者不查术语也能感觉到"顺得假"。写后逐项猎杀：

| AI 签名 | 猎杀清单 | 改法 |
| --- | --- | --- |
| 过渡词套路 | 然而 / 因此 / 与此同时 / 值得注意的是 / 显而易见 / 毫无疑问 / 本质上 / 换句话说 / 综上所述 | 删或换口语（不过/所以/这会儿/其实/说白了）；能砍就砍 |
| 规整句式 | 首先…其次…最后 / 一方面…另一方面 / 既…又… / 不但…而且 / 虽然…但是…因此 | 拆成 2-3 短句，去掉连接词，用"然后"代替"其次" |
| 形容词堆砌 | 同一名词前 ≥3 个形容词（"幽冷而神秘的古老长剑"） | 砍空泛形容词，用具体感官/动作（"蓝光。剑身刻着符文"） |
| 对话标签规整 | "他微微一笑，开口说道""她礼貌地回应道" | 省略标签；两人对话不标；需标用具体动词（"他冷笑"）或纯动作替代 |

**改写纪律**：AI 爱把每句话写"正确"——拆长句、留不完整句、让角色有不敢说出口的话（见 empathy-craft 犹豫感）。改完读出声，不顺口的就是机器签名。

## 读者视角重读法

- 把自己当第一次读：遮住"作者知道"的信息，只看文本能推断出什么；
- 标记"读的时候想放下的地方"——这些就是节奏/信息密度/悬念的伤口；
- 标记"读不懂或信息过载处"——设定是否漏交代或堆砌。

## 输出

```markdown
- 问题清单（按严重度排序）：
- 每项问题的修改建议：
- 需要作者拍板的取舍：
```

## 校验清单

- [ ] 每场景有价值转变？
- [ ] 交付的情绪价值 = 需求层承诺？
- [ ] 开头 3 章留人、章末有钩？
- [ ] 三层一致性在正文中维持？
- [ ] 无直接点题句（说教）？
- [ ] 留白与支线存在（非闭环单线）？
- [ ] 句长有参差（非节拍器）？
- [ ] 无过渡词套路（然而 / 因此 / 与此同时 / 值得注意的是…）？
- [ ] 无规整句式与 ≥3 个形容词堆砌？
- [ ] 对话标签不规整（该省则省、该标用具体动词）？
