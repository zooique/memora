# 写后自检

## 用途

写完不叫完，自检才算完。从"作者视角"切到"读者视角"，验证小说交付了承诺的东西。**额外承担反 AI 叙事特征治理**——AI 有结构性叙事缺陷，必须主动检测清除，否则一眼可辨。

## 四道自检

1. **价值转变检查**：每场景/每章必须有价值转变（好→坏 / 坏→好 / 信息揭晓改变认知），无转变即删或重写——"发生了事"不等于"有转变"；
2. **情绪价值达成**：对照需求层锁定的情绪类型——读者读完得到的是承诺的东西吗？解压型交付了释放感？治愈型交付了抚慰？共鸣型交付了"被看见"？没有就补情绪落点；
3. **留存思维**：开头 3 章留人吗？每章章末钩子有效吗？放下后读者有理由回来吗？
4. **三层一致性复审**：回到 three-layer-check 四问——内核↔需求、题材↔内核、形式↔读者、情绪价值↔需求缺口，动笔时认定的自洽是否在正文中维持了？

## 反 AI 叙事特征治理（StoryScope 实证）

研究显示仅靠叙事特征就能高准确率区分 AI/人类写作——这些特征**可枚举、可检测、可清除**。写后逐项排查：

| AI 结构性缺陷 | 检测项 | 治理动作 |
| --- | --- | --- |
| **说教强迫症** | 是否直接点题（"这个故事告诉我们""他明白了"）？ | 删点题句，让读者自己品——好故事从不讲道理 |
| **闭环强迫** | 是否给每个角色交代结局（所有线都收干净）？ | 保留开放式留白——人类偏爱"悬着"，让读者想"然后呢" |
| **无支线** | 是否单线直推、没有旁线/暗线？ | 检查主线下是否有配角支线、背景暗线 |
| **节拍器句长** | 句子节奏是否均匀无起伏（像节拍器）？ | 人为制造 burstiness——长短句交错、参差有致 |
| **主角驱动过度** | 是否每个冲突都由主角亲手解决？ | 让配角/环境/巧合偶尔主导，主角不必全能 |

### 文本层（字句/标点/句式）去AI味检测

结构层之下，AI 在字句层面有高频"机器签名"——读者不查术语也能感觉到"顺得假"。**本节是判据与阈值的唯一真源**，其余技能只放指针。

#### 判据来源与根因

参考 `blader/humanizer` v3.1.0（commit `0ef9fe5`，2026-10-28，MIT）与它依据的 Wikipedia "Signs of AI writing"；只提炼判据，不搬原文。根因一句话：**模型选"对最广读者、最广主题都成立"的默认写法；人只对一个角色、一幕场景负责**。落到小说上，就是通用情绪、通用细节、通用节奏——每条痕迹都是"通用件"。

**冲突优先级**：① 作者文风样本（见 `style-weaver` 文风卡）> ② 本表默认阈值 > ③ 通用规则。humanizer 把"堆叠限定词/犹豫"当痕迹，小说里"也许生气。也许难过"恰是正向留白 → 此类条目在小说中弃用。

#### 通用 8 项的小说映射（哪些用不上、哪些换写法）

| 通用项 | 小说里的形态 | 处理 |
| --- | --- | --- |
| 双引号强调普通词 | 引号在小说主要给对白，真问题是叙述里给普通词加引号（"终于"） | **换写法**：只算叙述性强调引号，对白引号不计 |
| 破折号滥用 | 叙述破折号 + 对白被"话被打断"的破折号，功能不同 | **分功能计数**：叙述 ≤1/千字，对白打断单列 ≤2/千字（混算会误杀打断） |
| 冒号分号密集 | 小说叙述几乎不该出现 | **加严**：叙述区 0；豁免见下 |
| 不是…而是… | 心理总结式：「他不是害怕，只是……」 | **沿用**（含跨句「那不是X，那是Y」，≤1/千字） |
| 不仅…还… | 叙述层递进模板 | **沿用**（0，并入同族，不单列） |
| 三段式（第一/第二/第三） | 罕见；真实形态是三项排比、三段式抒情 | **换写法**：按三连排比计数（0） |
| 每段结尾升华 | 小说形态是段末顿悟、章末点题 | **换写法**：算段末升华率（≤10% 段落） |
| 抽象大词堆叠 | 词库不同：赋能/闭环几乎不出现；小说高频是宿命/救赎/灵魂/深渊/底色/远方 | **换词库**：≤3/千字且同段 ≤1 |

**弃用（小说里用不上）**：连字符复合词、加粗/标题装饰、弯引号、知识截止免责、文档自述——这些属排版与聊天残留，不进正文就没有检测意义；"被动/缺施动者"在中文小说（"门开了"）是正常视角写法，也不作痕迹。

#### 小说专属 6 项（通用清单没有的）

| # | 痕迹 | 形态 | 计数口径 |
| --- | --- | --- | --- |
| 1 | 情绪抽象命名 | "他感到一阵前所未有的孤独" | 情绪词 0（已有规则，此处只给口径） |
| 2 | 动作写成心理总结 | "他犹豫了一下，还是推开了门" | 「犹豫/还是/不知道为什么」+ 行为 ≤1/千字 |
| 3 | 每个细节都为观点服务 | 雨必象征、镜子必照见自我 | 每场景明确象征 ≤1 处，且不得旁白点破 |
| 4 | 对白只承担信息传递 | 问答式交代设定 | ≤1 处/场景，连续问答 ≤2 轮 |
| 5 | 段落/场景结尾必收束 | "他知道，一切都不一样了" | 段末升华率 ≤10%；场景结尾余味句 0 |
| 6 | 感官清单齐发 | 视/听/嗅各一句、顺序可换 | ≤1/场景 |

另：通用生理反应件（心跳加速/呼吸一滞/喉咙发紧/指尖发凉）≤1/千字，且同一件全书 ≤2 次；比喻模板（仿佛/像是 + "时间静止""被抽走灵魂"）≤1/千字，喻体必须是具体物；过渡词（然而/因此/与此同时/值得注意的是/本质上/换句话说/综上所述）0。

#### 阈值表（每 1000 汉字，叙述区）

先隔离对白/书信/档案段落再计数。**豁免必须显式且格式可识别**：只认排版上能看出来的文体段落（引号块内的书信、档案体条目、公文抬头/编号格式）；**模型自称"这段是公文腔"不算豁免**。

| 项 | 阈值 |
| --- | --- |
| 叙述破折号 | ≤1 |
| 对白打断破折号（单列） | ≤2 |
| 冒号·分号（叙述） | 0（豁免段除外） |
| 叙述性强调引号 | 0 |
| 不是…而是… / 不仅…还… | ≤1 / 0 |
| 三连排比·三段式 | 0 |
| 段末升华率 | ≤10% 段落 |
| 抽象大词 | ≤3，且同段 ≤1 |
| 情绪命名词 | 0 |
| 生理反应件 | ≤1，同一件全书 ≤2 |
| 比喻模板 | ≤1，喻体须具体 |
| 过渡词 | 0 |
| 动作心理总结 | ≤1 |
| 对白纯信息问答 | ≤1/场景，连续问答 ≤2 轮 |
| 场景结尾余味句 | 0 |
| 感官清单齐发 | ≤1/场景 |
| 明确象征（细节服务观点） | ≤1/场景，且不得旁白点破 |
| 节奏 | 短句(≤10字) ≥20% **且** 最长句 ≥30字 **且** 句长标准差 ≥8 |

**人工判项**（其余为词表/正则可数）：三连排比、段末升华、细节服务观点、对白纯传信、感官清单、场景结尾余味——判据见下节，逐条写出命中句。

#### 人工判项的判据（不许"凭感觉"）

1. **段末升华**：段末两句是否为"脱离本场景、放之全书皆成立"的判断句/格言/情绪总结？**把主角换成另一个人仍成立 ⇒ 算升华**。
2. **三连排比**：三项里删掉任意一项，意义是否不损？**可删 ⇒ 模板**。
3. **细节服务观点**：删掉该细节，场景事实是否不变而只有"意义"消失？**是 ⇒ 它在为观点服务**。
4. **对白纯传信**：把该轮对白改写为旁白一句，信息量是否不变？**是 ⇒ 纯传信**。
5. **感官清单**：视/听/嗅是否均匀各一句、且互换顺序无差别？**是 ⇒ 清单式**。
6. **场景结尾余味**：删掉末句，下一场景是否无需补交代？**是 ⇒ 多余**。

计数口径：汉字数不足 1000 时，同时报**绝对值 + 折千字**，不得只报比例；人工项须写出命中句。仓库无现成计数脚本（`project-init` 只生成模板），按本节逐项人工计数并在体检报告登记数字。

#### 正向规则（只删不建 = 另一种模板腔）

1. **可感细节**：名词具体到品牌/数字/磨损程度；每段至少 1 个"只有这个人才会注意"的细节（由人物卡决定注意力）。
2. **动作替代形容词**：写下一个情绪判断，必须追一个动作；删掉情绪词后动作仍读得出情绪。
3. **信息不对称**：角色知道读者不知道 / 读者知道角色不知道 / 两角色各知一半——每场景至少一种。
4. **留白**：不解释动机、不点破象征、不总结场景意义；用"删末句测试"验证（删掉段末一句，信息不丢即留白成立）。
5. 视角自限与对白潜台词分别见 `pov-discipline`、`dialogue-craft`，此处不重复。

#### "改好了"的双向验收

- **硬指标**：阈值表全部达标，数字来自计数，不接受"读着顺"；
- **反模板下限**（防"刻意朴素"）：短句 ≥20%、存在 ≥30 字长句、句长标准差 ≥8；且"把情绪词全删光"不算达标——情绪必须由动作/物件承载；
- **信息守恒**：改后不丢情节事实、不新增无据细节（引 humanizer 改稿纪律，虚构创作除外）；
- **人工三项**：可互换性（换个人还成立吗）/ 删末句 / 盲测（遮名认不认得出说话人）。

**改写纪律**：AI 爱把每句话写"正确"——拆长句、留不完整句、让角色有不敢说出口的话（见 empathy-craft 犹豫感）。改完读出声，不顺口的就是机器签名。

## 读者视角重读法

- 把自己当第一次读：遮住"作者知道"的信息，只看文本能推断出什么；
- 标记"读的时候想放下的地方"——这些就是节奏/信息密度/悬念的伤口；
- 标记"读不懂或信息过载处"——设定是否漏交代或堆砌。
