# polish-method：修改打磨方法论

## 用途

初稿不是作品。打磨是把"写完的"变成"能交付的"——删掉作者舍不得但读者不买账的部分，让节奏、文风、情绪都到位。

## 作者反馈 → 修订策略（先定位，再动手）

作者给反馈时往往是一句模糊感受（「这段没感觉」「太拖了」「像 AI」）。**先把它翻译成问题类型，再决定动哪一轮**——拿到就改，多半在改错的地方。

| 作者说 | 大概率问题 | 定位与改法 |
| --- | --- | --- |
| 「没感觉 / 不够打动」 | 情绪没落进文字 | 查 `empathy-craft`：有情感锚点细节吗？反应是人物指纹还是通用件？再查叙述者是否留有犹豫（结论没给满） |
| 「像 AI / 太顺了」 | 机器签名 | 走本文「去AI味三阶段」+ `craft-review` 微层检测（过渡词 / 规整句式 / 形容词堆砌 / 对话标签） |
| 「太拖了 / 看不下去」 | 进入点太晚或密度不足 | 进入点砍前段铺垫 30%；查每 500 字是否「有件事发生了」；参照单章篇幅基线（见 `longform-guard`） |
| 「太快了 / 没反应过来」 | 铺垫不足或情绪没停 | 高潮前补蓄水；情绪落点停久一点（见 `emotion-wave`） |
| 「太假了 / 太刻意」 | 裸巧合或缺因果 | 补回溯锚定（前文埋因）或性格催化（是他这性格必然这么做） |
| 「主角不像他 / 配角像工具人」 | 行为脱离动机 | 回 `character-sheet` 核目标 / 需求 / 缺陷；给配角一个自己的小欲望 |
| 「看不懂 / 信息乱」 | 设定没随人走 | 删旁白式设定说明，改由人物遭遇 / 对话带出（见 `world-builder`） |
| 「对话分不清谁在说」 | 语言指纹缺失 | 回 `dialogue-craft`：遮住名字能认出吗？语气即身份 |
| 「视角乱 / 不知道谁在想」 | POV 失守 | 回 `pov-discipline`：一场景一视角，禁止 head-hopping |

**纪律**：一轮只改定位到的那一类问题，不混着改；改完回到「读者视角重读」验收。三轮仍不通过 → 问题多半在结构层，回大纲而非继续润色。

## 三轮打磨法

### 第一轮：删冗余（结构层）

- 删"无价值转变"的场景（见 scene-craft）；
- 删重复信息（说过两次的设定/人物/情绪只留一次）；
- 删解释腔（"他其实很生气，因为他……" → 删，让行为说话）；
- 删角色自言自语式心理独白，能靠动作表达的不写内心。

### 第二轮：收紧节奏（张力层）

- 检查每个场景的**进入点**是否够晚（前段铺垫砍掉 30%）；
- 检查章末钩子是否有效（价值转变未完成？）；
- 高潮前有无拖沓（大高潮前 3 章开始加速）；
- 句长检查：该紧张的地方是不是长句太多（该短没短）。

### 第三轮：润色（文风层）

- 动词换准（"走"→"踱/蹭/挪"按情绪）；
- 删形容词堆叠（一个动词顶三个形容词）；
- 对白顺口：读出声，不像人会说的改掉；
- 情绪落点检查：该停的地方有没有留白（见 emotion-wave）。

## 去AI味三阶段（写后必过）

第三轮润色偏向文风，这里单列 AI 专属的三道清除关——AI 文本有可枚举的"机器签名"，读者一眼辨。逐段过：

### 阶段一：删旁白式感知

删掉"谁感知到了什么"的宣告词，直接写感知内容：

> 他感到 / 看见 / 听到 / 发现 / 意识到 / 注意到 / 觉得 / 认为 / 心想

- 改前：他感到一阵寒意从背后袭来。
- 改后：背后一阵寒意袭来。

### 阶段二：删情绪形容词

删"愤怒 / 悲伤 / 恐惧 / 绝望 / 狂喜 / 温柔 / 冷漠 / 震惊"等直接情绪词，用物象/动作承载（详见 empathy-craft 陈述→展示）：

- 改前：他愤怒地握紧了拳头。
- 改后：拳头攥了一夜，指节青白。

### 阶段三：检查以人带事

逐段查：①连续 3 句以上世界观说明 → 改对话/行动带出；②抽象概念先于具体人物 → 调顺序，人物在前；③旁白式判断句（"他是一个……""这个世界……"）→ 删，让读者自己发现。

**自检**：全文无"他看见/感到/觉得"、无直接情绪形容词、无连续 3 句以上设定说明。

## 读者视角重读

- 隔一天再读（或请 AI 以读者身份读）；
- 标记"想放下的地方"——这些是节奏/信息密度的伤口；
- 标记"读不懂/信息过载处"——设定漏交代或堆砌；
- 标记"情绪没被触动处"——对照需求层的情绪承诺，缺的补落点。

## 打磨纪律

- **删比改多**：初稿普遍偏肥，第一轮目标砍 10-20%；
- **一个场景一个作用**：保留最有价值转变的那个，其余并掉；
- **打磨不是重写**：结构问题回大纲层解决，不动文风层硬撑；
- **每轮只做一件事**：删冗余时不想润色，润色时不再删——分轮做，不混。

## 校验清单

- [ ] 三轮各完成一遍（删/紧/润）？
- [ ] 初稿删减 10-20%？
- [ ] 无解释腔/无重复信息？
- [ ] 读者视角重读过，伤口已修？
- [ ] 情绪落点齐全（对照需求层承诺）？
- [ ] 去AI味三阶段过了（无旁白式感知 / 无直接情绪形容词 / 无以人带事问题）？
