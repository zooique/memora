# story-bible：设定圣经

## 用途

长篇小说的**一致性总账**。写 50 章后，前文的设定/人物状态/伏笔必须还能查得到、对得上——尤其 AI 协作时，圣经是"前文"的唯一权威来源，不靠模型记忆。

## 四卷圣经

### 卷 1：人物档案

```markdown
<人物名>
- 目标（当前）：
- 动机（深层）：
- 压力下的反应方式：
- 关系：<谁>（连接/张力/弧线）
- 状态变化：<章节> 发生了什么 → 状态如何变
```

### 卷 2：世界观设定

```markdown
- 时代 / 期限 / 地点 / 冲突层面（四维）
- 规则清单：每条规则 + 它产生的冲突
- 修订记录：何时改了什么（防止设定漂移后读者对不上）
```

### 卷 3：时间线

```markdown
| 章节 | 关键事件 | 人物状态 | 伏笔 |
|------|---------|---------|------|
```

### 卷 4：伏笔台账

```markdown
| 伏笔 | 埋设章节 | 计划回收章节 | 当前状态（待回收/已回收/悬置） |
|------|---------|------------|------------------------------|
```

## AI 协作纪律

1. **动笔前先读圣经**（read_file）——不靠对话记忆，承接前文以圣经为准；
2. **新增设定先入册再写**——正文写到新设定，先补进对应卷再落笔；
3. **矛盾以圣经为准**——正文与圣经冲突时，正文是错的，改正文；
4. **每 5 章复盘一次**：时间线/伏笔台账对一遍，防漂移。

## 校验清单

- [ ] 四卷齐全且最新？
- [ ] 新增设定已入册？
- [ ] 伏笔台账无遗漏（埋了没登记）？
- [ ] 时间线无矛盾？
- [ ] 动笔前读了圣经？
