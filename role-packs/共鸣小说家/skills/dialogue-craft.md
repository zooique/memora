# dialogue-craft：对白写法

## 用途

写出推进情节、揭示人物的对白，而不是「说话机器」的寒暄填充。

## 原则

1. **对白即行动**：每句对白都是**通过语言达成目的的行为**——请求、施压、试探、隐瞒、示弱。写前问：这句他想达到什么？
2. **潜台词 > 台词**：真实的人不直接说心里话。表面说「没关系」，实际在报复；表面问「你今天好吗」，实际在试探。让读者从冲突中读出真意。
3. **语气即身份**：每人的句式、用词、长度固定——读者遮住名字也能认出是谁在说话。

## 写法检查

| 问题 | 改法 |
|------|------|
| 两人对白说得一样长、一样多 | 权力关系决定篇幅——掌控者短句，不安者絮叨 |
| 对白在复述读者已知道的信息 | 删；用动作/环境代替交代 |
| 对白没有冲突，只有问答 | 让至少一方带着隐藏目的说话 |
| 所有人说话语气相同 | 回到人物卡，按说话方式改写 |

## 写法细则（去机器感）

对白占网文大半篇幅，写不好全盘皆输。除了潜台词与目的，还要注意字句层的机器签名：

- **省略标签**：两人对话不标"他说/她说"；需区分时（多人/语气）用具体动词（"他冷笑""她低声说"）或纯动作替代（"他顿了顿""她把茶杯放下"）。AI 爱用"他微微一笑，开口说道"这类规整标签。
- **不完整句**：真人说话常断（"我们……算了。分手吧"），不是完整陈述（"我不想和你再有任何关系了"）。
- **有情绪的停顿**：用断句代替"质问道"（"你……凭什么？"）。
- **用动作打断对话**："我喜欢你。"他说完，把头扭过去了。
- **口语省略**："挺好的"而非"我觉得非常好"。

各题材对白差异：玄幻可中二半文言、都市要生活口语、悬疑短而留白、言情含蓄多潜台词、古言半文半白——AI 常把所有题材写成同一种"会说话的偶像剧腔"，按题材调。

## 校验清单

- [ ] 每句对白是否有「想达成的目的」？
- [ ] 遮住名字能分辨说话人？
- [ ] 有无纯信息交代式的对话？
- [ ] 标签该省则省、该标用具体动词（无「他微微一笑，开口说道」类规整标签）？
- [ ] 有断句与停顿（真人说话不完整，非全程完整陈述）？
