# empathy-craft：共情技法

## 用途

**共情是 AI 最弱的环节**——模型默认写"统计中心的反应"（心跳加速、泪流满面、胸口一热），这些是通用件，谁都能用，谁都不打动。共情不能靠"想共鸣"，要靠方法：把"打动人"拆成可执行的技法。

## 五个技法

### 1. 情绪逻辑（反应指纹）

每个人都有自己应对情绪的方式——有人压力下用幽默转移，有人进入照顾模式，有人外化，有人内化到看不出。**写谁，就按谁的情绪逻辑反应**：

```markdown
人物：<名字>
- 压力下的第一反应（幽默/照顾/外化/内化/沉默）：
- 最害怕被看穿的时刻：
- 情绪失控时的具体行为（不是形容词）：
```

### 2. 陈述→展示（情感锚点）

**禁止直接写情绪名词**（伤心/愤怒/害怕/开心）。情绪藏在动作、细节、他人反应里——每场景找一个细节把核心情绪"挂"住：

- ✗ "他非常愤怒"
- ✓ "他把门摔上的时候，玻璃震了一下"
- ✗ "她哭了"
- ✓ "庆功宴上有人开了三瓶酒，她那杯一直没动"

### 3. 情感轨迹

情绪不是平的——写前给方向，让情绪有起伏：

```markdown
情感轨迹：初始（克制/否认）→ 中途（动摇/试探）→ 最后（本音/崩溃/接纳）
```

### 4. 潜台词

对话表面说 A，实际在要 B；真意藏在动作里。台词里说破 = 读者不参与 = 无共鸣：

- ✗ "他问：'你真的要走吗？'"
- ✓ "他说：'你真的要走吗？'声音比平时低了一度。烟灰掉在袖子上，他没有掸。"

### 5. 可互换性测试

**这段反应换个人、换本小说还成立吗？成立 = 通用 = 重写。** 好反应是指纹不是证件照——硬汉侦探和初恋少女面对危险，反应绝不共用同一套生理描写。

## 叙述者的犹豫与克制（AI 最深的破绽）

前 5 个技法解决"情绪落进文字"。但 AI 文本还有一层更深的机器感，不在字面上，在**叙述者的姿态**：AI 没有不敢写的东西，每句话都"算对了"，天然一种"毋庸置疑"的气场。真人写作会犹豫、会克制、会怕——这些不是缺陷，是人味最浓处。

四个注入法：

1. **结论不给满**：AI 替读者下结论（"他明白了——这一切都是谎言"）；人类留半步（"他好像明白了什么。但没说出来"）。让读者自己得出结论。
2. **叙述者承认不确定**：AI 全知（"她心中充满复杂情感"）；人类有限（"他看了半天，不知道她什么表情。也许生气。也许难过"）。观察者本就看不清。
3. **克制收尾**：AI 爱把每段情感收束完整（像作文结尾）；人类常留一段没说完的收束（"太阳快落了。他走了。门没锁"）。读者带着没说完的离开。
4. **角色不敢说**：AI 角色想说就说（"我要离开这里"）；真人没说出口的远比说出的多（"他想说什么。嘴动了动，又闭上了。'……算了。'"）。把没说出口的写出来就是人味。

**自检**：①有没有一句是叙述者替读者下的结论？②有没有一处叙述者承认"我不确定"？③有没有一段对话角色把话全说完了？有则补回犹豫的痕迹。

## 演出纪律（写稿时遵守）

- 情绪只展示不命名：禁止"伤心/难过/愤怒/开心"等直接形容词；
- 感情越强烈，动作越轻、台词越少（高张力 = 克制）；
- 让读者在自己心里**生成**情绪，作者不代劳。

## 校验清单

- [ ] 这段反应只属于这个人物（换了人不成立）？
- [ ] 场景有情感锚点细节挂住核心情绪？
- [ ] 情绪轨迹有起伏（不是平的）？
- [ ] 对话有潜台词、真意在动作里？
- [ ] 全文无直接情绪形容词？
- [ ] 叙述者留有犹豫痕迹（结论没给满 / 承认不确定 / 克制收尾 / 角色有不敢说的话）？
