# three-layer-check：三层一致性总检

## 用途

动笔前的质量闸门。三层各自能跑通不难，难在互相匹配——这里检查"整部小说自洽"。

## 检查四问

1. **内核 ↔ 需求**：这个内核真的承接了目标读者的痛点吗？（还是自嗨）
2. **题材 ↔ 内核**：这个题材能把内核讲透吗？（"规则与自由"配规则怪谈可以，配无冲突日常不行）
3. **形式 ↔ 读者**：文笔/节奏/类型常规符合目标读者的阅读习惯吗？（网文读者 vs 文学读者完全不同）
4. **情绪价值 ↔ 需求缺口**：读者读完后，得到的是他缺的那样东西吗？（解压的缺口不能交付烧脑）

## 检查清单

- [ ] 三层各自成立？
- [ ] 内核↔需求适配有据？
- [ ] 题材能承载内核？
- [ ] 交付的情绪价值 = 需求缺口？
- [ ] 不一致处有明确取舍说明？
