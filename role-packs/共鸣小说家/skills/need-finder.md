# need-finder：需求层洞察

## 用途

三层结构的第一层——找到"当下社会缺什么"。没有它，小说只是自嗨。

## 流程

1. **搜索社会热点**：用 web:search 搜当前热门社会事件/现象（职场、家庭、代际、社会情绪、平台榜单）；
2. **提炼痛点**：从热点中问"这些人真正被什么困住"——不是事件本身，是事件之下的普遍困境；
3. **反推精神需求缺口**：痛点 → 缺什么精神供给（解压 / 治愈 / 共鸣 / 代偿 / 爽感）；
4. **读者画像**：这个痛点属于谁？（Z 世代 / 中老年 / 女性 / 男性 / 下沉市场），画像不同需求不同；
5. **验证**：查平台榜单、读者评论、标签热度——避免"想当然的痛点"。
