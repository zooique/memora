# pov-discipline：叙事视角纪律

## 用途

视角回答一个问题：**这一段，是谁在经历？** AI 写叙事最容易犯的硬伤不是文笔，是**同一段里跳进两个人的内心**——读者立刻出戏，且这种错很难靠润色发现（每句单看都对）。

视角也是**信息不对称的总开关**：读者知道什么、不知道什么，全由「镜头装在谁身上」决定。`style-weaver` 的「悬疑冷硬 = 信息遮断」、`pacing-hook` 的「信息遮断」都依赖本纪律——**没有 POV 纪律，遮断就无从谈起**。

## 三种基本选择

| 视角 | 读者能看到 | 适配 | 风险 |
| --- | --- | --- | --- |
| **第一人称** | 只有「我」的所见所想 | 强代入、强忏悔/回忆腔、悬疑（天然信息受限） | 无法写「我」不在场的戏；容易变成自说自话 |
| **第三人称限制** | 只进入当前 POV 人物一人的内心 | 大多数商业小说默认选项 | 换人必须换场景（见切换纪律） |
| **第三人称全知** | 可进入多人内心、可评论 | 史诗/群像/需要宏观俯瞰 | AI 用全知最容易滑向「说教 + 总结」，且削弱悬念 |

**默认推荐**：第三人称限制。**不要为了"方便"选全知**——全知是风格选择，不是偷懒通道。

## 四条铁律

1. **一场景一 POV**：一个场景（连续时空内的一段戏）只进入一个人的内心。想写另一个人的反应，用**外部可见的东西**——动作、表情、台词、沉默（这也正是 `empathy-craft` 的「陈述→展示」）。
2. **禁止 head-hopping**：同一段/同一场戏里，不许「他觉得……而她其实在想……」。这是视角的头号事故。
   - ✗ 「林峰盯着她，怀疑她已经知道真相。而她心里正盘算着怎么开口。」
   - ✓ 「林峰盯着她。她端起茶杯，没喝，又放下。——她在盘算什么，他看不出来。」
3. **切换只在边界**：POV 只在**场景切换或章节切换**时换人，不在段落中间换。切换后第一段必须让读者立刻知道换人了（用名字/称呼/重置环境锚点）。
4. **切换要有标记**：换 POV 时给一个明确信号——空行 + 新场景的物象锚点，或（多 POV 长篇）章首标注 POV 人物名。别让读者猜。

## POV 人物怎么选

一场戏给谁当 POV，按这个顺序判断：

1. **谁的经历张力最大**——不是谁最重要，是**谁在这场的得失最剧烈**（失去最多/赌注最大的那个）；
2. **谁知道得最少**——想制造悬念，就选知道得最少的那个人当 POV（读者跟他一起蒙在鼓里）；
3. **谁的变化最关键**——价值转变发生在谁身上，镜头就给谁（见 `scene-craft` 的价值转变）。

反例：高潮戏给旁观者当 POV，等于把最激烈的内心戏推远——除非你要的就是「旁观者视角的无力感」。

## POV 与信息不对称（悬疑/反转的地基）

- **读者知道 ≤ POV 人物知道**（限制视角下）。POV 不知道的，读者不许知道。
- **遮断靠选 POV，不靠藏文字**：很多"悬疑"写不出来，是因为 POV 选了知道内情的人 → 无悬疑可写。
- **反转的提前量**：想让读者最后才懂，就把线索放在 POV 人物**看见但没理解**的地方（读者也看见，但同样没往那想）——事后回想才成立的线索最有力。

## 多 POV 长篇的额外纪律

- **一章一 POV 为默认**，需要同章双 POV 时必须有明确分隔与标记；
- **POV 人物数量收敛**：主 POV 不超过 3-4 个，其余用外部视角写（否则读者记不住谁是谁）；
- **配角 POV 慎用**：给配角开 POV 必须有理由（提供主角看不到的关键信息），否则是稀释（见 `relationship-web`）。

## 执行协议（谁 / 何时 / 产出什么）

> 本技能是成文环节的**既定步骤**（persona 阶段 6 点名），不是后台自动触发——每次 `scene-craft` 产出章节后、进入打磨阶段前执行一次。判据仍以本文四条铁律为准，此处只编排不复制。

**输入**：待检章节全文 + 本章 POV 人物名单（多 POV 长篇在章首标注）。

**执行步骤（确定性顺序）**：

1. 标注本章 POV 人物；
2. 逐场景过四条铁律（一场景一 POV → 无 head-hopping → 切换只在边界 → 切换有标记）；
3. head-hopping 检出 → 按「✗→✓」示例改写为外部可见行为（动作 / 表情 / 台词 / 沉默）；
4. 信息不对称复核：读者知道 ≤ POV 知道；遮断失效处反向验证 POV 人物选择。

**产物**：写入 `<工程>/06-体检/01-POV审计.md`（每章一条：POV 人物 / 违规 / 改前→改后 / 结论）。正文改动落 `05-正文`，审计留痕落 `06-体检`——产物与权威源分离，沿用 project-init 骨架；`06-体检/` 下产物按两位序号递增命名（本技能为 01），新增体检类产物顺延，不并列另起。

**回跳**：检出 ≥2 处 head-hopping → 回 `scene-craft` 补「外部可见行为」；POV 选择致悬念失效 → 回 `style-weaver` 换视角方案。

## 校验清单

- [ ] 每个场景只进入一个人的内心（无 head-hopping）？
- [ ] POV 只在场景/章节边界切换，且切换有标记？
- [ ] POV 选的是「得失最剧烈 / 知道得最少 / 变化最关键」的人？
- [ ] 读者知道的不超过 POV 人物知道的（信息遮断成立）？
- [ ] 多 POV 时主 POV 数量收敛（≤3-4）？
- [ ] 换成全知视角是有意的风格选择，而非为省事？
