# world-builder：世界观构建

## 用途

故事发生的"世界"怎么搭。核心原则：**世界越小、钻研越深，越自由**——越具体的世界越能自然产生冲突，越不容易掉进陈词滥调。

## 麦基四维设定

1. **时代**：故事发生在什么历史时期？这个时期的社会规则、物质条件、价值观是什么？
2. **期限**：故事持续多久？（几小时 / 几天 / 几年）——期限越短，紧迫感越强；
3. **地点**：在哪个物理空间？城市/乡村、室内/户外——空间限制即冲突来源（密室比广场更出戏）；
4. **冲突层面**：冲突主要发生在哪一层——内心 / 人际 / 社会 / 制度 / 超自然？层面决定世界的"攻击方式"。

## 设定原则

- **设定服务内核与题材**：世界观是内核的具象化容器——"规则与自由"内核配制度异化的世界（规则怪谈/职场/仙侠修行体系），不配无冲突的日常流水；
- **限制力 > 自由度**：好设定是"能产生冲突的约束"，不是百科全书——每条设定问一句"它让什么冲突成为可能？"答不上就删；
- **只写用得上的**：设定不在正文堆砌，只展示与情节/人物相关的部分（冰山原则）——作者掌握全貌，读者只见露出水面的一角。
