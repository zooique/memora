# longform-guard：长篇防崩

## 用途

短篇靠灵感，长篇靠**工程**。写 50 万字崩掉的不是文笔，是规划——卷部结构没留余量、大纲写死细节、设定漂移、体力透支。本技能防这三类崩。

## 卷/部规划

- **以卷为单元**：每卷 = 一个完整的冲突周期（起→承→转→合），卷末有阶段性了结 + 新钩子（跨卷张力）；
- **卷内留缓冲**：每卷计划内容只占该卷容量的 70%，留 30% 给角色"活"出来的意外（人物会自己长出来，写死反而假）；
- **全书 2-3 个大高潮**：分布在卷末/中后段，不要每卷都拉满（情绪波浪线原则）。

## 大纲预留

- **大纲是路线图不是剧本**：只定"每卷解决什么冲突、谁站在对面、价值怎么转"，不写死具体对话和细节；
- **结局留两种可能**：动笔时定"预设结局"，写作中允许人物偏离后改到"更真实的结局"——偏离要登记（outline-expand 纪律）；
- **预留"发现"的空间**：好长篇的惊喜来自写的过程中发现——大纲别把路封死。

## 设定漂移防护

- **设定圣经是唯一权威**（见 story-bible）：矛盾时以圣经为准，改正文不改圣经；
- **新设定先入册再写**：写到新设定，先登记四卷再落笔；
- **每 5 章复盘**：时间线/伏笔台账对一遍，发现漂移立即标记（这是允许的，但要"知道自己在漂"）；
- **人名地名清单**：出现一次以上的专名登记在册，防"王磊"变"王雷"。

## 连载体力管理

- **断更保护**：每章末留"下一章必写钩子"（即使断更，回来有抓手）；
- **章节模板**：每章固定节奏（开场接续→进展→转变→钩子），写的时候不用重新设计；
- **每卷完整体检**：卷末做一次全卷复盘（节奏/情绪/伏笔），发现问题在下一卷补。

## 单章篇幅密度（体积感红线）

卷部规划管宏观，单章要管**体积感**——AI 写场景天然偏短（一场戏八百字就写完了）或注水（同一情绪反复写）。无基线即无红线。

**基线（动笔前按类型定）**：

| 类型 | 单章基线 | 说明 |
| --- | --- | --- |
| 网文（番茄 / 起点等） | 2000-3000 字 | 章章有钩，宁短勿拖 |
| 出版向文学 | 3000-5000 字 | 允许慢，但每章须有价值转变 |
| 短篇 / 中篇 | 单章不低于 1500 字 | 太短会碎 |

**红线**：

- **连续 3 章低于基线 60%** → 场景没展开，回 `scene-craft` 补动作 / 对话 / 感官 / 内心四维；
- **高于基线 150%** → 检查是否同一价值转变写了两遍（删重复，不是硬砍）；
- **单章无价值转变** → 不论字数都重写（见 `scene-craft`）。

**纪律**：篇幅是结果不是目标——先问「这章的事说完了吗」，再用基线校准；**为凑字数注水比写短更致命**。

## 校验清单

- [ ] 每卷有完整冲突周期 + 跨卷钩子？
- [ ] 单章篇幅在基线内（无连续过短 / 注水）？
- [ ] 卷内留 30% 缓冲？
- [ ] 大纲是路线图、结局留可能？
- [ ] 设定以圣经为准、新设定先入册？
- [ ] 断更保护 + 卷末体检？
