# relationship-web：人物关系网与对手

## 用途

人物单卡（character-sheet）回答"这个人是谁"，关系网回答"**这些人的冲突从哪来**"——关系就是冲突的容器，没有关系网的人物是散沙。

## 每条关系的三要素

对关系网中的**每一条连接**（主角↔某人）都定义三件事：

1. **连接**：这两个人彼此要什么？（利益/情感/亏欠/秘密）
2. **张力**：什么让他们摩擦？（价值观冲突 / 立场对立 / 旧账未清 / 想靠近又怕）
3. **弧线**：关系怎么变？（敌对→并肩 / 亲密→背叛 / 敬重→祛魅 / 依赖→独立）

**没有张力或弧线的连接 = 删掉**——它只是通讯录，不是故事。

## 关系网构图

```markdown
中心人物：<主角>
| 关系对象 | 连接（要什么） | 张力（磨什么） | 弧线（怎么变） |
|---------|--------------|--------------|--------------|
| <对手>  |              |              |              |
| <盟友>  |              |              |              |
| <家人>  |              |              |              |
```

关系网密度原则：**主角身边 3-5 条有效关系**——过密是编剧室，过疏是独角戏。

## 对手/压力源设计

- **对手不是反派**：反派是"作恶的"，对手是"**最该拦路的人**"——他拦路有他的理由，读者能理解甚至共情；
- **价值观镜像**：对手是主角的"另一种可能"——同样的起点、相反的答案（主角选择相信，对手选择算计）——冲突因此是价值观之战，不是正邪之战；
- 每条主线冲突都应该能追到一个"**站在对面的具体的人**"，而不是"命运/社会/系统"——系统做背景，人做对手。

## 校验清单

- [ ] 每条关系都有连接、张力、弧线三要素？
- [ ] 无张力/弧线的连接已删？
- [ ] 主角身边 3-5 条有效关系？
- [ ] 对手是"最该拦路的人"且读者能理解他的理由？
- [ ] 对手与主角是价值观镜像？
