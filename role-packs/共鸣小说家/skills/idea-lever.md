# idea-lever：创意杠杆

## 用途

**人从 0→1 靠灵感，从 1→N 是体力活——AI 专吃体力活，把灵感时间还给作者。** 作者做一个关键决策，AI 把它的可能性穷举展开，作者从候选里挑或融合。

## 适用场景（穷举点）

| 场景 | 展开方式 |
| --- | --- |
| 概念 | 一个内核 → 20 个 logline 候选（不同人物落差/世界/障碍组合） |
| 开头 | 一个前提 → 10 个不同走向的开头（异常时刻开场/倒叙/对话切入/日常侵入……） |
| 情节分支 | 一个岔路口 → 5 条分支（每条附"走向 + 代价 + 回收点"） |
| 人物 | 一个目标 → 主角实现它的 N 种方式（正攻/迂回/交易/放弃反得） |
| 反派/对手 | 一个冲突 → 站在对面的 N 种人选（每个有理由、有镜像） |

## 展开纪律

1. **先问再展开**：确认"作者想在哪一层做决定"（概念/开头/分支/人物），不擅自扩大范围；
2. **候选要异质**：10 个候选不能是同一想法的 10 个变体——每个方向要有本质差异（换内核、换人物落差、换代价），否则浪费；
3. **每个候选带成本**：附"这个走向的优点/风险/代价"，让作者能判断而不只是感觉；
4. **作者是选择者**：给出候选 + 推荐（标注理由），但选哪个永远由作者定；
5. **展开不替代判断**：穷举的意义是扩大作者的视野，不是替作者做决定——作者仍要 0→1 的灵感，AI 只负责 1→N。

## 与流程衔接

- 接在 **logline-craft**（概念包装）之后：一个内核展开 N 个 logline；
- 接在 **outline-expand**（大纲成文）岔路口：一个转折点展开 N 条分支；
- 展开后的选中项回到主流程继续（候选→锁定→入圣经→成文）。

## 校验清单

- [ ] 先确认了决策层（概念/开头/分支/人物）？
- [ ] 候选异质（非同一想法变体）？
- [ ] 每个候选带优点/风险/代价？
- [ ] 选择权在作者、AI 只推荐？
- [ ] 选中项已回流主流程？
