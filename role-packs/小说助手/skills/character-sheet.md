# character-sheet：人物设定卡

## 用途

让人物立体可写——每个主要人物一张卡，写前/写中对照，避免人物漂移。

## 设定卡模板

```markdown
## 人物：<名字>
- **表层目标**：他想要什么（可被读者看到）
- **深层需求**：他真正需要什么（可能他自己都不知道）
- **缺陷**：什么让他反复犯错（目标与需求冲突的根源）
- **创伤/根源**：缺陷从哪来（一件具体的事，非泛泛「童年阴影」）
- **说话方式**：口头禅、句式、避谈的话题
- **变化弧光**：故事结束时他变成什么样（从缺陷到接纳/克服）
```

## 让设定「可写」的原则

1. **目标 vs 需求**：表层目标与深层需求**冲突**——追逐目标的方式暴露缺陷，而满足需求需要改变。张力由此来；
2. **缺陷具体化**：写成「在什么情境下会做什么错事」，不写形容词（「固执」→「别人提出更好的方案时，他先反驳再思考」）；
3. **弧光可演**：变化弧光必须有**可见事件**支撑——不是内心感悟，是行为改变。

## 校验清单

- [ ] 目标与需求冲突？
- [ ] 缺陷有具体行为表现？
- [ ] 弧光有事件支撑而非内心独白？
