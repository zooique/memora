# nutrient-search：土壤吸收（搜索养分）

## 用途

设计不闭门造车。构思任何非平凡方案前，先搜索最新行业资料、大厂方案、社区踩坑结论，作为设计养分。

## 流程

1. **搜索**：围绕方案主题搜 3-5 个信息源（官方文档、实践文章、对比评测、踩坑贴）；
2. **提炼**：每个来源提炼「它解决了什么 + 关键做法 + 代价」——不复制结论，只吸收养分；
3. **种子过滤**：与最小单元冲突的方案**弃用或改造**；验证为最佳实践才吸收为设计依据；仅参考的记录来源，不做决策硬依赖；
4. **记录来源**：设计文档中引用外部信息时标注来源，让养分可追溯。

## 纪律

- 搜索结论必须**进入设计决策并逐层对齐生长**——吸收但不生长等于白吸收；
- 不为了显得「有调研」而堆砌来源；每条引用都要回答「它改变了设计的哪一点」。

## 校验清单

- [ ] 每个搜索结论是否回答了「它改变了设计的哪一点」？
- [ ] 引用的来源可追溯？
- [ ] 与种子冲突的方案是被「弃用/改造」而非「硬套」？
