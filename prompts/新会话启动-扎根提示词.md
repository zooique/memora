# 新会话启动 · 扎根提示词

> 粘贴此提示词到新对话开头，让 AI 先吸收土壤（项目记忆 + 规则 + 代码现状 + 网络最新信息），再让种子（本轮最小单元）自然生长。

---

## 一、一句话指令

> **"基于 Memora 的项目上下文，先加载项目记忆和规则，明确本次任务的最小单元，然后开始。若需设计非平凡功能，先搜索网络最新信息作为养分。"**

## 二、启动机制（四步）

```
1. 扎根 · 吸收土壤    —— 读项目记忆 / 规则 / 代码现状，设计非平凡功能时再搜索网络
2. 认种子 · 定最小单元 —— 一句话圈定本次要长什么，不扩散边界
3. 自然生长 · 层层依赖 —— 内核 → 插件 → UI，只在上层枝条生长，不越层
4. 反馈归档 · 反哺土壤 —— 更新记忆 / 规则 / 任务清单，让下次生根更肥
```

## 三、第一步：扎根（本提示词的核心）

**新对话框的第一步不是"开始动手"，而是"扎根"**——先让种子落在土壤里，再谈生长。

### 扎根动作（AI 自动执行）

| 动作 | 内容 | 目的 |
|------|------|------|
| 读项目记忆 | `project_memory.md` + 最近 topics | 恢复项目约定、决策、历史 |
| 读规则 | `.trae/rules/` 下适用本次的规则 | 加载心智模型 / 分层 / 编码规范 |
| 看代码现状 | 相关 `src/`、`hosts/`、文档 | 确认"长在哪个枝条上"，不重复造轮子 |
| 搜索网络 | 仅当**设计非平凡功能**时 | 吸收土壤养分，避免闭门造车 |

### 搜索网络的触发条件

**不是每次都搜，只在"养分不足"时搜**：

| 场景 | 是否搜索 |
|------|---------|
| 日常小任务（改 bug / 小调整） | 不必搜，扎根后直接长 |
| 设计非平凡功能（新模块 / 新架构 / 新交互） | 必须搜，作为设计依据 |

## 四、使用方式

粘贴此提示词后，AI 即按"扎根 → 认种子 → 生长 → 归档"执行。深入参考：

- `.trae/rules/network-soil-mindset.md` — **网络为土壤思维模型**（本提示词的哲学依据）
- `.trae/rules/single-truth-source-mindset.md` — 单一真理源（种子/最小单元定义）
- `.trae/rules/programmer-mindset-rules.md` — 心智模型总纲
- `prompts/项目起始提示词.md` — 项目设计哲学与架构全貌（若需更完整上下文）
