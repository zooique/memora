### 项目架构

- **内核**（`src/`）：零 native 依赖的 Node.js 记忆引擎，ESM + TypeScript 5
- **宿主**（`hosts/memora-sprite/`）：Electron 40 桌面伴侣，含完整窗口/快捷输入/浮窗三形态
- **同步机制**：修改内核源码后必须 `npm run sync-memora`（编译+同步到 `node_modules/memora/dist/`）
- **CI 流程**：Gitee push → GitHub 镜像同步 → Actions build.yml → 产物发布到 `memora-sprite-releases` 公开仓
- **发版**：改 `hosts/memora-sprite/package.json` version → git tag `v{x.y.z}` → push tag → CI 自动构建+发布

### 工程约束

- 内核修改后必须 `npm run sync-memora`
- IPC 通道数 127，新增通道前需评估（阈值 130）
- 防御性编程被反对——不掩盖 bug
- 代码必须添加注释（函数级/类级/文件级/变量级）
- PowerShell 命令连接符用 `;` 不用 `&&`
- commit message 遵循 conventional commits，body 每行 ≤100 字符
