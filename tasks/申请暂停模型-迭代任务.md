## 统一质量门（每阶段提交前必跑，全绿方可提交）
- 内核：`tsc --noEmit` + `eslint`
- sprite：`tsc -p tsconfig.electron.json` + `lint:css` + `check-ipc` + `build:electron`
- 提交：PowerShell（**禁止 Bash 跑 git 写操作**）；先手动跑齐上述门，再 `git commit` 时设 `$env:LEFTHOOK='0'` 跳过钩子执行体（门已先验证，非裸 skip）。
- 内核改动后**必须 `npm run sync-memora`** 再打包（内核随客户端冻结，否则改了不生效）。
