### G4 · 记忆治理面板（✅ 已实施，2026-08-23 · P1 · 新增，方案未覆盖）

- **锚点**：`agent.governance`（`MemoryGovernance`，[index.ts:48](../src/index.ts#L48)）· `agent.memory.listDeleted/writePurgeExpired` · `agent.getMetrics().decay`
- **现状**：[extension.ts:204-276](../hosts/memora-vscode/src/extension/extension.ts#L204-L276) 三个命令仅弹提示，无 UI
- **动作**：
  1. 设置面板「记忆」选项卡补治理区：记忆统计卡（活跃/回收站/来源分布，复用 [memoryView.ts](../hosts/memora-vscode/src/webview/scripts/memoryView.ts) 已有数据）
  2. 衰减按钮 + 最近衰减记录（读 `metrics.decay`）
  3. 过期清理按钮 + 二次确认（复刻现有 `cleanupMemories` 语义）
- **验收**：治理操作在 UI 内完成，命令保留作兼容；typecheck + 测试全绿
- **涉及文件**：`settingsPanel.ts` / `settingsView.ts` / `settingsStyles.ts` / `protocol.ts`（如新增消息）
- **实施记录（2026-08-23）**：✅ 已落地。
  - `protocol.ts`：新增 `governance_load`/`governance_decay`/`governance_cleanup`（W→E）+ `governance_loaded`/`governance_result`（E→W）+ `GovernanceStatsDto`（对齐内核 `AgentMetrics.decay`，含 `lastRunAt`）。
  - `settingsPanel.ts`：治理三消息 handler + `loadGovernance()`（`memory.stats()` + `listDeleted` + `getMetrics().decay`）+ `runDecay()`（`agent.governance.decay()`）+ `runCleanup()`（`writePurgeExpired(30 天前)`，host 弹确认框）；`buildHtml` 记忆子视图补治理区骨架（统计卡 + 衰减/清理按钮 + 结果提示）。

  - `memoryStyles.ts`：治理区样式（`#memory-root` 前缀 + `.btn` 复用，错误提示用 `--vscode-errorForeground`）。
  - 测试：`memoryView.test.ts` +7 用例（15 全绿）；顺带修复基线测试漂移——`settingsView.test.ts` HTML 骨架补 `#skills-root`（2026-08-22 加技能视图时未同步，5 用例曾红）。

### G3 · 会话检查点断点续跑（P1 · 新增，方案未覆盖）

- **锚点**：`Agent.restoreFromCheckpoint()`（[agent.ts:1023](../src/agent/agent.ts#L1023)）· `SessionCheckpoint` 类型（index.ts 已导出）· **宿主存储已实现** `saveCheckpoint/loadCheckpoint/deleteCheckpoint`（[sessionStore.ts:219-228](../hosts/memora-vscode/src/extension/host/sessionStore.ts#L219-L228)）· 内核 checkpoint→composer 续上下文（[agent.ts:546-559](../src/agent/agent.ts#L546-L559)）

- **动作**：

- **风险**：检查点语义需先实证（内核侧行为未在宿主侧验证过），**先验证后固化**

### G5 · 多 Provider 路由 + 后台通道（P2 · 新增，待决策）

- **锚点**：`AgentOptions.providerRouter`（[types.ts:487](../src/agent/types.ts#L487)）· `Agent.setProvider/setBackgroundProvider`（[agent.ts:1186/1196](../src/agent/agent.ts#L1186)）· `ProviderRouting`/`TaskType` 类型
- **现状**：[assemble.ts:114-116](../hosts/memora-vscode/src/extension/host/assemble.ts#L114-L116) router 恒返回单 Provider；background 未接
- **决策门槛**：是否需要「对话强模型 + 后台快模型」双通道（收益 = 摘要/洞察/回忆成本下降；成本 = 配置复杂度 + 多 Key 管理）
- **动作**（决策通过后）：
  1. 设置面板「大模型」补「后台模型」下拉（可空）
  2. assemble.ts：`providerRouter` 按 `taskType` 分发；`setBackgroundProvider` 注入
- **验收**：指标区可见后台任务走独立模型；未配置时行为不变

### G2 · 代码执行能力（P2 · B7，待安全决策）

- **锚点**：`ICodeExecutionProvider` + `safeExecuteCode`（src/code-exec/）· `AgentOptions.codeExecutionProvider`（[types.ts:525](../src/agent/types.ts#L525)）· `run_code` 工具条件性包含（[builtinTools.ts:209](../src/agent/builtinTools.ts#L209)，`non-idempotent`）
- **现状**：未注入 → `run_code` 不暴露

- **验收**：对话中 `run_code` 可调用且受沙箱约束
