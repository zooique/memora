## 发版缘由

宿主 `0.13.0` 在 VS Marketplace 被拒（run `45593091319` step 21）：

```
Error: An item with the same key has already been added.
Key in dictionary: 'extension/dist/extension/role-packs/???????????????/rules.md'
```

根因：`role-packs/共鸣小说家` 与 `role-packs/匠码工程师` 各 5 个中文字（UTF-8 各 15 字节）。
Marketplace 服务端按单字节编码解读条目路径，非 ASCII 逐字节变 `?`，两者塌缩为同一键。

Open VSX 的 `0.13.0` 已发布且不可重发，故换版本号 `0.13.1` 补齐 Marketplace。
