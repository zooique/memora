## E. 方法论沉淀（已入记忆）

1. **门禁覆盖**：改 `hosts/**/extension/host/**` 必须跑宿主层测试（`npm run test:all` 或 `--prefix hosts/memora-vscode`）；**勿把 host 层并入根 include**——`hostIntegration` 有并发 flake 实证，根 `fileParallelism:true` 会把它灌进默认门禁。
2. **突变验证法**：移除型修复先临时回退旧逻辑跑目标测试，红 → 证明测试真锁定该行为，再还原。
3. **Edit 换行符坑**：重写文件后 `git status` 显 M 但 `git diff` 为空 = 仅 stat 脏（换行符归一化无差异），不污染提交。
4. **误归因教训**：G21 红灯 09-07 曾被误归为「B 层内核根因/既有失败」，真因是 09-05 b4c2feba（改 1 文件 0 测试 + 落门禁盲区）。红灯先查最近改动，再怀疑根因。
