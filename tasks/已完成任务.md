## 2026-08-28 · Round-based 会话存储方案完全落地（无残留收口）

> 会话分叉 Round-based 单一模式终态收口，源设计见 [round-independent-storage-design.md](../docs/architecture/round-independent-storage-design.md) v1.2。

- **appendMessage 僵尸接口收敛**：ISessionStore 删 appendMessage 声明 + 内核/宿主两实现 + 相关测试适配，统一 round-based 接口；全库零 `appendMessage`/`copySession`/`storageMode` 残留。
- **pending Round 原子性**：appendUser 写 pending（refCount=0）不登记会话；appendAssistant complete 时才 incrementRef + appendRoundId——崩溃残留 pending 为孤儿，可被 GC 清理。
- **引用计数闭环**：deleteSession（内核 inMemorySessionStore + 宿主 WorkspaceSessionStore 对称实现）遍历 roundIds 递减 refCount。
- **GCService Agent 接线**：createPostInitComponents 创建 + startPeriodic（GC_INTERVAL_MS=24h），close 先于 storage 关闭 stopPeriodic；GC 不按状态过滤（pending/error 崩溃残留同回收），minAgeMs 判龄保护进行中轮。
- **recall 同会话优先补齐**：checkpointRestoreCoordinator.warmRecall 透传 sessionId + 热窗口 excludeRoundIds（与 contextPreparer 对称，防热窗口摘要二次注入）。
- **roundSummaryLoader 按会话过滤**：assembler.ts 上下文截断回退只取当前会话 roundIds 对应摘要（sessionStore 缺失降级全量），防跨会话摘要渗入"遗忘补偿"。
- **角色包粘性复位确认**：seed/prepare.ts 经 sessionId 变化隐式复位，覆盖会话切换与分叉出口。
- **设计文档 v1.2 对齐**：§4.2/§4.4/§4.5/§5.2/§5.3/§6.1/§6.3/Phase5 全部改写为实际实现；4 个过时测试断言同步修正（constants 字段数 / degradation 登记断言 / gc pending 语义）。
- **注释去痕（炼化归元）**：11 处 §章节号注释清理（删编号留意图，对齐注释减法规则）。
