**关键设计决策**：

| 决策                    | 理由                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- |
| **放弃 FTS5 虚表**      | unicode61/trigram 都不能正确处理中文；sqlite3 npm 不支持 JS 自定义 tokenizer |
