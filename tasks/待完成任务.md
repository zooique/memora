| 安全性       | ✅   | embedding API 走 Authorization header，无密钥暴露；vector-store JSON 持久化无注入风险 |

**关键设计决策**：

- 不引入 sqlite-vec（C++ 原生模块，编译环境复杂），改用纯 JS 余弦相似度
- 单用户本地场景 5k 条记录内，纯 JS 余弦相似度 < 10ms，性能足够
- 向量持久化用 JSON 文件（而非 SQLite 扩展），冷启动时加载
- 混合搜索策略：关键词（确定性）+ 向量（语义），取并集去重，权重 × 相似度综合排序
