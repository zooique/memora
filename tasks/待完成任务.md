### Phase 2：交互可响应性（按钮无响应专项）

| ID | 任务 | 问题描述 | 验收标准 |
| -- | ---- | -------- | -------- |
| UI-IR-01 | 修复 DOM 元素空引用导致的启动崩溃/按钮无响应 | `UIManager` 构造函数假设所有 DOM 元素存在，若 HTML 与 TS 不同步则抛出 | 引入元素存在性检查，缺失元素时记录 warn 并降级（不阻塞其他功能）；启动失败率降为 0 |
| UI-IR-02 | 统一事件监听器生命周期 | `initModalListeners` 直接调用 `addEventListener` 未走 `eventCleanupFunctions`；`float.html` 也有多个匿名监听器 | 所有事件注册必须通过 UIManager 的 `addEventListener` 或等价清理机制；`cleanup()` 能完整卸载 |
| UI-IR-03 | 修复角色下拉菜单点击冲突 | `persona-selector` 点击展开后，`document` 全局 click 关闭下拉，但内部 item 用 `stopPropagation` 绕开，存在时序与重复触发风险 | 下拉菜单展开/关闭逻辑健壮；点击选项后仅触发一次切换；点击外部可靠关闭 |
| UI-IR-04 | 修复弹窗关闭与背景点击冲突 | `initModalListeners` 中关闭按钮与 backdrop 监听可能重复触发；`showConfirmDialog` 每次新建监听器 | 弹窗显示/隐藏状态单一可信；关闭按钮、背景、Esc、确定/取消行为互不重复触发 |
| UI-IR-05 | 为所有异步操作补充进行中反馈 | 部分按钮（如记忆搜索、角色切换、项目下拉加载）无 loading 状态，用户无法感知是否已触发 | 所有触发 IPC 的按钮/输入在异步期间有禁用或 loading 提示；失败时通过 toast 反馈 |
