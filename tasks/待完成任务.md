## 长线方案使用指南

### 触发式任务的执行流程

当用户反馈或数据验证到达触发条件时：

1. **定位任务 ID**：在阶段 A/B 表中找到对应行（如 LONG-A3 对话面板内联 banner）
2. **查阅路线图**：参照 [用户体验闭环路线图.md](../hosts/memora-sprite/docs/用户体验闭环路线图.md) 对应闭环的 v2 升级路径章节
3. **启动问诊**：复制该闭环的"打磨启动提示词（v2 触发时使用）"到新对话
4. **执行修复**：按"问诊 → 接纳 → 方案更新 → 提交前审查"链路推进
5. **迁移归档**：完成后将任务从 LONG-XXX 迁移到 [已完成任务.md](./已完成任务.md)

### 架构/代码健康任务的执行流程

当阈值到达或年轮审判触发时：

1. **定位任务 ID**：在阶段 B 表中找到对应行（如 LONG-B1 agent.ts 长度监控）
2. **查阅健康度快照**：参照 [健康度快照/](./健康度快照/) 对应日期的诊断报告
3. **启动模式**：依据任务类型选择模式
   - 文件长度/拆分 → 模块重思（模式 4）→ 方案更新 → 提交前审查
   - 枝叶层提取（NAT-10/11/12/13）→ 方案更新 → 提交前审查
   - 健康度趋势 → 神木回天（模式 14）→ 归档待办
4. **迁移归档**：完成后将任务从 LONG-XXX 迁移到 [已完成任务.md](./已完成任务.md)

### 长线方案维护原则

- **不提前实施**：所有 ⏸️ 任务均等触发条件到达再实施，遵循 ADR-017 自然生长原则
- **不重复处理**：阶段 C 已归档项保留追踪，触发时机到达时再激活
- **统一编号**：新发现的任务追加到阶段 A（用户体验）或阶段 B（架构/代码健康），分配下一个 LONG-XXX 编号
- **定期校验**：每次年轮审判或健康度诊断后校验本文件，将已达成触发条件的任务激活，将已完成的任务迁移
