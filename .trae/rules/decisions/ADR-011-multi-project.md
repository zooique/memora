# ADR-011 · 多项目并发

> **状态**：✅ 已采纳
> **日期**：2026-06-03（年轮审判补写，原始实现日期 2026-06-02）
> **来源**：[01-主架构-v4.0.md §4.5](../../docs/基础设计文档/01-主架构-v4.0.md) +
> M-207 任务

## 背景

用户可能同时管理多个项目（如工作项目 + 个人项目），每个项目有独立的 `.memora/`
配置和记忆库。需要支持：

1. 在不同项目间快速切换
2. 切换时自动加载对应项目的记忆
3. 防止并发写入导致数据损坏

## 决策

采用 **ProjectManager + 锁文件** 方案：

1. **ProjectManager**：管理多项目的注册、切换、记忆加载
2. **锁文件**（`.memora/.lock`）：防止同一项目被多个 Agent 实例同时写入
3. **全局规则**（`~/.memora/rules/`）：跨项目共享的规则（如安全策略）
4. **`/project` 命令**：CLI 中切换项目

## 关键实现

| 组件           | 文件                            | 职责                 |
| -------------- | ------------------------------- | -------------------- |
| ProjectManager | `src/memory/project-manager.ts` | 项目注册/切换/锁管理 |
| 锁文件         | `.memora/.lock`                 | 并发写入保护         |

## 后果

**正面**：

- 用户无需退出即可切换项目
- 锁文件防止数据损坏
- 全局规则减少重复配置

**负面**：

- 锁文件在异常退出时可能残留（需 stale lock 检测）
- 项目切换有延迟（需重新加载记忆）
