# ADR-005 · CLI 优先于 Web 形态（阶段一交付）

> **状态**：🔄 已迁移（2026-06-11）  
> **原状态**：✅ 已接受（2026-06-02）
> **迁移原因**：memora 内核定位为零依赖纯逻辑库，CLI 移出至宿主项目
> **来源**：[土壤分析报告.md §二](../../docs/土壤分析报告.md)

## 背景

Memora 作为本地 Agent，需要选择交付形态：CLI / 本地 Web / IDE 插件 / 多端。

## 决策（已迁移）

**CLI 已从 memora 内核移出**。原决策"阶段一交付 CLI 形态"已完成其使命。
当前 CLI 由宿主项目（泊文 `hosts/memora-cli/`）提供，memora 内核定位为纯逻辑库。

## 理由（历史）

- **目标用户是开发者**：习惯 CLI；接受配置文件手动编辑
- **零部署成本**：`npm install -g memora` + `memora` 命令即可
- **可作为其他形态的内核**：未来 Web 形态 = 在 CLI 外套一层 Web UI

## 替代方案

| 方案           | 放弃原因                                               |
| -------------- | ------------------------------------------------------ |
| 本地 Web 服务  | 阶段一不必要；增加前端复杂度；端口冲突；用户要开浏览器 |
| IDE 插件       | 强绑定 IDE；插件审核；版本同步问题                     |
| 多端协同       | 违反"单机本地"定位；隐私风险                           |
| CLI + Web 都做 | 阶段一过载；测试矩阵翻倍                               |
