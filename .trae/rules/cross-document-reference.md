# 跨文档交叉引用规范

> **生效日期**：2026-06-02
> **来源**：健康度诊断 v1 发现 H1（跨文档引用错位）后建立
> **优先级**：P1（强制遵守） **适用范围**：Memora 项目所有 `docs/**/*.md` 文件

---

## 一、问题描述

Memora 的设计文档体系包含 6 份相互引用的文档。多个文档使用相同的章节号（如 4.x、9.x），但章节标题完全不同——这导致：

- ❌
  **H1 类问题**：A 文档写"见 9.4 节"，B 文档的 9.4 节和 A 文档想说的不是同一回事
- ❌ 读者按字面引用去查，会落到无关章节
- ❌ 跨文档引用时容易混淆

**典型案例**：

| 文档                  | 4.3 节     | 9.4 节   |
| --------------------- | ---------- | -------- |
| 01-主架构-v4.0.md     | 统一索引   | 存储隔离 |
| 02-上下文组装-v4.0.md | 冷启动补白 | 降级策略 |

**如果只写"见 4.3 节"**，读者无法判断是哪个文档的 4.3 节。

---

## 二、规范要求

### 2.1 强制规范（必须遵守）

#### 规则 1：所有跨文档引用必须使用"文档.章节号"格式

**错误写法** ❌：

```markdown
详见 4.3 节。参见 9.4 节。
```

**正确写法** ✅：

```markdown
详见 [01-主架构-v4.0.md §4.3](./01-主架构-v4.0.md)。参见
[02-上下文组装-v4.0.md §9.4](./02-上下文组装-v4.0.md)。
```

#### 规则 2：跨文档引用必须用 markdown 链接，不能只用纯文本

**错误写法** ❌：

```markdown
详见 01-主架构-v4.0.md 4.3 节。
```

**正确写法** ✅：

```markdown
详见 [01-主架构-v4.0.md §4.3 统一索引](./01-主架构-v4.0.md)。
```

**理由**：纯文本无法点击跳转，且不强制"文档名"出现。

#### 规则 3：跨文档引用时，章节号必须真实存在

**错误写法** ❌：

```markdown
详见 [02-上下文组装-v4.0.md §9.4 多项目并发](./02-上下文组装-v4.0.md)
```

（02-上下文组装-v4.0.md §9.4 是"降级策略"，不是"多项目并发"——H1 类错误）

**正确做法**：

1. **修改引用前先查目标文档**：用 Grep 确认目标章节的标题
2. **写完后做引用验证**：用健康度诊断（入口 9）定期全量验证
3. **章节标题复制粘贴**：不要凭记忆写标题，必须从目标文档复制

#### 规则 4：同文档内引用可使用简化格式

**同文档内引用**（不需要文档名前缀）：

```markdown
详见 §4.3 统一索引。参见 §9.4 存储隔离。
```

**简化条件**：引用方与被引用方在同一个 `.md` 文件内。

#### 规则 5：URL 编码文件名

文件名包含空格或中文时，URL 中应编码：

| 文档名              | URL 编码                              |
| ------------------- | ------------------------------------- |
| 03-安全权限-v0.2.md | `03-安全权限-v0.2.md`                 |
| 01-主架构-v4.0.md   | `01-主架构-v4.0.md`（无空格无需编码） |
| 04-测试策略-v0.2.md | `04-测试策略-v0.2.md`                 |

### 2.2 推荐规范（建议遵守）

#### 推荐 1：跨文档引用时附章节标题

```markdown
详见 [01-主架构-v4.0.md §4.3 统一索引](./01-主架构-v4.0.md) 参见
[02-上下文组装-v4.0.md §5 与用户主动输入的边界](./02-上下文组装-v4.0.md)
```

**好处**：读者不用打开链接就能判断内容方向。

#### 推荐 2：关系表中显式标注关系类型

```markdown
| [01-主架构-v4.0.md §3.3 记忆分层](./01-主架构-v4.0.md) | **依赖** |
5 层记忆体系是本协议 3.5 节阈值机制的基础 |
```

**关系类型**：

| 关系     | 含义                                     |
| -------- | ---------------------------------------- |
| **依赖** | 本节内容依赖被引用章节                   |
| **扩展** | 本节在被引用章节基础上扩展               |
| **补充** | 本节补充被引用章节未涉及的内容           |
| **正交** | 本节与被引用章节独立，互不干扰           |
| **冲突** | 本节与被引用章节存在不一致（需年轮审判） |

#### 推荐 3：新增文档时立即更新关系表

**触发条件**：新建任何 `docs/**/*.md` 文件后。

**必须动作**：

1. 在 `01-主架构-v4.0.md` 第十一章"与子文档的关系"中添加一行
2. 在被引用方文档的"关系表"中添加反向索引
3. 在 Grep 中验证双向引用

## 三、引用规范速查表

| 引用场景             | 正确格式                                                                   | 错误格式               |
| -------------------- | -------------------------------------------------------------------------- | ---------------------- |
| 跨文档引用文件级     | `[01-主架构-v4.0.md](./01-主架构-v4.0.md)`                                 | `01-主架构-v4.0.md`    |
| 跨文档引用章节级     | `[01-主架构-v4.0.md §4.3 统一索引](./01-主架构-v4.0.md)`                   | `见 4.3 节`            |
| 同文档引用章节       | `§4.3 统一索引`                                                            | （不适用）             |
| 同文档内嵌链接       | `[§4.3 统一索引](#43-统一索引)`                                            | `见 4.3 节`            |
| 跨文档引用带标题描述 | `[02-上下文组装-v4.0.md §5 与用户主动输入的边界](./02-上下文组装-v4.0.md)` | `边界判断`（自己概括） |

## 四、章节号 § 的使用

`§` 是章节号的标准符号（Unicode U+00A7），表示"section"。

**使用方式**：

- `§4.3` 表示第 4 章第 3 节
- `§4.3.1` 表示第 4 章第 3 节第 1 小节
- `§4` 表示第 4 章（无具体小节）
- `§4.3 §4.4` 表示同时引用两个章节

**示例**：

```markdown
详见 [01-主架构-v4.0.md §3.3 记忆分层](./01-主架构-v4.0.md) 和
[§3.5 记忆归档](./01-主架构-v4.0.md)。
```

## 五、引用验证方法

### 5.1 单文档验证

```bash
# 提取所有跨文档引用
grep -nE '\[.*\.md[^\]]*\]\(.*\)' path/to/document.md

# 手动检查每条引用：
# 1. 目标文件存在？
# 2. 章节号正确？
# 3. 章节标题与描述匹配？
```

### 5.2 全量验证

每月底或大版本前执行**健康度诊断**（入口 9）：

1. 用 Grep 提取所有 6 份文档的引用
2. 验证每个引用的目标文件 / 章节存在
3. 检查章节号与标题描述的匹配
4. 输出引用正确率

**目标**：引用正确率 ≥ 95%。

## 六、规范违反的修复方式

| 违反类型                             | 修复方式                             | 优先级 |
| ------------------------------------ | ------------------------------------ | ------ |
| 跨文档引用无文档名前缀               | 用 SearchReplace 加上 `§章节号` 格式 | P2     |
| 跨文档引用链接无效（目标不存在）     | 修改目标到真实存在的章节             | P1     |
| 跨文档引用章节号错误                 | 查目标文档后修正                     | P1     |
| 跨文档引用标题描述与实际章节标题不符 | 复制粘贴原始章节标题                 | P2     |
| 同文档内引用使用了"文档名"前缀       | 删除前缀，保留 `§章节号` 即可        | P5     |
