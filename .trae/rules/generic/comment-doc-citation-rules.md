# 注释引用文档锚点纪律

> **方向**：本文件管**源码注释 → 文档**这一个引用方向。文档 → 文档、文档 → 源码的引用格式归 [cross-document-reference.md](./cross-document-reference.md)（§7 速查）。
> **一句话**：注释引文档是好习惯；坏的是**用会消失的过程稿给长寿的生产代码当锚**。定案结论引定案锚，过程稿只作临时指针，随文档处置一并清算。

## 1. 锚点分层（引什么）

| 层 | 载体 | 生产代码注释可否引用 |
| --- | --- | --- |
| **定案锚** | `.trae/decisions/ADR-*.md`、`docs/architecture/**`、[terminology-anchor-rules.md](../terminology-anchor-rules.md) | **可长期引**——它们承载不可逆约束，改动=破坏契约，指针不会无故失效 |
| **过程稿** | `docs/方案-*.md`、`docs/*-探索方案.md` 等探索期草稿 | **仅临时指针**——按 [exploration-decision-sedimentation-rules.md](./exploration-decision-sedimentation-rules.md) 必然降级或删除，指针注定过期 |

判据一句话：**被引的文档死了，注释还成立吗？** 成立才可长期引。

## 2. 临时指针的写法（引过程稿时）

结论未定案、但代码已按该稿实现时，允许注释引过程稿作临时指针，条件：

1. 写清**文档名 + §章节**（如「论证见 `docs/<文档名>.md` §6.2」）——可清算、可检索；
2. **禁行号、禁 `file:///` 绝对路径**，定位用符号名（格式细则 → [cross-document-reference.md](./cross-document-reference.md) §7）；
3. 注释只留**指针 + 一句话结论**，长论证留在文档里，不搬进注释（减法红线 → [comment-doc-slimming-rules.md](./comment-doc-slimming-rules.md)）。

## 3. 清算义务（本文件的核心）

**过程稿降级/删除的处置动作，必须包含「注释引用清算」**：

1. 扫 `src/`、`hosts/`、`scripts/` 注释中的该文档引用（含无路径的概念指针）；
2. 逐条二选一：**改指定案锚**（结论已固化时）/ **去引用**，把「为什么」压缩进注释使其自足；
3. 清算未完成 = 处置未完成，不得提交处置。

> 理由：`docs:links` 门禁只扫 `.md`，注释里的文档指针腐烂是**静默失效**（与「静默失败 = 假阴性」同族），靠人工巡检必漏。把清算写成处置清单的完成条件才能断根。

**降级为指针不等于免清算**：文件名若保留（指针文档形态），引用虽不断，但被引的论证已搬走——须确认指针文档头部仍能回答「为什么」，不能则改指新真源。

## 4. 概念名指针

无路径的**概念名**引用（如「大文本统一通道 §6.2」）随概念名存活，不因文件移动而断；但概念被取代时按 §3 一并清算。**概念名不得写成伪路径**（不带目录却像路径的写法无法清算）。

## 5. 反模式

| 反模式 | 后果 |
| --- | --- |
| 注释里堆长论证 | 注释膨胀，与文档双写 |
| 「详见方案」不带文档名 | 无法清算、无法检索 |
| 文档处置了，注释指针还在 | 静默腐烂，读者信任失效坐标 |
| 注释写行号 | 行号无 SSOT，增删代码即失效 |

## 6. 存量口径

现存的过程稿引用**不为清算而清算**：对应文档在册时指针当前是准确的，批量改注释只换位置不除风险。一律按 §3 随对应文档处置时清算。
