# 前端审美指南

一棵好树不只长得壮，还要长得美。

AI 生成的前端代码有通病——千篇一律的紫白渐变、Inter 字体、模板化布局。这不是"风格选择"，而是"千树一面"的病态——每棵树都长得一样，就没有树是美的。本指南对抗这种病态，确保项目的前端枝叶各有风姿。

---

## 设计思维

编写前端代码之前，先理解上下文并确定一个**大胆的美学方向**：

1. **目的**：这个界面解决什么问题？谁在使用？
2. **调性**：选择一个极端方向——极简主义、复古未来、有机自然、奢华精致、趣味玩具、编辑杂志、粗野主义、装饰艺术、柔美粉彩、工业实用……从这些中汲取灵感，但设计出真正契合的美学方向
3. **约束**：技术要求（框架、性能、无障碍）
4. **差异化**：什么让这个界面**令人难忘**？用户会记住的那一件事是什么？

**关键**：选择一个清晰的概念方向并精准执行。大胆的极繁主义和精致的极简主义都可行——核心是**意图性**，不是强度。没有意图的设计，就是千树一面。

---

## 五维审美

### 一、排版

- 选择美观、独特、有趣的字体
- **禁止**使用泛用字体：Arial、Inter、Roboto、system-ui
- 搭配一个有特色的展示字体 + 一个精致的正文字体
- 字体选择要出人意料、有个性
- **绝不在不同项目中收敛到相同选择**（如 Space Grotesk）

### 二、色彩

- 承诺一个连贯的美学，使用 CSS 变量保持一致性
- 主导色 + 锐利强调色 > 胆怯的均匀分布色板
- **禁止**使用陈词滥调的配色：紫白渐变、蓝白企业风
- 每个项目的配色方案应该独特，匹配项目气质

### 三、动效

- 用动画创造效果和微交互
- HTML 优先 CSS-only 方案；React 项目使用 Motion 库
- 聚焦高影响力时刻：一个精心编排的页面加载（staggered reveals + animation-delay）比零散的微交互更令人愉悦
- 利用滚动触发和悬停状态创造惊喜
- 极简设计中的动效应克制而精准

### 四、空间

- 意想不到的布局：不对称、重叠、对角线流动
- 打破网格的元素
- 大量留白 **或** 精心控制的密度——二选一，不要中间地带
- 避免千篇一律的三列卡片布局

### 五、细节

- 创造氛围和深度，而非默认纯色背景
- 添加匹配整体美学的上下文效果和纹理
- 创意手法：渐变网格、噪点纹理、几何图案、层叠透明、戏剧性阴影、装饰边框、自定义光标、颗粒叠加
- 极简设计中的细节应微妙而精确

---

## 实现原则

1. **实现复杂度匹配美学愿景**：极繁主义需要精心编排的代码（大量动画和效果）；极简/精致需要克制、精准、对间距/排版/微妙细节的精心关注
2. **优雅来自对愿景的精准执行**，不是来自折中
3. **每个设计都应不同**：在明暗主题、不同字体、不同美学之间变化
4. **绝不收敛到常见选择**：如果 AI 倾向于选择某个字体/配色，主动避开它
5. **生产级质量**：功能完整、视觉惊艳、连贯一致、每个细节精心打磨

## 千树一面检测

在体验评审或提交前审查中，用以下清单检测前端代码是否落入千树一面的病态：

| 序号 | 检查项 | 典型病态表现 |
|------|--------|-------------|
| 1 | 字体选择 | 使用 Inter/Roboto/Arial/system-ui |
| 2 | 配色方案 | 紫白渐变、蓝白企业风 |
| 3 | 布局模式 | 千篇一律的三列卡片、居中标题+副标题+按钮 |
| 4 | 间距风格 | 所有间距相同，缺乏节奏感 |
| 5 | 动效质量 | 无动效，或过度使用 bounce 弹跳 |
| 6 | 背景处理 | 纯白/纯灰背景，无纹理无层次 |
| 7 | 整体印象 | 看起来像模板，缺乏项目个性 |
