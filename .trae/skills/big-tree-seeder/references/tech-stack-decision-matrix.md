# 技术栈决策指南

> 用于第 3 步"项目适配"，基于土壤分析结果引导做出关键技术决策。
>
> **更新规则**：新增决策维度时，在"项目决策维度来源"表中追加。

---

## 决策记录模板

每个技术栈决策记录包含：

```markdown
## 决策 N：{决策名称}

| 属性             | 值               |
| ---------------- | ---------------- |
| 决策项           | {决策维度}       |
| 选择             | {选择的方案}     |
| 推荐程度         | ⭐⭐⭐⭐⭐       |
| 理由             | {2-3 条核心理由} |
| 替代方案         | {考虑过的方案}   |
| 放弃替代方案原因 | {为什么不选}     |
| 风险             | {潜在风险}       |
```

---

## 项目决策维度来源

播种机在第 3 步时，基于项目类型使用对应决策维度。

典型决策项：运行时、框架、数据库、前端方案、ORM、认证、测试框架等。

---

## 版本标注约定

| 标注     | 含义                     |
| -------- | ------------------------ |
| `[推荐]` | 大多数场景的首选         |
| `[稳定]` | 长期支持，生产可用       |
| `[慎用]` | 有已知局限，需评估后使用 |
| 无标注   | 标准选项                 |

---

## 代码项目决策选项

> 包含后端运行时、Web 框架、数据库、前端框架、样式方案、模块系统、验证库等必选决策项，以及 ORM、认证方案、测试框架、文件存储、日志等可选决策项，并附有典型场景的技术栈组合推荐。
