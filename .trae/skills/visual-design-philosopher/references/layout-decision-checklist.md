# 布局决策实战清单

> 视觉管理大师 skill 的可操作决策表。评审/设计任何界面时，按此逐项判定。

## A. 元素归类清单（先做这个）

把界面每个元素列出来，逐行判定：

| 元素 | 使用频率 | 风险等级 | 归类（一/二/三） | 布局决定 |
|------|---------|---------|----------------|---------|
| （示例：发送按钮） | 每天 | 安全 | 一级 | 常驻输入区右下，最大操作 |
| （示例：删除会话） | 每周 | 危险 | 次级 | 弱化小图标 + 二次确认 |
| （示例：导出 JSON） | 每月 | 安全 | 三级 | 设置面板底部 |

> 判定规则：
> - 频率是"普通用户"频率，不是"作者"频率。作者每天用的调试功能，普通用户可能一月一次。
> - 拿不准 → 归到更隐蔽的那一层。宁可藏起来被问"在哪"，不可平铺造成"不知道看哪"。

## B. 聚合 vs 隔离 四问

| # | 问题 | 聚合 | 隔离 |
|---|------|------|------|
| 1 | 这两个元素是用户同一时刻操作的吗？ | 是 → 相邻 | 否 → 分开 |
| 2 | 它们是不是"同一件事"的不同部分？ | 是 → 共容器 | 否 → 分区块 |
| 3 | 其中一个比另一个危险吗？ | 否 → 同强度 | 是 → 视觉降噪危险方 |
| 4 | 它们属于不同任务流吗？ | 否 → 可近 | 是 → 物理分隔 |

## C. 主焦点三问

| # | 问题 | 通过标准 |
|---|------|---------|
| 1 | 用户打开这个视图第一眼看哪？ | 有明确答案（元素 X） |
| 2 | 如果只保留一个元素，留哪个？ | 能立刻说出 |
| 3 | 主焦点周围有竞争者吗？ | 无——竞争元素已降噪或移走 |

## D. Agent 界面检查（memora 专项）

### D.1 Agentic 三要素检查

| # | 检查 | 通过标准 |
|---|------|---------|
| 1 | **Context-aware**：Agent 建议出现在正确的上下文中吗？ | 建议出现在用户正在操作的文件/面板旁（inline），而非凭空出现在对话框 |
| 2 | **Transparent**：过程透明吗？ | 用户知道 Agent 在做什么（进度提示）、用了什么（工具可查）、下一步做什么（步骤预告） |
| 3 | **Controllable**：节奏可控吗？ | 用户可随时中断（停止按钮常驻可见）、覆盖（修改建议后执行）、调整自主等级 |

### D.2 信任增量建立检查

| # | 检查 | 通过标准 |
|---|------|---------|
| 4 | **置信度可视化**：Agent 输出带置信度标记吗？ | 高=🟢可直接执行 / 中=🟡需确认 / 低=🔴标注不确定——三级标记清晰可见 |
| 5 | **渐进自主升级**：信任等级与权限绑定了吗？ | 首次默认建议模式，成功 N 次后自动升级；用户可手动锁定等级 |
| 6 | **逃逸舱三通道**：每个 Agent 操作都有撤销/中断/覆盖吗？ | 撤销=30s 软回滚，中断=随时停止，覆盖=修改后执行——三通道齐全 |
| 7 | **操作可追溯**：Agent 决策有记录吗？ | 用户可查看 Agent "为什么这么决定"的推理过程摘要 |

### D.3 核心界面原则检查

| # | 检查 | 通过标准 |
|---|------|---------|
| 8 | 工具调用可见可检查吗？ | 每个工具调用有独立卡片/块，可展开看参数结果 |
| 9 | 自主模式可见吗？ | 当前模式（建议/执行/审批）以徽章形式显示在任务旁 |
| 10 | 进度可感知吗？ | 多步任务有"3 of 7"类进度，非黑盒 |
| 11 | 审批三档分级了吗？ | 可逆=软、破坏=硬、灾难=二次，非一刀切 |

## E. 反模式速查（立即改）

| 反模式 | 问题 | 改法 |
|--------|------|------|
| 全部元素同尺寸同对比 | 没有焦点 | 主焦点放大 + 其余降噪 |
| 靠"重点/重要"文字标签区分 | 层级设计失败 | 用位置/尺寸/留白表达 |
| 危险按钮和普通按钮长得一样 | 误触风险 | 危险操作降噪 + 二次确认 |
| 相关操作散落各处 | 心智断裂 | 按语义聚合到相邻 |
| 只有 hover 才出现的操作 | 触摸/键盘用户不可见 | 常驻弱化 或 focus-visible 显示 |
| 空态只写"暂无数据" | 浪费引导机会 | 告诉用户"怎么让它出现" |
| 错误只报不指路 | 用户对着错误发呆 | 附修复入口 |
| 所有审批同权重 | 用户点穿所有确认 | 三档分级 |
| Agent 建议脱离上下文 | 用户不知道为什么在这里出现 | inline 到当前操作面板 |
| Agent 操作无置信度标记 | 用户不知道该信还是该查 | 三级置信度可视化 |
| Agent 操作无逃逸舱 | 用户被迫"全有或全无" | 撤销/中断/覆盖三通道 |
| Agent 执行过程黑盒 | 用户焦虑"它在干嘛" | 进度提示 + 步骤预告 |
