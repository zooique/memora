# ADR-022 · 上下文信任边界与 Agent 行为评估视角

> **状态**：✅ 已接受
> **日期**：2026-08-13
> **来源**：架构文档第四轮质量审查（安全 / 可观测 / 2026 生态维度）
> **依赖**：[ADR-021](./ADR-021-memory-conflict-supersede-write-path.md)（写路径取代检测）、[agent-design-philosophy.md](../architecture/agent-design-philosophy.md)（§6.3 / §13.x）、[role-pack-spec.md](../architecture/role-pack-spec.md)（§七）

## 背景

第四轮审查从安全、可观测性、2026 生态三个新维度，暴露三类系统级缺失：

| # | 问题 | 本质 |
|---|------|------|
| H1 | 上下文装配把角色包（高信任）与召回记忆/工具结果（低信任）**混装**，无信任等级区分 | **间接提示注入 / 记忆投毒 / 工具结果注入**——agent 特有攻击面（OWASP ASI）未覆盖 |
| H3 | 有事件流、自审查轮、1983 个单元测试，但**无"agent 行为评估（evals）"**——无法判断记忆/召回/生成是否在变好或退化 | 行业：agent 失败多为**静默失败**，evaluation→production 差距可达 20%+ |
| H2 | 角色包=可下载共享=供应链攻击载体，但安全设计只覆盖**合规**（拟人化新规），无 agent 安全审计 | 行业实测：36% 公开 skills 含提示注入（Snyk），平均质量 6.2/12（SkillsBench） |

## 决策

### 核心决策 1（H1）：上下文装配信任边界

在**最小单元（回答前装配，§6.3）**内区分信任等级，不引入独立安全框架：

- **高信任指令源**：角色包（persona/rule）注入 system prompt、全局安全规则；
- **低信任数据（untrusted data）**：召回的记忆/摘要、工具结果、外部检索内容——保持来源标记，不与其承载的指令混淆；
- system prompt 只由高信任源构成，**绝不直接拼入未标记的不可信数据**；
- 工具结果（尤其 web_search 外部内容）做基础净化与长度上限，防长上下文注入。

**SSOT 自检**：这是回答前装配的自然属性声明（来源标记是确定性属性），非新增机制。

### 核心决策 2（H3）：Agent 行为评估视角（远期）

复用已有组件（§13.x 事件流 + 自审查轮 + 测试），串成**评估视角**：

- 事件流承载 **run/session 两级轨迹**（run=多次模型+工具调用，session=多个 run），可回放；
- 结合自审查轮的外部验证信号，生产中的低质量/失败轨迹导出为**回归用例**，防模型/提示/召回变更后静默退化；
- **不引入独立评估引擎**——是"可观察"固有属性的产品化延伸。

### 核心决策 3（H2）：角色包安全审计硬门槛

- **安全审计是角色包进入可传播目录的前提**（不只合规）：persona/rules/strategy/内嵌 skills 发布前须经注入检测与质量审查；
- memora 作为 reference implementation 对下载角色包做基础注入扫描，发现恶意内容拒绝装载；
- 签名/完整性校验随"硬通货"远期规划落地；
- **当前不实现，先确立硬门槛**（spec §七 声明）。

## 考虑的替代方案

- **H1·独立内容安全框架/守卫模型（如 Llama Guard）**：强对抗但新增运行时依赖 + 独立层，违反零依赖内核与最小单元；本地单用户威胁模型下过度。**放弃**：信任边界应在装配内解决。
- **H3·第三方评估平台（LangSmith / Langfuse）**：现成但外部依赖；评估是宿主/产品化关注点，内核只承诺"轨迹可回放"。**放弃**。
- **H2·不做安全审计，依赖开放目录**：零成本但行业实证 36% 注入风险。**放弃**：硬通货需信任基础。

## 后果

### 正面影响

- 补齐 agent 对抗安全盲区（信任边界、供应链审计），与 2026 OWASP ASI 对齐
- 全部为"最小单元内声明 + 复用已有组件"，无新机制、无运行时负担

### 负面影响

- 信任边界声明增加装配时的纪律约束（来源标记、净化）
- H3 评估视角、H2 注入检测为远期声明，当前不产生即时能力

## 何时回顾

- 进入多租户/高安全场景时，评估是否需独立守卫模型（H1 升级）
- 产品化需要评估质量时，启用 H3 评估视角
- 角色包进入可传播目录时，落地 H2 注入扫描与签名
- web_search 出现实际注入事件时，加速工具结果净化实现
