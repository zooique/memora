# ADR-037 · 底部状态形态宪法：动/静分离 · 抽屉化（四宪法）

> **状态**：✅ 已接受
> **日期**：2026-10-05 用户拍板（§6.3/6.7 三问），同日 C1 落地后补录定案（S2 固化触发 1：src 生产引用 ≥1——宿主骨架/裁决/样式三处注释 + 行为测试锁）
> **过程稿**：`docs/方案-底部状态条收纳-20261001.md`（四病根因诊断 / 外部形态调研证据 / 被否方案明细 / C1 真机验收清单 / §三实现契约 SSOT——「怎么变过来的」归该稿）；`docs/方案-提示UI两分收敛-20261005.md` §九（P4/P10B/P10C 止血脉络与教训）

## 背景

底部状态区四个用户可见缺陷**同根**：`瞬态载体（会自己消失的通知条）承载了非瞬态内容（状态 / 历史 / 用户正在看的东西）`——详情被条拖死陪葬、文档谎报「错误带清除按钮」、error 无出口、details 收起与保活两轴对撞。P10B/P10C 曾在旧架构内止血（follower 随从 + open 轴），属临时契约，C1 落地即退役。

## 决策

1. **宪法① 阻塞决策贴输入区，决策完留痕**：A 类确认卡维持输入框上方恒主位（A1 不动）；决策**结果**（批准/拒绝/超时 + 工具面）写入活动时间线——补「无处回顾刚才批了什么」，不是搬家。
2. **宪法② 状态不自己消失**：error/info 条作为**瞬态通知**可自动撤（info 2500ms / error 8000ms），但其事件**必先落时间线**（`showActivity` 先 push `activityHistory`）；错过通知 ⇒ 入口有未读徽章，信息不丢。
3. **宪法③ 常驻的是入口与开关，不是通知，也不是仪表**：唯一常驻状态面 = **抽屉入口 `#dockChip`**（徽章表达未读/计数）；会变成历史的东西一律进抽屉体。不设常驻状态仪表（四家竞品均无此物，属设计者自造形态）。
4. **宪法④ 抽屉不自动弹**：未读只亮入口徽章；时间线**只在用户主动拉开抽屉时可见**。**「不自动弹」是终态行为取向，不是缺陷**——任何裁决路径不得因未读自动展开面板。
5. **结构定案（宪法的结构落点）**：
   - **唯一折叠轴** = 抽屉展开态（`_dockExpanded`），只由入口 click 翻转；`<details>` open 第二轴随 C1 整组拆除（两套折叠语义并存 = 对撞根）。
   - **入口常驻可达判据** = `被收纳条 >0 ‖ 活动历史非空 ‖ metrics 已渲染`；时间线一旦有内容入口常驻，瞬态条撤后历史仍可达；文案：有收纳显 `+N`，否则显「活动」。
   - 抽屉体分**控件段**（被收纳活跃条，动作按钮可达）与**时间段**（历史 + 诊断指标，静态固定不随条搬运）两段。

## 理由

- 外部形态调研（2026-10-05 实查 Trae / Roo / Cline / Kilo 官方文档，非记忆）：审批卡在流底动作节点与输入框上方视觉同位；瞬态错误自动撤但归动作节点；常驻的是自动批准开关而非状态仪表；待办完成后折叠、按需展开。memora 无流内动作节点载体（P13 红线），故「卡不动 + 决策入线」。
- 四病同根 ⇒ 逐个修 = 永远在追症状；先立宪法一次裁决，换掉后续所有同类讨论的返工。
- 不可逆性：宿主骨架（`chatPanel.ts`）、显隐裁决（`resolveDock`）、行为测试锁（`chatView.test.ts` P4 C1 块 + 五发变异）已按此定形，反转即破用户可见契约。

## 替代方案

| 方案 | 放弃原因 |
| --- | --- |
| 常驻状态仪表条（草案初稿） | 四家竞品均无此物，实查证伪；状态压缩进入口徽章即可 |
| 确认卡迁入消息流 | memora 无流内动作节点载体（P13 红线）；与输入框上方恒主位视觉同位，迁移无增益 |
| 意图闩（手动展开过 ⇒ 钉住显形） | 实测 6 条既有测试红——闩无法区分「系统显形扫一眼」与「主动点开细看」两种相反期望，此路证死 |
| follower 随从 + open 轴止血（P10C） | 临时契约：条撤陪葬与 open+hidden 撞样式的问题被「时间段静态固定 + 唯一折叠轴」从结构根消除，C1 落地即按期退役 |
