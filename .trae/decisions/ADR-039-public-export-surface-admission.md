# ADR-039 · 公共导出面收敛判据（REL-3.1 挂面判据）

> **状态**：✅ 已接受
> **日期**：2026-10-06 判据定案 + `b69f85ff` 收敛落地，2026-10-08 终盘对账分账；2026-10-10 补录 ADR（Go/No-Go 审查 M8：判据 rationale 原只在不随包发布的方案文档/台账里）
> **过程稿**：`CHANGELOG.md` 4.0.0 区 Breaking（导出面收敛条，随包发布）；`src/__tests__/publicApiSurfaceGuard.test.ts` 头注释（守卫判据与变异验证收据）

## 背景

`b69f85ff` 之前是「顺手 export 即公开」的零筛选默认态：3.0.1 导出面 201 个符号，大量纯内部实现挂公共面、每次导出都在积累 breaking 债。同期文档面已出实锤事故——API 手册 §十六 有 **5 处幻觉承诺**（`AgentProjectEntry` / `BOOST_INCREMENT` 等 src 根本没有的导出）+ 1 处滞后承诺，即「文档单方面承诺了不存在的 API」。没有判据、没有守卫，增删两个方向都在静默漂移。

## 决策

1. **挂面判据（两条准入，OR 关系）**：公共导出只保留 ① 宿主（`hosts/memora-vscode`）/ 脚本经 `@zooique/memora` **真实 import** 的符号；② README / API 手册 §十六 **明文承诺**的公共 API。两条都不占 ⇒ 从 `src/index.ts` 移除。纯内部实现不挂公共面。
2. **收编 ≠ 删除**：被收编的类型定义仍留在原模块、随函数签名/结构推断可用，只是不再可显式具名 import——外部消费者改用类型推断或自有定义。
3. **守卫三向机器化**（`publicApiSurfaceGuard`，验收标准不是变绿而是能红）：
   - **向 A**（防未登记公开）：`index.ts` 公开面 ⊆ 消费面 ∪ 承诺面——新增公共导出必须先过两条准入之一；
   - **向 B**（防幻觉文档）：手册 §十六 承诺的符号必须在 src 真实存在；
   - **向 C**（防承诺落空）：承诺的模块级符号必须仍在公开面——「文档承诺但未导出」的具名 import 会得到 undefined。
   豁免名单（import 示例噪声 / 结构推导类型 / 叙述词）为冻结封闭集，新增须带分账理由。
4. **判定前全量重盘 + 双独立路径对账**：历史快照「约 70 个」重盘实测 53；终盘 3.0.1→4.0.0 实移 55，分账诚实登记——误报 2（3.0.1 后新增再收回，不构成对外破坏）/ 漏登 4 补登 / 终盘后回归 1（`ProcessMetricsPayload` 因宿主真实 import 重新挂面）= 发布面 **54**。

## 理由

- **「消费」是硬事实、「承诺」是硬契约**，两者都可机器验证（AST 解析 `index.ts` + import 扫描 + 文档 token 切片）；任何第三种理由（"看起来该公开"）都不可验证 = 静默漂移的入口。
- **双向/三向对账而非单向清单**：单向清单锁不住「新增」（SCRIPT-1 时代契约测试只钉已登记前缀、测不出新增未登记的实锤教训同型）。
- **宿主零改动实证**：收编清单与宿主 84 个真实 import 零交集（tsc 双绿）——判据①先行保证了收敛不伤真实消费者。

## 替代方案

| 方案 | 放弃原因 |
| --- | --- |
| 逐符号人工评审、不建守卫 | 无机器闸门，下一个 major 仍会无声增删（守卫能红是验收标准） |
| 只看「有文档提及」单一判据 | 会把内部实现被迫全部文档化；文档滞后于代码是常态，消费事实更硬 |
| 被收编类型一并物理删除 | 破坏「类型随签名结构推断可用」的既有消费方式，收编 ≠ 删除 |
| 沿用「顺手 export」默认态 | 公共面无限膨胀，每次 major 收敛都是一次无判据的大手术 |

## 何时回顾

- 下个 major 再收敛导出面：判据沿用，数字一律重盘重算（描述性计数以当次实测为准，不引用本 ADR 的历史数字）。
