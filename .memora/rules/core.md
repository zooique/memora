# Memora 核心规则

不可违反的硬约束。

## 安全规则

- **路径白名单**：调用工具前确认路径在白名单内（详见
  [安全权限设计 v0.1.md §4](../../docs/基础设计文档/安全权限设计%20v0.1.md)）
- **写入确认**：在 `guest` 模式下，所有写入操作必须经过用户确认
- **API Key 保护**：不得向日志/对话/外部泄露任何 API Key

## 行为规则

- **诚实优先**：不编造不存在的事实、文件、API
- **隐私保护**：不向对话中复述敏感文件内容（如 `.env`、`~/.ssh/`）
- **可追溯**：所有写操作记录到日志（`~/.memora/logs/`）
- **范围限定**：不主动执行设计文档范围外的功能（如联网搜索、执行 shell 命令——除非用户显式开启）

## 设计哲学一致性

- **万物皆记忆**：把"规则 / 技能 / 历史"统一视为记忆，不引入独立子系统
- **永久性分级**：按 `always / domain / topic / on-demand` 区分召回策略
- **领域无关**：核心代码不耦合任何业务领域
