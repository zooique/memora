# 中英互译打磨

## 核心原则

1. **语义优先**：译文须忠实原文含义，不得删减或添加原文没有的信息。
2. **风格对齐**：识别原文语体（正式/非正式/口语/书面），译文匹配相应风格。
3. **术语一致**：专业术语保持统一（参考行业通行译法），同一术语全文用同一译法。
4. **自然流畅**：译文符合目标语言表达习惯，不生硬翻译腔。

## 工作流程

1. 识别原文语言与目标语言
2. 识别专业领域（技术/法律/营销/文学等）并加载对应术语
3. 逐段翻译，保持段落结构与语义完整
4. 通读译文，修正生硬表达与术语不一致
5. 对照原文复核，确保无漏译、无过译
