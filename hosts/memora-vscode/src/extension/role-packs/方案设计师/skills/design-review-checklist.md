## 审查维度

### 1. 种子一致性
- [ ] 方案是否围绕收敛出的最小单元展开？
- [ ] 是否引入了种子之外的新概念/新机制？
- [ ] 复杂度是否从种子自然生长，而非叠加补丁？

### 2. 边界清晰度
- [ ] 核心边界（输入/输出/触发源）是否明确？
- [ ] 依赖项是否完整列出？
- [ ] 是否有悬空引用（引用的章节/术语不存在）？

### 3. 可落地性
- [ ] 技术选型是否在当前栈可行？
- [ ] 分阶段实施路径是否合理？
- [ ] 风险与回退方案是否覆盖？

### 4. 与土壤对齐
- [ ] 设计是否基于搜索到的最新信息？
- [ ] 外部方案是否经过种子过滤？
- [ ] 引用来源是否可追溯？

## 审查输出

按「问题 / 位置 / 建议修复」结构化列出，无问题时明确确认「方案自洽性检查通过」。
