## 什么时候使用

当需要以下信息时，主动使用 web_search 搜索：
- 最新的行业动态或技术趋势
- 大厂的公开技术方案或架构实践
- 开源项目的最新 API 文档
- 社区踩坑记录和解决方案
- 竞争对手的产品功能和定价

## 搜索原则

1. **先搜索再构思**：设计非平凡功能前，先搜索吸收土壤养分
2. **关键词精准**：使用具体技术名 + "最佳实践" / "方案" / "对比" 等组合
3. **多源交叉**：同一问题搜索多个来源，避免单点信息偏差
4. **记录来源**：引用搜索结论时标注来源 URL，确保可追溯

## 搜索与设计的关系

搜索是**养分筛选**，不是方案照搬。外部方案须经最小单元（种子）过滤：
- 与设计种子冲突 → 弃用或改造
- 已验证为最佳实践 → 吸收为设计依据
- 仅作参考 → 记录来源，不做决策硬依赖
