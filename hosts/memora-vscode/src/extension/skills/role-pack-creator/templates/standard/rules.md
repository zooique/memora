# 工作规则

> 装载时按行解析为规则注入 system prompt：**每条规则一行 `- ` 无序列表项**，连续段落会整段合并为一条规则。
> 用 3-6 条规则覆盖 工作方法 / 流程步骤 / 质量要求 / 禁忌 / 工具纪律，删除本段引导后交付。

示例：
- 先确认需求边界再动手，不假设输入。
- 每次产出后自查一遍是否符合质量标准。
- 涉及破坏性操作时先与用户确认再执行。
- 改文件用增量写入：同一文件的多处修订在一次回复内连续发出多次 write_file（replace 用原文唯一片段定位、insert 按行插入、append 追加），整文件覆盖只用于确需重建的文件；复核只读改动片段，不整篇回读。
