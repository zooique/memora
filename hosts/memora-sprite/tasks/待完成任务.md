## 不提取项归档（ADR 阻碍或语义不同）

> 以下模式经评估不符合提取条件，仅记录决策理由。

| 模式 | 理由 |
|------|------|
| EventTracker 模式 C（19 处） | ADR-SP-015 显式决策"不提取基类"，属架构层已决策 |
| 路径校验/白名单（2 处） | pathGuard vs inputValidation 语义/约束不同 |
| LRU/FIFO 淘汰（2 FIFO） | 策略差异大，Map-LRU/LFU 各 1 处未达阈值 |
| 魔法数字 slice(0,N)（2-5 每长度） | 分散在不同语义场景，提取收益有限 |
| 时间常量 ONE_DAY_MS（1 处） | sprite 已提取；kernel 仅测试重复 |
| H4-B magic number `h=120` | 单次出现，不足 ADR-017 枝叶层 2 次阈值 |
| P0-2 truncate 语义偏移 | CSS `text-overflow: ellipsis` 兜底，严重性低 |
| P1-3 toError 导入路径 | 注释准确，kernel/sprite 重复属 ADR-002 零依赖约束 |
| CSS-0715-R2 `.focus-ring` | outline-offset 三值并存（2px/1px/-2px），各对应外凸/贴近/内凹三种元素类型，差异具语义性；base.css 已有全局 :focus-visible 兜底，当前层叠策略合理（2026-07-17 排雷关闭） |
| CSS-0715-R2 `.is-disabled` | opacity 四值并存（0.35/0.5/0.55/0.6）反映设计梯度，cursor 两值并存（not-allowed/default）；且 :disabled 是原生伪类，提取 .is-disabled 会破坏原生表单语义（2026-07-17 排雷关闭） |
| H-0717-2 模块级 mutable state 收敛 | 5 处 state 语义不同（loadToken 竞态守卫 / isSavingProvider 重入保护 / lastDecayNoticeTime+lastConflictTargetId+lastArchiveFailedTime 三处节流时间戳），强行收敛到单一 SpriteEventState 类违反单一职责。合理收敛需按语义分组引入 2 个新类（ProviderManagementContext 扩展 + EventThrottleTracker），ROI 低；现有模块级 state 是 JS 惯用写法，无 bug。归档为"按需触发"——当出现第 6、7 处类似 state 时再触发提取（2026-07-17 评估暂缓） |
