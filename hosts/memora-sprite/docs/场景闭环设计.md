# Memora Sprite 场景闭环设计

> **设计目的**：定义用户使用程序的完整场景路径（触发→操作→反馈→完成），用于体验评审、回归测试、功能验收的基准。
> **设计原则**：每个闭环必须有明确的"完成判定"（用户可感知的状态变化），不可中途断路。
> **更新日期**：2026-07-12

---

## 闭环总览

## 场景 1：首次启动→配置→首次对话

> **用户画像**：新用户，首次安装 Memora Sprite
> **前置条件**：`~/.memora-sprite/config.json` 不存在

### 路径

```
启动应用
  ↓
[主进程] startSprite() 配置缺失抛错 → agentReady=false
  ↓
[渲染进程] getAgentStatus() → {ready:false, error:'配置不完整'}
  ↓
isConfigMissing=true → shouldShowOnboarding()=true → showOnboardingDialog()
  ↓
[用户操作] 步骤1 了解功能 → 步骤2 选择 Provider + 填 API Key + 保存
  ↓
[IPC] LLM_PROVIDER_SAVE → saveLlmProvider() + reinitAgent() → setupAgentReady()
  ↓
[渲染进程] AGENT_READY 事件 → agentReady=true → onboarding 步骤3 "开始使用"
  ↓
[用户操作] 关闭弹窗 → 切换到对话面板 → 输入消息 → 发送
  ↓
[IPC] CHAT_STREAM → 流式回复
```

### 完成判定

- 对话面板出现 AI 流式回复
- 设置面板 Provider 列表显示刚添加的 Provider（active 状态）
- 侧边栏 Agent 状态指示器显示"就绪"

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| config.json 不存在 | onboarding 弹窗出现 | 白屏 / 无引导 |
| Provider 保存 | 按钮显"保存中..." + disabled | 无 loading / 可重复点击 |
| 保存成功 | Agent 自动初始化 | 仍提示"请先配置" |
| Agent 初始化失败 | toast 错误 + 设置面板可重试 | 静默失败 / 无反馈 |
| 首次对话 | 流式回复正常 | 被守卫拦截 / 超时 |

## 场景 2：日常对话→记忆沉淀

> **用户画像**：已配置 Agent 的日常用户
> **前置条件**：Agent 就绪，至少有过一次对话

### 路径

```
[用户操作] 对话面板输入消息 → 发送
  ↓
[IPC] CHAT_STREAM → Agent.chat() → LLM 流式回复
  ↓
[Agent 内部] 记忆管道自动提取记忆 → 写入 IMemoryStorage
  ↓
[事件] memoryAdded 事件 → IPC MEMORY_ADDED
  ↓
[渲染进程] 记忆面板自动刷新（如当前在记忆面板）
  ↓
[感知面板] 情感基调 / 默契度 / 上下文状态更新
```

### 完成判定

- 记忆面板列表出现新记忆条目（source 类型正确）
- 感知面板情感维度数值更新
- 仪表盘统计卡片数字递增

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 对话产生记忆 | 记忆面板自动刷新 | 需手动刷新才可见 |
| 记忆 source | 正确标识来源（对话/剪贴板/快速输入） | source 为空或错误 |
| 感知面板更新 | 情感维度数值变化 | 数值不变 / 面板空白 |
| 多轮对话 | 记忆持续累积 | 记忆丢失 / 重复 |

## 场景 3：记忆召回→编辑→关系建立

> **用户画像**：积累了一定量记忆的用户
> **前置条件**：记忆面板有至少 10 条记忆

### 路径

```
[用户操作] Ctrl+Shift+R 全局快捷键（或 Ctrl+K 命令面板"搜索记忆"）
  ↓
[渲染进程] 切换到记忆面板 + 聚焦搜索框
  ↓
[用户操作] 输入关键词 → 搜索 → 点击记忆卡片查看详情
  ↓
[IPC] showMemory → 加载记忆详情 + 演化脉络 + 邻居关系
  ↓
[用户操作] 点击"编辑" → 修改内容/标签 → 保存
  ↓
[IPC] updateMemory → 更新成功 toast
  ↓
[用户操作] 切换到图谱视图 → Ctrl+拖拽建立关系
  ↓
[IPC] createRelation → 图谱显示新连线
```

### 完成判定

- 记忆详情弹窗显示编辑后的内容
- 图谱视图显示新建立的关系连线
- 演化脉络显示编辑历史

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 全局快捷键 | 应用未聚焦时也生效 | 需先点击窗口 |
| 搜索结果 | 关键词高亮 + 按相关度排序 | 无结果 / 排序混乱 |
| 编辑保存 | toast 成功 + 详情刷新 | 保存失败无提示 |
| 图谱关系 | 拖拽连线 + 关系标签 | 拖拽无响应 / 关系丢失 |

## 场景 4：主动提示→响应→冷却

> **用户画像**：使用一段时间的用户，累积了事件
> **前置条件**：ProactiveEngine 检测到可提示事件（记忆累积/洞察/里程碑等）

### 路径

```
[ProactiveEngine] checkPending() 检测累积事件 → buildHint()
  ↓
[事件] proactiveHint 事件 → IPC PROACTIVE_HINT
  ↓
[渲染进程] 显示主动提示横幅（顶部滑入动画）
  ↓
横幅内容：事件摘要 + 操作按钮（查看/静默1小时/不再提醒/关闭X）
  ↓
[用户操作] 点击"查看" → 根据事件类型跳转到相应面板
  ↓
[记录] recordAccept() → 重置连续拒绝计数 → 冷却恢复正常
  ↓
[冷却] 自适应冷却公式：baseCooldown × (1 - rapport × 0.5) × (1 + rejects × 0.5)
```

### 完成判定

- 横幅正确显示事件摘要
- "查看"按钮跳转到正确面板（记忆→记忆面板，洞察→仪表盘，角色→设置）
- 冷却时间随默契度和接受/拒绝历史动态调整

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 事件累积 | 达到阈值后触发提示 | 永不触发 / 频繁触发 |
| 横幅显示 | 顶部滑入 + 可操作 | 遮挡内容 / 无法关闭 |
| "查看"跳转 | 跳转到正确面板 | 跳转错误 / 无响应 |
| "静默1小时" | 1小时后恢复提示 | 永久静默 / 不到1小时恢复 |
| 冷却机制 | 连续拒绝冷却递增 | 冷却不变 / 冷却过长 |
| 里程碑 | 首次100/1000条记忆触发 | 不触发 / 重复触发 |

## 场景 5：技能安装→使用

> **用户画像**：想要扩展精灵能力的用户
> **前置条件**：有 .md 格式的技能文件

### 路径

```
[用户操作] 打开设置面板 → 切换到"技能" tab
  ↓
[用户操作] 将 .md 文件拖入 dropzone 区域（或点击选择文件）
  ↓
[渲染进程] skillDropManager.handleSkillDrop() → 过滤 .md 文件
  ↓
[IPC] SKILL_INSTALL → 主进程写入 configDir/skills/ → 热重载
  ↓
[渲染进程] toast "N 个技能安装成功" + 技能列表刷新
  ↓
[后续] 对话中 Agent 匹配技能 → 工具调用卡片展示
```

### 完成判定

- 技能列表出现新安装的技能
- 对话中技能被正确匹配和调用
- 工具调用卡片正确展示技能执行结果

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 拖入非 .md 文件 | 过滤掉，不安装 | 报错 / 静默忽略 |
| 多文件拖入 | 逐个安装，失败不中断 | 一个失败全部失败 |
| 安装成功 | toast + 列表刷新 | 无反馈 / 列表不更新 |
| 热重载 | 无需重启即可使用 | 需重启才生效 |
| 技能匹配 | 对话中正确触发 | 不匹配 / 匹配错误 |

## 场景 6：角色切换→对话行为变化

> **用户画像**：配置了多个角色的用户

```
[用户操作] 侧边栏角色下拉菜单 → 选择新角色（或 Ctrl+K 命令面板"切换角色"）
  ↓
[IPC] switchPersona → Agent 切换角色 → personaSwitched 事件
  ↓
[渲染进程] 侧边栏角色显示更新 + toast "已切换到 XXX"
  ↓
[用户操作] 发起对话 → 角色风格回复
  ↓
[感知面板] 情感基调 / 沟通风格指标更新
```

### 完成判定

- 侧边栏显示新角色名称
- 对话回复风格符合新角色设定
- 感知面板沟通风格指标反映角色切换

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 角色列表 | 显示所有配置的角色 | 缺失角色 / 列表为空 |
| 切换反馈 | toast + 侧边栏更新 | 无反馈 / 显示未更新 |
| 对话风格 | 回复符合新角色 | 风格未变 / 混合风格 |
| auto 模式 | 根据对话内容自动匹配 | 不匹配 / 匹配错误 |
| 手动切换后 | auto 模式暂停，保持手动选择 | 自动覆盖手动选择 |

## 场景 7：三态窗口切换

> **用户画像**：使用托盘模式的日常用户
> **前置条件**：应用已启动，系统托盘图标可见

### 路径

```
[初始状态] 应用启动 → tray 态（托盘图标 + 可选浮动气泡）
  ↓
[路径A] 双击托盘图标 → full 态（完整窗口）
  ↓
[路径B] 单击浮动气泡 → full 态
  ↓
[路径C] Ctrl+Shift+Space → tray ↔ full 切换
  ↓
[用户操作] 在 full 态对话/查看记忆/设置
  ↓
[用户操作] 点击标题栏 X → tray 态（窗口隐藏，托盘保留）
  ↓
[浮动气泡] 主动提示事件 → 球体弹跳动画 + 状态点激活
  ↓
[在场状态] 用户离开 → 球体变暗 + "离开 N 分钟"标签
```

### 完成判定

- tray→full 切换：<100ms 窗口出现
- full→tray 切换：窗口消失，托盘图标保留
- 浮动气泡：拖动流畅，单击展开，右键菜单正常
- 在场状态：离开/回来状态正确反映

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 双击托盘 | 窗口出现在上次位置 | 位置重置 / 无响应 |
| Ctrl+Shift+Space | 全局生效 | 需先聚焦窗口 |
| X 按钮 | 隐藏到托盘（非退出） | 直接退出 / 无响应 |
| 浮动气泡拖动 | 跟手移动，不触发点击 | 拖动触发展开 |
| 在场检测 | 锁屏/挂起正确检测 | 状态不更新 |
| 主动提示 | 气泡弹跳 + 未读徽章 | 无动画 / 徽章不更新 |

## 场景 8：快速输入→记忆沉淀

> **用户画像**：需要快速记录想法的用户
> **前置条件**：应用已启动（tray 态即可）

### 路径

```
[用户操作] Ctrl+Shift+C 全局快捷键
  ↓
[主进程] quickInputWindow.show() → 独立浮窗弹出
  ↓
[用户操作] 输入内容 → 点击确认（或 Enter）
  ↓
[主进程] clipboardHandler.suppressNextChange() → 写入剪贴板
  ↓
[主进程] 异步写入 source:'quick-input' 记忆（不阻塞关闭）
  ↓
[浮窗] 自动关闭
```

### 完成判定

- 浮窗弹出：<200ms
- 确认后内容写入剪贴板（可粘贴验证）
- 记忆面板出现 source:quick-input 的新记忆
- 剪贴板变化检测被抑制（不触发"分析" toast）

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 全局快捷键 | tray 态也生效 | 需 full 窗口 |
| 浮窗弹出 | 独立于 full 窗口 | 跟随 full 窗口 |
| 确认写入 | 剪贴板内容正确 | 剪贴板为空 / 内容错误 |
| 记忆沉淀 | source:quick-input | source 为空 / 不沉淀 |
| 抑制检测 | 不触发"分析" toast | 误触发"分析" |

## 场景 9：剪贴板保护→分析→写入

> **用户画像**：复制了有价值内容的用户
> **前置条件**：应用已启动，剪贴板轮询运行中

### 路径

```
[用户操作] 复制文本内容（Ctrl+C）
  ↓
[clipboardHandler] 2秒轮询检测哈希变化 → emit('changed')
  ↓
[渲染进程] Toast "剪贴板有新内容" + "分析"按钮
  ↓
[用户操作] 点击"分析"
  ↓
[IPC] CLIPBOARD_ANALYZE → 敏感内容检测
  ↓
[分支A] 命中敏感模式（token/信用卡/密码/私钥/AWS Key）→ Toast "检测到敏感内容，已静默忽略"
  ↓
[分支B] 未命中 → 输入护栏检查
  ↓
[分支B-1] 护栏拦截 → Toast "剪贴板内容被拦截：原因"
  ↓
[分支B-2] 通过 → 确认对话框预览内容
  ↓
[用户操作] 点击"确认"
  ↓
[IPC] MEMORIES_ADD → 写入 source:'clipboard' 记忆 → Toast "已存为记忆"
```

### 完成判定

- 敏感内容被正确拦截（5 种模式全覆盖）
- 确认对话框正确预览内容
- 记忆面板出现 source:clipboard 的新记忆
- 程序写入剪贴板时不触发"分析"（suppressNextChange）

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 被动检测 | 2秒内检测到变化 | 检测延迟 / 不检测 |
| 敏感过滤 | API Key/密码等被拦截 | 敏感内容通过 |
| 输入护栏 | Agent 注入的护栏生效 | 护栏不生效 |
| 确认弹窗 | 内容预览 + 确认/取消 | 无预览 / 无法取消 |
| 写入抑制 | 程序写入不触发检测 | 误触发"分析" |
| 重复复制 | 同内容不重复提示 | 重复提示 |

## 场景 10：会话管理→归档→回收站

> **用户画像**：积累了大量对话的长期用户
> **前置条件**：有跨多天的对话历史

### 路径

```
[用户操作] 对话面板 → 日期导航下拉 → 选择历史日期
  ↓
[IPC] loadSessionHistory → 加载该日期对话
  ↓
[用户操作] 查看历史对话 → 点击"一键归档"按钮
  ↓
[IPC] archiveSession → 会话归档 → sessionArchived 事件
  ↓
[渲染进程] 对话面板刷新 + toast "已归档"
  ↓
[用户操作] 切换到记忆面板 → 更多菜单 → "回收站"
  ↓
[渲染进程] 显示已删除/已归档的记忆列表
  ↓
[用户操作] 选择记忆 → "恢复" 或 "彻底删除"
  ↓
[IPC] restoreMemory / permanentlyDeleteMemory → 列表刷新
```

### 完成判定

- 日期导航正确加载历史对话
- 归档后对话从主列表移除
- 回收站显示已归档/已删除的记忆
- 恢复操作后记忆重新出现在主列表

### 断点检查清单

| 检查点 | 预期行为 | 异常表现 |
|--------|---------|---------|
| 日期导航 | 正确加载历史对话 | 加载失败 / 日期错乱 |
| 归档操作 | toast 成功 + 列表刷新 | 无反馈 / 归档失败 |
| 跨日切换 | 发消息自动切到今天 | 停留在历史日期 |
| 回收站 | 显示已删除/已归档 | 列表为空 / 显示错误 |
| 恢复操作 | 记忆重新出现在主列表 | 恢复失败 / 位置错误 |
| 彻底删除 | 不可恢复 + 列表刷新 | 仍可恢复 / 列表未更新 |

## 闭环验证优先级

| 优先级 | 场景 | 验证频率 |
|--------|------|---------|
