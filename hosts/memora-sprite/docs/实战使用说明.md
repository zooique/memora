# Memora Sprite · 实战使用说明

## 1. 前置条件

- **Node.js ≥ 22 LTS**
- **LLM API Key**（DeepSeek / OpenAI / 任何 OpenAI 兼容端点）

## 2. 快速开始

```powershell
cd e:\zooique\memora\hosts\memora-sprite
npx tsx src/index.ts
```

**首次启动**会进入交互式引导：

```
=== Memora Sprite 首次启动 ===

请选择 LLM 提供商：
  1. DeepSeek（推荐，性价比高）
  2. OpenAI GPT-4o
  3. OpenAI GPT-4o-mini
  4. 自定义（任何 OpenAI 兼容端点）

请输入选项 [1-4]（默认 1）：
请输入 API Key：
```

配置保存在 `~/.memora/config.json`，下次启动直接使用。

**后续启动**会自动跳过引导，直接进入对话：

```
Memora Sprite 已启动（/quit 退出 | /dashboard 仪表盘 | /persona 角色列表 | /switch <名称> 切换角色 | /web <关键词> 浏览器搜索 | /config 配置）
```

## 3.5 时间感知

精灵启动时自动将当前时间注入系统提示词，Agent 始终知道"现在几点"：

```
当前时间：2026/06/16 15:30:45 CST（Asia/Shanghai）
```

这意味着：
- 你可以问"今天是什么日期？"——Agent 能准确回答
- 你可以问"帮我写一个本周的周报"——Agent 知道本周是哪周
- 不再受 LLM 知识截止日期的限制

> 时间格式自动适配系统时区，无需手动配置。

### `/config` 可配置项

| 键名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `triggerIntervalMs` | 数字 | 3600000 | 定时触发器间隔（毫秒），默认 1 小时 |
| `defaultPersona` | 字符串 | — | 启动时自动切换的角色名称 |
| `silentMode` | 布尔 | false | 静默模式：关闭主动提示 |
| `proactiveThreshold` | 数字 | 3 | 累积多少个事件后触发主动提示 |
| `proactiveCooldownMs` | 数字 | 300000 | 主动提示冷却时间（毫秒），默认 5 分钟 |
| `fileWatcherEnabled` | 布尔 | true | 是否启用文件变化监听 |
| `fileWatcherPaths` | 逗号分隔 | `.` | 监听路径（相对于项目目录），如 `src,docs` |
| `fileWatcherIgnore` | 逗号分隔 | `**/node_modules/**,**/.git/**,**/dist/**` | 忽略的 glob 模式 |
| `fileWatcherDebounceMs` | 数字 | 1000 | 文件变化防抖时间（毫秒） |

### 配置示例

```powershell
# 关闭文件监听
/config fileWatcherEnabled false

# 只监听 src 和 docs 目录
/config fileWatcherPaths src,docs

# 降低主动提示冷却为 1 分钟
/config proactiveCooldownMs 60000

# 开启静默模式（不打扰）
/config silentMode true
```

配置保存在 `~/.memora/sprite.json`，重启后仍然生效。

## 4. 文件监听（FileWatcherTrigger）

精灵启动后自动监听项目目录的文件变化。**只感知"哪个文件变了"，不读取文件内容**（ADR-SP-004 安全原则）。

### 监听范围

默认监听整个项目目录，忽略以下模式：
- `**/node_modules/**`
- `**/.git/**`
- `**/dist/**`

### 文件变化如何触发主动提示

1. 每次文件保存 → 累积一个 `file` 事件
2. 累积到 `proactiveThreshold`（默认 3）个事件
3. 精灵主动提示：`[精灵] 检测到 3 次文件变化——需要我帮你整理一下吗？`
4. 冷却期（默认 5 分钟）内不会重复提示

### 实战验证

1. 启动精灵后输入 `/dashboard`，确认看到 `已注册触发器：timer, fileWatcher`
2. 在项目中编辑保存几个文件
3. 再次输入 `/dashboard`，观察 `累积事件：N`
4. 达到阈值后，精灵会主动弹出提示

## 5. 记忆系统

每次对话，精灵会自动积累记忆：

| 记忆类型 | 来源 | 示例 |
|----------|------|------|
| 用户画像 | 对话中推断的用户偏好 | "用户偏好简洁的代码风格" |
| 洞察 | 对话中提取的规律 | "Vue 组件中 ref 不能作为 prop 传递" |
| 文件变化 | FileWatcherTrigger | "src/utils.ts 被修改" |

### 查看记忆

输入 `/dashboard` 查看记忆仪表盘，包括：
- 总记忆数
- 按来源分类统计
- 累积事件数（当前/阈值）
- 已注册触发器列表

## 6. 角色系统

精灵支持多角色切换，每个角色有独立的提示词和行为模式。

```
/persona              # 查看所有角色
/switch 开发者        # 切换到"开发者"角色
/switch 代码审查员     # 切换到"代码审查员"角色
```

角色文件存放在 `~/.memora/personas/` 目录下。

## 9. 常见问题

**Q: 首次启动后 API Key 错了怎么办？**

编辑 `~/.memora/config.json`，修改 `llm.apiKey` 字段，或者删除该文件重新启动引导。

**Q: 文件监听没反应？**

输入 `/config` 确认 `fileWatcherEnabled` 为 `true`。输入 `/dashboard` 确认 `已注册触发器` 包含 `fileWatcher`。

**Q: 对话报错？**

检查 API Key 是否有效、网络是否正常。如果需要调试，设置环境变量：
```powershell
$env:MEMORA_DEBUG = "true"
npx tsx src/index.ts
```

**Q: 如何重置所有数据？**

删除 `~/.memora/` 目录（会丢失所有记忆和配置）。
