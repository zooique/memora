# Memora 精灵 UI 布局重思方案

> **模块范围**：完整窗口主界面布局（sidebar + titlebar + main-content）
> **触发原因**：多轮功能叠加导致UI崩坏（面板同时显示、信息密度过高、操作路径混乱）
> **设计哲学**：专注模式（应无所住，而生其心）——对话是核心，一切其他功能为对话服务
> **版本**：v1.0（2026-06-30）

---

## 一、现状诊断

### 1.1 表层Bug（立即修复）

| 问题 | 根因 | 影响 |
|------|------|------|
| 所有面板同时可见 | `#panel-chat` / `#panel-memories` 设置了 `display: flex`，ID选择器优先级高于 `.panel { display: none }` | 截图中对话区和记忆区重叠显示，UI完全崩坏 |
| 设置面板已有同类注释警告 | settings.css 第9-10行明确标注"不要覆盖display"，但chat.css和memory.css未遵守 | 同类问题重复出现 |

### 1.2 架构问题（需要重思）

#### 问题A：侧边栏信息过载

**现状**：240px侧边栏内塞入：
- 品牌区
- 角色选择器
- 仪表盘5个统计卡片（精灵叙事+记忆+洞察+角色+事件）
- 8个可展开section（情感基调、默契度、对话上下文、模式洞察、里程碑、运行指标、学习与回顾、建议列表）

**矛盾**：专注模式需要极简，但"精灵感知系统"需要展示状态。用户80%时间不需要看到情感进度条和默契度数值。

#### 问题B：三面板互斥模型不合理

**现状**：对话/记忆/设置三个面板互斥切换（Ctrl+1/2/3）。

**矛盾**：
- 用户在对话中频繁需要快速查阅记忆 → 切换面板打断心流
- 记忆列表中点击"讨论"需要切回对话 → 操作路径长
- 设置是低频操作，不应该和高频的对话/记忆并列主导航

#### 问题C：记忆面板功能膨胀

**现状**：记忆面板头部有搜索框+添加按钮+3种视图切换+更多菜单；下面叠着高级筛选栏、洞察统计栏、健康度诊断栏。

**矛盾**：每种功能都想"主动可见"，结果是没有重点。高级筛选/洞察/健康度是低频管理功能，不应占据主工具栏。

#### 问题D：顶部栏角色混乱

**现状**：titlebar同时承担：
- 窗口拖拽区
- 面板导航（对话/记忆/设置segmented control）
- 命令面板入口
- 窗口控制按钮（最小化/最大化/关闭）

**矛盾**：导航标签和窗口控件挤在一起，在紧凑窗口下空间紧张；导航标签放在titlebar不符合常见桌面应用惯例。

#### 问题E：感知数据与操作界面混杂

**现状**：情感基调、默契度、上下文指标、模式洞察等"精灵内在状态"直接放在侧边栏，和用户操作控件（角色选择、统计数字）混在一起。

**矛盾**：这些数据是"精灵感知用户"的结果，不是"用户操作精灵"的入口，放在侧边栏既占空间又容易让用户困惑"我需要调这些吗？"

## 二、用户心智模型分析

### 2.1 用户使用Memora的核心场景

| 场景 | 频率 | 核心需求 |
|------|------|---------|
| 与精灵对话 | 极高 | 大输入区、清晰的消息流、不被打扰 |
| 对话中查阅某条记忆 | 高 | 快速找到、不打断对话、看完即回 |
| 添加一条新记忆 | 中 | 快捷入口、不需要切换上下文 |
| 切换角色 | 中 | 知道当前是谁、快速切换 |
| 浏览/搜索记忆 | 中 | 需要更大空间查看列表和图谱 |
| 配置LLM/查看审计/管理技能 | 低 | 明确的入口、不需要经常打开 |
| 了解精灵状态（情感/默契） | 极低 | 好奇时看看、不应常驻 |

### 2.2 核心设计原则

1. **对话为王**：对话面板始终占据主视区，不被其他面板完全覆盖
2. **记忆旁置**：记忆作为侧边抽屉/面板，可快速展开/收起，不覆盖对话
3. **设置收纳**：设置收敛为一个独立窗口或模态层，不在主界面常驻
4. **感知退隐**：精灵状态（情感/默契/上下文）默认隐藏，通过微妙指示器体现，需要时再展开详情
5. **渐进披露**：高频功能1步可达，中频功能2步，低频功能3步以上可接受

## 三、新布局方案

### 3.1 整体布局结构（三区域模型）

```
┌─────────────────────────────────────────────────────┐
│  Titlebar (44px, 仅窗口拖拽 + 控制按钮)              │
├──────────┬──────────────────────────────────────────┤
│          │  ┌────────────────────────────────────┐  │
│ Sidebar  │  │                                    │  │
│ (64px    │  │         对话主区                    │  │
│  图标模   │  │     (始终可见，核心区域)            │  │
│  式，可   │  │                                    │  │
│  展开)    │  └────────────────────────────────────┘  │
│          │  ┌────────────────────────────────────┐  │
│          │  │         输入区 (固定底部)            │  │
│          │  └────────────────────────────────────┘  │
└──────────┴──────────────────────────────────────────┘

记忆面板：右侧抽屉（默认收起，点击记忆按钮/快捷键滑出，覆盖在对话右侧）
设置面板：独立模态窗口（点击齿轮图标打开，居中弹窗）
感知详情：侧边栏展开时显示，或输入框上方微妙指示器
```

### 3.2 各区域详细设计

#### Titlebar（顶部栏）

**变更**：移除导航标签（对话/记忆/设置），回归纯粹的窗口标题栏。

```
┌─────────────────────────────────────────────────────┐
│ [Memora] [当前角色]                    ─ □ ✕        │
└─────────────────────────────────────────────────────┘
```

- **左侧**：品牌名+当前角色（如"Memora · 精灵"），点击角色名弹出角色选择下拉
- **中间**：纯拖拽区（可放置命令面板按钮，居中或靠右）
- **右侧**：窗口控制按钮（最小化/最大化/关闭）
- **移除**：对话/记忆/设置三tab导航

#### Sidebar（侧边栏）

**变更**：从240px缩窄为64px图标模式（默认态），可点击展开为200px详情态。

**默认态（64px图标栏）**：
- 顶部：品牌logo（点击展开侧边栏）
- 中部：垂直图标导航
  - 💬 对话（激活态高亮）
  - 🧠 记忆（点击打开右侧记忆抽屉）
  - ⚙️ 设置（点击打开设置模态窗口）
- 底部：精灵状态指示器（一个小圆点，颜色表示状态：蓝=正常/黄=思考中/绿=有主动提示）

**展开态（200px详情栏，点击logo或hover展开）**：
- 品牌区+收起按钮
- 角色选择器（紧凑卡片）
- 极简统计：记忆/洞察数字（2个数字，不是5个卡片）
- 精灵叙事摘要（一行文字，点击展开感知详情面板）
- **移除**：情感进度条、默契度进度条、运行指标网格、学习与回顾等默认隐藏到"感知详情"中

**感知详情**：点击叙事摘要后，在侧边栏内展开一个可滚动区域，展示情感/默契/上下文/洞察/里程碑/运行指标等所有感知数据。这个区域是"开发者/好奇模式"，普通用户日常不需要打开。

#### 对话主区（Main Content）

**变更**：对话面板始终占据核心窗口，不再被其他面板完全替换。

```
┌─────────────────────────────────────┐
│ 对话标题栏                           │
│ "对话"  今日0条消息    [日历图标]     │
├─────────────────────────────────────┤
│ (精灵叙事条 - 仅在有事件时显示，      │
│  不是常驻元素)                        │
├─────────────────────────────────────┤
│                                     │
│         消息流区域                   │
│         (flex:1, 可滚动)             │
│                                     │
├─────────────────────────────────────┤
│ (精灵状态微指示 - 4个小圆点，        │
│  hover显示情感基调详情)              │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ 输入框...                       │ │
│ │ [+]  [发送/停止]                │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

**简化点**：
- 主动提示banner：保留，但改为从顶部滑入的紧凑通知条
- 回到底部按钮：保留
- 移除：情感指示器常驻显示（改为hover/点击可见）
- 移除：对话区和记忆区的硬边界

#### 记忆面板（右侧抽屉）

**变更**：从独立主面板改为右侧抽屉（Drawer），宽度360px，覆盖在对话右侧（不push对话区，而是半透明遮罩+滑入）。

```
对话主区                │ 记忆抽屉（360px）
┌──────────────┐┌─────────────────────┐
│              ││ 记忆    [×]          │
│              ││ ┌─────────────────┐ │
│   对话内容    ││ │ 搜索记忆...      │ │
│   （底层可见） ││ └─────────────────┘ │
│   半透明遮罩  ││ [+添加] [列表⌄]     │
│              ││ ┌─────────────────┐ │
│              ││ │ 记忆列表         │ │
│              ││ │ ...             │ │
│              ││ │ ...             │ │
│              ││ └─────────────────┘ │
└──────────────┘└─────────────────────┘
```

**简化记忆工具栏**：
- 顶部：标题"记忆" + 关闭按钮
- 搜索框（全宽）
- 添加按钮 + 视图切换（列表/时间线/图谱）收为一个下拉或2个图标按钮
- **移除**：高级筛选、洞察统计、健康度诊断从主工具栏移出
  - 这些作为记忆面板内的折叠section或"更多"菜单中的选项
  - 图谱视图可以全屏展开（点击后覆盖整个对话区作为临时视图）

**交互**：
- 打开方式：点击侧边栏🧠图标、Ctrl+2、对话中"回忆"相关操作、记忆卡片点击
- 关闭方式：点击×、点击遮罩区、Ctrl+2、Esc
- 点击记忆列表项：弹出详情弹窗（模态），不关闭抽屉
- 点击"在对话中讨论"：关闭抽屉，回到对话，输入框预填内容

#### 设置面板（模态窗口）

**变更**：从主面板改为独立模态窗口，尺寸约640×520px，居中弹出。

```
┌─────────────────────────────────┐
│ 设置                    [×]     │
├──────────┬──────────────────────┤
│ 大模型    │                      │
│ 嵌入      │   右侧表单区域        │
│ 精灵      │                      │
│ 项目      │                      │
│ 画像      │                      │
│ 审计      │                      │
│ 技能      │                      │
│ 作品      │                      │
└──────────┴──────────────────────┘
```

- 左侧垂直tab列表（8个tab）
- 右侧对应内容区（可滚动）
- 底部：保存/取消/恢复默认按钮
- **优势**：设置不打断对话心流，关闭后立即回到对话现场

### 3.3 导航模型变更汇总

| 功能 | 原位置 | 新位置 | 触发方式 |
|------|--------|--------|---------|
| 对话 | 主面板tab1 | 核心区域（常驻） | 默认显示 |
| 记忆 | 主面板tab2 | 右侧抽屉 | 侧边栏🧠图标 / Ctrl+2 / 对话中回忆 |
| 设置 | 主面板tab3 | 模态窗口 | 侧边栏⚙️图标 / Ctrl+, |
| 角色切换 | 侧边栏选择器 | 侧边栏展开态 / titlebar点击 | 始终1步可达 |
| 命令面板 | titlebar按钮 | titlebar中央/右侧 | Ctrl+K |
| 情感/默契等 | 侧边栏常驻section | 侧边栏感知详情（折叠） | 点击叙事摘要展开 |
| 高级筛选/洞察/健康 | 记忆面板常驻工具栏 | 记忆面板折叠区/更多菜单 | 需要时展开 |
| 新建会话 | 对话工具栏日历旁 | 对话工具栏 | 始终可见 |
| 记忆图谱 | 记忆面板tab | 记忆面板视图切换/全屏 | 列表视图内切换 |

## 四、关键交互流程

### 4.1 对话中查阅记忆

**原流程**：Ctrl+2切到记忆面板 → 搜索/浏览 → 点击记忆查看 → Ctrl+1切回对话（4步，对话上下文被完全替换）

**新流程**：Ctrl+2打开记忆抽屉 → 搜索/浏览 → 点击记忆弹窗查看 → Esc关闭抽屉（3步，对话始终可见，上下文不丢失）

### 4.2 查看精灵情感状态

**原流程**：侧边栏直接展示4个进度条（常驻，占据空间）

**新流程**：注意到侧边栏底部精灵圆点变色 → 点击展开侧边栏 → 看到叙事摘要 → 点击展开感知详情查看具体数值（3步，好奇时才看）

### 4.3 配置LLM

**原流程**：Ctrl+3切到设置面板 → 修改配置 → 保存 → Ctrl+1切回对话（4步，对话被替换）

**新流程**：点击⚙️或Ctrl+, → 模态窗口中修改 → 保存/取消 → 自动回到对话（2步，模态关闭即返回）

### 4.4 对话中快速添加记忆

**保留**：输入框旁的[+]按钮直接打开添加记忆弹窗（0面板切换，1步完成）

## 七、风险与注意事项

1. **CSS优先级问题必须先修复**：这是导致截图中UI崩坏的直接原因，Phase 1必须首先完成
2. **抽屉组件需要处理键盘焦点**：打开时焦点移入抽屉，关闭时焦点回到触发元素（ModalManager已有此模式可复用）
3. **64px图标模式需要tooltip**：hover图标时显示功能名称
4. **记忆抽屉宽度需考虑记忆详情**：360px是合理初始值，记忆详情弹窗在抽屉上层
5. **响应式适配**：小窗口（<800px）下边栏64px模式更适合，但抽屉可能需要全宽
6. **动画性能**：抽屉滑入使用transform而非left/right，确保60fps
7. **测试覆盖**：Phase 1完成后必须运行现有UI测试确保面板切换功能正常
