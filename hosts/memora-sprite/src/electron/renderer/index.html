      使用帮助

      功能简介

      Memora 精灵是一个本地 AI 伙伴，拥有跨会话记忆能力。它能在你工作时自动归档关键信息，在后续对话中主动回忆上下文。

      • 对话：与 AI 自由对话，精灵会记住你的偏好和上下文。
      • 记忆：自动归档关键信息，支持搜索、筛选、关系图谱。
      • 角色：切换不同 AI 角色，适配不同工作场景。
      • 仪表盘：查看记忆健康度、感知状态、运行指标。

      三种窗口形态

      • 完整窗口：完整对话体验，包含记忆/角色/设置面板。快捷键 Ctrl+1 对话、Ctrl+2 记忆、Ctrl+3 设置。
      • 浮动图标：桌面悬浮球，单击展开迷你对话。可拖动移动位置。
      • 系统托盘：最小化到任务栏托盘，右键菜单操作，后台常驻。

      配置指引

      1. 在大模型标签页中点击「添加」，选择服务商并输入 API Key。
      2. 推荐使用 DeepSeek（国内可直接注册，性价比高）。
      3. 在精灵标签页中可调整主动提示频率、静默模式等。
      4. 在项目标签页中可切换专注模式，锁定特定项目。

      常见问题

      如何获取 API Key？
      在大模型标签页点击「添加」，选择服务商后点击「获取 API Key」链接，跳转到对应平台注册并获取。
      对话没有响应？
      检查底部状态栏服务商是否显示「未配置」，确保已正确配置 API Key。点击状态栏可快速跳转到设置。
      记忆如何归档？
      默认使用全自动归档模式。可在精灵标签页中切换为「仅洞察自动」或「全手动」模式。
      如何切换项目？
      在项目标签页中切换专注模式，或拖入项目文件夹到对话区。
      快捷键有哪些？
      按 Ctrl+/ 查看完整快捷键列表。常用：Ctrl+. 停止生成、Esc 关闭弹窗。
      数据存储在哪里？
      所有数据存储在本地 ~/.memora-sprite/ 目录下，不上传到任何云端服务器。
