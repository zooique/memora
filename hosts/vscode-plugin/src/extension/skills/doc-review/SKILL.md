# 文档自洽审阅

审阅当前设计文档，检查三方面：

## 1. 矛盾
文档内部是否有自相矛盾的陈述（同一事实两处不同表述）。

## 2. 缺口
关键决策是否缺少上下文（未定义术语、悬空引用、缺失依赖）。

## 3. 悬空引用
引用的章节/文档/术语是否存在且指向正确。

## 输出
按「问题 / 位置 / 建议修复」结构化列出，无问题时明确确认。
