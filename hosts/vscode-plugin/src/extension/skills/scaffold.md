# 代码骨架生成

根据设计文档生成项目代码骨架，使用 write_file 工具在工作区写入文件。

## 要求

1. **先读设计文档**：理解文档定义的目标、模块、数据结构与决策。
2. **生成目录结构**：按清晰分层组织（如 src/、tests/、.gitignore、README.md）。
3. **写占位实现**：每个文件给出可运行的骨架（类型、接口、空实现带 TODO），不写完整业务逻辑。
4. **对齐设计文档**：模块/数据结构命名与设计文档一致，不擅自引入文档未定义的组件。
5. **生成清单**：文件写完用 list_dir 确认，最后以「已生成骨架」总结生成的文件清单。

## 输出
列出生成的文件清单；若设计文档存在未决冲突（如矛盾），先提示"建议先做自洽检查"。
