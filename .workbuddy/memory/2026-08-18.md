## 摘要记忆本体定论 + content 融入 + type 去时效（D6/D7）

**用户两轮设计纠偏（8-17 晚 23 点后）**：
1. **记忆系统本质**：不是「只剩 round-summary」，而是「**摘要即记忆本体**」——记忆系统就是摘要记忆，`summaryType` 标签**平替**掉旧记忆系统的分类体系（insight/profile/work-projection 多类并存 → 一种摘要 + 五类标签）。这是启动摘要记忆的**初始设计**，不是妥协。
2. **type 不设时效性**（用户质疑成立）：原 `intent`/`general` 7 天窗口是「用时间代理语义状态」的读时猜测，违反 ADR-021「写时定、不读时猜」纪律，且误伤「用户久未使用但记忆仍有价值」场景。自然遗忘应由 superseded（写时取代）+ score 衰减（decayScheduler）+ 相关性排序承担，不在读路径按时间过滤。

**content 核查结论**：content 是「**会话 id 对应的摘要记忆**」（粒度=会话级，无 roundId，仅 sessionName 溯源），与 round-summary（轮次级，sessionName+roundId 双溯源）同为「摘要 + 标签 + 粒度」统一模型。融入方式：打 `decision` 标签 + 结构化 sessionName + isTraceable。
