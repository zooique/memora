- 判断：单 md 确实单薄（3 短板：L2 树形策略用点路径平铺是妥协、自然语言 rules 机器校验弱、L3/知识引用装不下）；但**不能倒向纯 YAML**（persona 大段文本会毁掉可读性与 LLM 直读性——生态门槛）。
- **定案：分层单文件**——Markdown 为皮（## Persona/## Rules 内容层，人写人读+LLM 直读），嵌套 YAML 为骨（frontmatter：元数据 + strategy 嵌套对象 + skills 结构化数组，机器可校验）。
- 关键收益：**嵌套 YAML 取代点路径平铺，终结 snake/camel 键名分裂**（strategy.act.tool_calls vs toolCalls 之争自动消失）；规范引用用点路径、文件内嵌套，等价映射。
- spec 更新：§二（分层单文件 + 完整样例）、§三（结构图 skills 移 frontmatter）、§四（skills 结构化数组：capability 必填/description 可选）、§六（嵌套 vs 点路径等价说明）。复验 33/33 链接 0 断裂、旧 ## Skills 正文残留 0。
- 格式厚度三层：schema（键类型/取值/必填规范）→ 校验器机检 → formatVersion 版本语义 + 未来"单文件+可选附件目录"平滑升级。

## 第二十一轮：角色包格式再定案——文件夹包（老板：「skills 都是压缩包/文件夹分层，角色包是代替 skills 的存在，单文件还是单薄」）
- 老板关键洞察：**skills 生态已是文件夹形态（SKILL.md + references/scripts/assets，zip 分发），角色包要"代替 skills"就必须继承其分发形态**——单文件单薄。
- 实证对齐：~/.workbuddy/skills/aihot = SKILL.md + references + LICENSE + _skillhub_meta.json；插件缓存 = SKILL.md + scripts；.trae/skills/big-tree-grower = SKILL.md + references。
- **定案：文件夹包（bundle），双形态**——完整形态=文件夹（role-pack.md + skills/ 内嵌标准 skills 包 + references/ + assets/ + scripts/ + manifest.json 可选，zip 分发）；最小形态=单文件 role-pack.md（无资源零依赖装载 L1）；渐进升级（单文件→文件夹装载行为不变，都以 role-pack.md 为入口）。
- **代际关系（§2.1）**：Skills=能力单元（会做什么）；角色包=完整行为单元（身份+能力+约束+行事，**有身份的能力包**）= skills 的容器/超集；"角色包代替 skills"=能力分发升级为行为分发。
- spec 更新：§二（文件夹包+§2.1-2.4）、§三（结构图）、定位宣言/核心原则同步改"文件夹包（最小形态单文件）"。复验 2/2 链接 0 断裂、文件夹包表述 14 处。
- 意义：角色包格式与 skills 生态兼容（内嵌标准 skills 包、复用解析器/市场分发），是"代替 skills"的自然升级而非另起炉灶。

## 第二十二轮：政策核查 + 合规内建（老板问：豆包等下架自定义智能体是否政策不允许，角色包是否伪命题）
- 事实（WebSearch 实证，2026-07）：《人工智能拟人化互动服务管理暂行办法》2026-07-15 施行（全球首个 AI 拟人化/情感陪伴监管法）；豆包/千问同步下线用户自建智能体、元宝 6-30 下线；主因=平台主动避险（合规成本+UGC 审核难+不赚钱，微博反方观点：新规是幌子、成本是真相）；**豁免条款：智能客服/知识问答/工作助手/学习教育/科研不涉及持续性情感互动不适用**；**千问保留并加码工具型智能体（MCP 协议）——去伪存真**。
- 结论：**角色包不是伪命题**——政策禁止的是"失控的拟人化情感互动"，不是"自定义角色"形态；角色包定位生产力 Agent（工作助手）在豁免区间；被下架的伪智能体（固定 prompt 无工具无决策）恰是角色包的反面；**角色包 rule 段/skills 边界/strategy 显式化 = 让平台审核责任可落地的结构化答案**。
- 落地：role-pack-spec.md 新增 **§七 合规与安全**——① aiIdentityDisclosure 强制 AI 身份标注；② rule 段=内容红线载体；③ `interactionType: tool_assistant | companion`（默认 tool_assistant，校验必填；companion 落《办法》管辖需物理隔离）；④ 未成年人保护钩子 minorProtection；⑤ 校验器拒绝 companion+虚拟亲密特征。**范式方向约束：做生产力不做陪伴**。mvp-scope 补豁免定位句（写作助手=工作助手豁免区间）。
- 复验：9/9 链接 0 断裂；spec 现 9 节。
- 战略意义：政策反而验证了角色包方向——工具化/协议化/能落地的 Agent 是政策留出的赛道（千问实证）。

## 第二十三轮：行业标准同构验证 + spec 行业校准（老板：上网搜最新 agent 新闻，讨论角色包文件形式是否合理）
