## 角色系统 Bug 修复（2026-07-27）

### P0：Manual 模式默认回退 bug
- **根因**：`shouldFallbackToDefault()` 不检查 mode，manual 模式下仍会回退到 default
- **修复**：`agent.ts` 加 `if (this.personaManager.currentMode !== 'auto') return false;`

### P1：消息底部角色标签与实际回答角色不一致
- **根因**：`chatStreamHandler.ts` 在 `agent.chat()` 之前捕获 `personaName`，此时 `tryAutoMatchPersona` 未执行
- **修复**：将 `SPRITE_STREAM_START` 延迟到 for-await 首个 chunk 后发送（此时 persona 已匹配完毕）
- **finally 守卫**：`streamStarted` 标志防止 generator 无产出时发送无对应 START 的 END

### P2 + 日志同步
- **autoMatch 去 async**：函数体无 await，改为纯同步 `autoMatch(input): string | null`，agent.ts 去 await
- **日志/注释同步**：3 处陈旧文案更新（60s/3次/5分钟 → 30s/5次/2分钟）

### 文件清单
- `src/agent/agent.ts`：shouldFallbackToDefault + await 移除
- `src/persona/personaManager.ts`：autoMatch 去 async + 日志/注释更新
- `hosts/memora-sprite/src/electron/ipc/chatStreamHandler.ts`：SPRITE_STREAM_START 延迟 + streamStarted 守卫
