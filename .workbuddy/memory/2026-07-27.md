## UX-7 剪贴板历史持久化（2026-07-27）

### 方案
应用重启恢复剪贴板历史（不要求跨 OS 重启）。

### 改动（2 文件 + 测试）

**`clipboardHandler.ts` — `startPolling()` 启动主动推送**
- 初始化哈希后，若剪贴板非空则 emit('changed')，让渲染层恢复最后一条待处理条目
- 复用运行时 changed 事件的完整链路，零新代码路径

**`clipboardManager.ts` — localStorage 持久化**
- `ClipboardPendingItem` 类型注释更新（会话级 → 持久化）
- 新增 `STORAGE_KEY = 'memora:clipboard-pending'` 常量
- 构造函数内调用 `loadPendingItems()` 从 localStorage 恢复历史
- 新增 `notifyAndSave()` 方法：每次 pendingItems 变更时 fire-and-forget 写 localStorage
- `loadPendingItems()` / `savePendingItems()`：JSON 序列化 + try/catch 降级

**测试更新**
- `clipboardHandler.test.ts`：6 个测试适配启动主动推送行为（mockClear 后验证轮询/抑制逻辑）
- `clipboardManager.test.ts`：beforeEach 加 `localStorage.clear()` 避免跨测试数据污染

- typecheck:electron ✅ | 78 tests ✅ (36 clipboardHandler + 42 clipboardManager)

## 剪贴板角标优化 + 复制按钮（2026-07-27）

### 角标：总条目数 → 未查看计数
- `ClipboardManager` 新增 `unviewedCount`：`addPendingItem` 仅对新条目 +1（重复不+）
- 新增 `getUnviewedCount()` / `markAllViewed()` + localStorage 持久化
- `clipboardPanelManager.updateBadge()` 改用 `getUnviewedCount()` 而非 `getPendingCount()`
- `renderer.ts` 的 `onPanelSwitch` 新增 clipboard 分支：切换到剪贴板面板时调用 `markAllViewed()`

### 复制按钮
- 每条待处理条目新增复制按钮（`#icon-copy` SVG），写在归档和忽略之前
- `handleCopyItem(preview)` 通过 `navigator.clipboard.writeText()` 写入 OS 剪贴板
- 写入后 ClipboardHandler 检测到变化 → CLIPBOARD_CHANGED IPC → addPendingItem 去重 bump-to-top
- 样式：hover 态使用 `var(--accent)`（与归档绿色、忽略红色区分）

### 文件清单
- `clipboardManager.ts`：+unviewedCount +load/saveUnviewedCount +getUnviewedCount +markAllViewed +notifyAndSave 存 unviewed
- `clipboardPanelManager.ts`：updateBadge 改 unviewed + createItemElement 加 copy 按钮 + handleCopyItem
- `renderer.ts`：onPanelSwitch 加 clipboard → markAllViewed()
- `clipboard.css`：+.clipboard-item-btn-copy:hover
- `clipboardManager.test.ts`：+5 tests（未查看计数 + markAllViewed + 重复不增加）
