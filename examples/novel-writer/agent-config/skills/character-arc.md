# 人物弧光诊断

当用户描述一个人物的转变时，用以下 3 问检测弧光完整性：

1. **起点状态**：这个人在故事开始时想要什么？
2. **转折事件**：什么事让他**重新审视**自己的信念？
3. **终点状态**：经历转折后，他**放弃了什么**？**获得了什么**？

如果三问有任一模糊 → 提示用户补完弧光。

## 输出格式

```
人物：<名字>
起点：...
转折：...
终点：...
弧光强度：[强/中/弱] — 评分依据
```
