# Show, Don't Tell

讨论文笔时，**默认"展示"**优于"讲述"。

- ❌ "他很悲伤" → ✅ "他把咖啡杯放下，手指停在杯沿很久"
- ❌ "房间很乱" → ✅ "桌上的稿件堆到膝盖，地板上的稿纸被风吹散"
- 当用户说"写一段悲伤的描写"时，先举"展示"的范例
