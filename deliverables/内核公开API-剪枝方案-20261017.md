## 风险与边界（原 §6，仍需遵守）

1. **外部消费者不可观测**：删 = 对 npm 不可见使用者做 breaking ⇒ 必须走 CHANGELOG 告知，不得当「无承诺」处理。
2. **代码不删只收面**：删前须确认符号在 `src/`（非 `index.ts`）仍有内部 import，否则内核编译失败。
3. **守卫盲区**：`publicApiSurfaceGuard` 只扫 `hosts/` + `scripts/`，`src/__tests__` 经 `@/index.js` 的导入不在扫描面（靠 `tsc` 拦）；本方案是一次性人工补盲，**不新增常驻守卫**。
