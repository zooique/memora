## 二、内核变更明细（真源 = CHANGELOG `[5.0.0]` 区）

### 2.1 Breaking Removed（5 批公开面收面/退役）

**① `PUB-API-PRUNE-1` — 公开面收回 12 项通用工具 / 重复入口（2026-10-17，最新批）**
- 收面对象：`createLlmProvider`（与 `createProviderFromConfig` 重复的便利入口）+ 11 项通用小工具（`truncate` `isPlainObject` `serializeFrontmatter` `safeSetTimeout/Interval` `clearSafeTimeout/Interval` `segmentText` `escapeLike` `escapeLikeSnippet` `toError`）。
- **性质**：非「零引用删除」——函数本体在 `src/` 内部仍在用（如 `toError` 内部 96 处），收回的只是 `src/index.ts` 导出行 + 手册 §十六 镜像行 + 接入指南 §六 工具表行。
- **唯一例外**：`escapeLikeSnippet`（组合便利）收面后零生产调用 = 僵尸工具，本体 + 自测一并删除；`escapeLike` 保留（内核 SQLite 实现自用）。

**② `GOAL-DRIFT-1` — 字面相似度目标漂移检测链整体退役**
- 删 `managers/goalConsistencyChecker.ts` 整模块（bigram+Jaccard + same/confirm/drift 三级判定）；删 `SessionManager.updateGoal()`、`SessionCheckpoint` 三字段（`mainGoal`/`currentGoal`/`goalChangeSeq`）、`goalDriftDetected` 事件；`createCheckpoint()` 签名收为无参。
- **三条独立退役理由**（任一单独成立）：① 从未通电且接线即炸（fail-pause 方向倒错）；② 区分能力实测为零（12/12 与 6/6 全判 drift，两区间完全重叠）；③ 判据性质违宪（语义判断，违反架构哲学 §4，且内核零第三方依赖 ⇒ 天花板锁死）。
- 关切不退役：交还「用户在环 + `ask_user`」既有通道；目标态登记 `GOAL-DRIFT-2`。

**③ `CHKPT-1/2/3` — 检查点脏标记链统一减法**
- 删 `SessionManager.flushNow()` / `flushOnShutdown()` 两个 **no-op 公开方法**（命名谎报持久化）；删 `checkpointDirty` 字段 + `settleCheckpoint()`（自问自答闭环 = 纯内耗）。
- 保留 `touchCheckpoint` 心跳半边（暂停超时判定兜底依据）。
- 注：`SessionCheckpoint.schemaVersion`（CHKPT-1）实际早于 2026-09-20 删除，本次为台账滞后销项。

**④ 发版前公开面历史遗留清理（2026-10-16 · 全公开 API 逐个审查批次）** — 5.0.0 是 major 窗口，已知遗留一次清完
- 删 `AgentOptions.fileConsistencyCheck` + `FileConsistencyCheck` 类型（僵尸声明，文档说删了代码残留）；
- 删 `LOOP_CONSTANTS.MAX_WEB_SEARCH_CALLS`（幽灵旋钮，运行时恒读 `strategy.webSearchLimit`）；键数 27 → 26；
- 删 `SessionManager.heartbeat()` / `isPaused()` / `isRunning()`（SSOT 冗余接口，提前于 deprecation 直删）；
- 立起 **deprecation 废弃机制**（`@deprecated` 标注 + 台账移除清单 + 守卫基线保留三件套），台账观察区立 `DEPRECATE-1`。

**⑤ 公开面零消费防滥用链 + 强制释放锁门面（2026-10-16 批）**
- 删防滥用计数链（`isPauseLimitReached` / `getConsecutivePauseCount` / `resetConsecutivePauseCount` + 私有连带，从未通电的谎报型僵尸）+ `Agent.forceReleaseChatLock()` 门面（宿主零真实调用）；
- 删恢复会话双入口（`restoreMostRecentSession` / `restoreSession`）+ `compensateTool` / `compensateAllNonIdempotent`（no-op 型）+ `getRecentToolExecutions` + `getBackgroundTaskStats`（含连坐 `BackgroundTaskStats`）；
- 连带 `6954d4f3`「收敛会话替换入口状态闸不对称」随本批收口——复核发现该提交原为 **CHANGELOG 漏账**（`assertSessionReplaceable` 零命中），**2026-10-17 已补账**为独立 Fixed 小节（见第三节）。

### 2.2 Added（新增能力）

| 条目 | 内容 | 状态 |

| **存储层 SQLite 内核切片** | 新增 `createNodeSqliteStorage(dbPath)`（同步工厂）+ `ReadOnlyMemoryStorage`（只读视图类型）2 个公共导出；实现类 `NodeSqliteStorage` 不挂公共面。**零第三方依赖、零 native**——基于 `node:sqlite` 内建模块 + `getBuiltinModule` 延迟加载 ⇒ `engines` 不收紧；只读视图写方法结构上不存在；语义逐位对齐 `InMemoryStorage`（共用契约套件） | 2026-10-16 |

| **`webSearchLimit` 策略键** | `global` 新增整数键（1~20，默认 6），web_search turn 粒度硬上限从写死常量抬为角色包可配；与 `askLimit` 完全同构；上界 20 依据联网检索同类 agent 预算 15~30 | `GUARD-SEARCH-1` |

## 六、结论

1. **内核变更全部已入账且质量闭环**：156 提交中内核部分（`src/` 76 文件 +5700/−3703、30 条 src 提交）在 CHANGELOG `[5.0.0]` 区**逐条可溯**；守卫体系本区间显著强化（成员级快照 + 三向文档对账 + 自消费完整性）。
2. **发布文档内容层对齐、版本标识层已订正**：4 处版本标识（API 手册 / 接入指南 / README 中英）原停在 4.0.0，**2026-10-17 已全部统一为 v5.0.0**；仅 CHANGELOG `[5.0.0] · 未发布` 标题待真正出包时改日期。
3. **5.0.0 的破坏面已完整披露**：**5 批** Breaking（公开面收面 ×2 + 目标漂移链退役 + 检查点减法 + 逐项清理）在 CHANGELOG 均有 Breaking 段明示 4.x 升级者代价。
4. **未闭合项均为「观察/悬案/缓办」**，无阻断发布的内核缺陷；`GATE-COV-1` 与 `ARCH-GAP-F3` 为需关注的两处。
